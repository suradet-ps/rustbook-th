## การติดตั้ง

ขั้นตอนแรกคือการติดตั้ง Rust เราจะดาวน์โหลด Rust ผ่าน `rustup` ซึ่งเป็นเครื่องมือบรรทัดคำสั่งสำหรับจัดการเวอร์ชันของ Rust และเครื่องมือที่เกี่ยวข้อง คุณจะต้องเชื่อมต่ออินเทอร์เน็ตสำหรับการดาวน์โหลดนี้

> หมายเหตุ: หากคุณไม่สะดวกใช้ `rustup` ด้วยเหตุผลบางประการ สามารถดูช่องทางเลือกเพิ่มเติมได้ที่[หน้าวิธีการติดตั้ง Rust แบบอื่นๆ][otherinstall]

ขั้นตอนต่อไปนี้จะติดตั้งคอมไพเลอร์ Rust เวอร์ชันเสถียร (stable) ล่าสุด ซึ่งการรับประกันความเสถียรของ Rust ทำให้มั่นใจได้ว่าตัวอย่างโค้ดทั้งหมดในหนังสือที่คอมไพล์ผ่าน จะยังคงคอมไพล์ผ่านกับ Rust เวอร์ชันใหม่กว่าในอนาคตได้อย่างแน่นอน ทั้งนี้ ข้อความเอาต์พุตอาจแตกต่างไปบ้างเล็กน้อยระหว่างแต่ละเวอร์ชัน เนื่องจาก Rust มีการปรับปรุงข้อความแจ้งข้อผิดพลาดและคำเตือนให้ชัดเจนขึ้นอยู่เสมอ กล่าวคือ ไม่ว่าคุณจะติดตั้ง Rust เวอร์ชันเสถียรรุ่นใหม่ใดก็ตามตามขั้นตอนนี้ โค้ดตัวอย่างในหนังสือเล่มนี้จะยังคงทำงานได้ถูกต้องตามที่คาดหวัง

> ### สัญกรณ์บรรทัดคำสั่ง
>
> ในบทนี้และตลอดทั้งเล่ม เราจะแสดงคำสั่งที่ใช้ในเทอร์มินัล โดยบรรทัดที่คุณต้องพิมพ์ลงในเทอร์มินัลจะขึ้นต้นด้วย `$` เสมอ ซึ่งคุณไม่จำเป็นต้องพิมพ์เครื่องหมาย `$` ตาม เพราะเป็นเพียงสัญลักษณ์พรอมต์บรรทัดคำสั่งที่บอกจุดเริ่มต้นของแต่ละคำสั่ง ส่วนบรรทัดที่ไม่ขึ้นต้นด้วย `$` จะแสดงผลลัพธ์ (output) จากคำสั่งก่อนหน้า นอกจากนี้ ในตัวอย่างคำสั่งเฉพาะของ PowerShell จะใช้เครื่องหมาย `>` แทน `$`

### การติดตั้ง `rustup` บน Linux หรือ macOS

หากคุณใช้งาน Linux หรือ macOS ให้เปิดเทอร์มินัลแล้วป้อนคำสั่งต่อไปนี้:

```console
$ curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh
```

คำสั่งนี้จะดาวน์โหลดสคริปต์และเริ่มการติดตั้งเครื่องมือ `rustup` ซึ่งจะทำการติดตั้ง Rust เวอร์ชันเสถียรล่าสุดให้โดยอัตโนมัติ คุณอาจต้องป้อนรหัสผ่านของผู้ดูแลระบบในระหว่างนี้ และเมื่อติดตั้งสำเร็จ จะมีข้อความต่อไปนี้ปรากฏขึ้น:

```text
Rust is installed now. Great!
```

คุณจำเป็นต้องมี _ตัวเชื่อมโยง_ (linker) ซึ่งเป็นโปรแกรมที่ Rust ใช้รวมผลลัพธ์ที่คอมไพล์แล้วเข้าด้วยกันเป็นไฟล์เดียว โดยทั่วไปในเครื่องของคุณมักจะมีโปรแกรมนี้ติดตั้งอยู่แล้ว แต่หากพบข้อผิดพลาดเกี่ยวกับตัวเชื่อมโยง คุณควรติดตั้งคอมไพเลอร์ภาษา C เพิ่มเติม ซึ่งโดยปกติจะมาพร้อมกับตัวเชื่อมโยง นอกจากนี้ คอมไพเลอร์ภาษา C ยังมีประโยชน์อย่างยิ่ง เพราะแพ็กเกจ Rust ยอดนิยมบางตัวจำเป็นต้องพึ่งพาโค้ดภาษา C ในการทำงาน

บน macOS คุณสามารถติดตั้งคอมไพเลอร์ C ได้ง่ายๆ โดยรันคำสั่ง:

```console
$ xcode-select --install
```

สำหรับผู้ใช้ Linux โดยทั่วไปแนะนำให้ติดตั้ง GCC หรือ Clang ตามคู่มือของดิสทริบิวชันที่ใช้งาน ตัวอย่างเช่น หากคุณใช้ Ubuntu สามารถติดตั้งแพ็กเกจ `build-essential` ได้ทันที

### การติดตั้ง `rustup` บน Windows

บน Windows ให้เข้าไปที่ [https://www.rust-lang.org/tools/install][install]<!-- ignore --> แล้วปฏิบัติตามคำแนะนำในการติดตั้ง Rust โดยในระหว่างขั้นตอนการติดตั้ง ระบบจะแนะนำให้คุณติดตั้ง Visual Studio ซึ่งจะช่วยจัดเตรียมตัวเชื่อมโยง (linker) และไลบรารีเนทีฟที่จำเป็นสำหรับการคอมไพล์โปรแกรม หากต้องการคำแนะนำเพิ่มเติมสำหรับขั้นตอนนี้ สามารถดูได้ที่ [https://rust-lang.github.io/rustup/installation/windows-msvc.html][msvc]<!-- ignore -->

เนื้อหาในส่วนที่เหลือของหนังสือเล่มนี้จะใช้คำสั่งที่รองรับทั้งใน _cmd.exe_ และ PowerShell หากมีจุดที่แตกต่างกันอย่างชัดเจน เราจะระบุไว้อย่างเจาะจงว่าควรใช้คำสั่งใด

### การแก้ปัญหา

หากต้องการตรวจสอบว่าคุณติดตั้ง Rust ถูกต้องเรียบร้อยหรือไม่ ให้เปิดเทอร์มินัลแล้วป้อนคำสั่งนี้:

```console
$ rustc --version
```

คุณควรจะเห็นหมายเลขเวอร์ชัน แฮชของคอมมิต และวันที่คอมมิตของเวอร์ชันเสถียรล่าสุดที่เผยแพร่ ในรูปแบบดังต่อไปนี้:

```text
rustc x.y.z (abcabcabc yyyy-mm-dd)
```

หากเห็นข้อความในรูปแบบนี้ แสดงว่าคุณติดตั้ง Rust สำเร็จเรียบร้อยแล้ว! แต่หากไม่พบข้อความดังกล่าว ให้ตรวจสอบว่าพาธของ Rust ถูกเพิ่มลงในตัวแปรระบบ `%PATH%` แล้วหรือไม่ ดังนี้:

ใน Windows CMD ให้ใช้:

```console
> echo %PATH%
```

ใน PowerShell ให้ใช้:

```powershell
> echo $env:Path
```

ใน Linux และ macOS ให้ใช้:

```console
$ echo $PATH
```

หากตรวจสอบทุกอย่างแล้วแต่ยังพบปัญหาในการใช้งาน Rust คุณสามารถขอความช่วยเหลือได้จากหลากหลายช่องทาง ดูวิธีติดต่อกับเพื่อนๆ ชาว Rustacean (ชื่อเล่นน่ารักๆ ที่เราใช้เรียกกลุ่มคนรัก Rust) ได้ที่[หน้าชุมชน][community]

### การอัปเดตและการถอนการติดตั้ง

เมื่อติดตั้ง Rust ผ่าน `rustup` แล้ว การอัปเดตเป็นเวอร์ชันล่าสุดก็สามารถทำได้อย่างง่ายดาย เพียงเปิดเทอร์มินัลแล้วรันคำสั่งอัปเดตต่อไปนี้:

```console
$ rustup update
```

หากต้องการถอนการติดตั้ง Rust และ `rustup` ให้รันคำสั่งต่อไปนี้ในเทอร์มินัล:

```console
$ rustup self uninstall
```

### การอ่านเอกสารในเครื่อง

การติดตั้ง Rust ยังได้รวมชุดเอกสารคู่มือไว้ในเครื่องของคุณด้วย เพื่อให้คุณสามารถเปิดอ่านแบบออฟไลน์ได้ทุกเมื่อ เพียงรันคำสั่ง `rustup doc` ระบบจะเปิดเอกสารคู่มือในเครื่องขึ้นมาบนเว็บเบราว์เซอร์ของคุณทันที

เมื่อใดก็ตามที่คุณพบชนิดข้อมูลหรือฟังก์ชันจากไลบรารีมาตรฐาน และต้องการทราบการทำงานหรือวิธีนำไปใช้งาน สามารถเปิดดูได้จากเอกสารส่วนต่อประสานโปรแกรมประยุกต์ (API) เพื่อหาคำตอบได้เสมอ!

### การใช้โปรแกรมแก้ไขข้อความและ IDE

หนังสือเล่มนี้ไม่ได้จำกัดว่าคุณจะต้องใช้เครื่องมือหรือโปรแกรมแก้ไขโค้ดใด คุณสามารถใช้โปรแกรมแก้ไขข้อความตัวใดก็ได้ตามความถนัด! อย่างไรก็ดี โปรแกรมแก้ไขข้อความและสภาพแวดล้อมการพัฒนาแบบบูรณาการ (IDE) ยอดนิยมหลายตัวต่างรองรับภาษา Rust ในตัว สามารถตรวจสอบรายชื่อโปรแกรมแก้ไขข้อความและ IDE ที่แนะนำในปัจจุบันได้ที่[หน้าเครื่องมือ][tools]บนเว็บไซต์ของ Rust

### การทำงานแบบออฟไลน์กับหนังสือเล่มนี้

ในหลายๆ ตัวอย่าง เราจะมีการนำแพ็กเกจนอกไลบรารีมาตรฐานมาใช้งาน ซึ่งจำเป็นต้องเชื่อมต่ออินเทอร์เน็ตหรือดาวน์โหลดแพ็กเกจที่ต้องพึ่งพา (dependencies) เตรียมไว้ล่วงหน้า หากต้องการดาวน์โหลดไว้ล่วงหน้า สามารถรันคำสั่งต่อไปนี้ (เราจะอธิบายรายละเอียดว่า `cargo` คืออะไรและแต่ละคำสั่งทำงานอย่างไรในภายหลัง):

<!-- When updating the version of `rand` used, also update the version of
`rand` used in these files so they all match:

* ch02-00-guessing-game-tutorial.md
* ch07-04-bringing-paths-into-scope-with-the-use-keyword.md
* ch14-03-cargo-workspaces.md

```console
$ cargo new get-dependencies
$ cd get-dependencies
$ cargo add rand@0.10.1 trpl@0.2.0
```

คำสั่งนี้จะดาวน์โหลดและแคชแพ็กเกจเหล่านี้ไว้ในเครื่อง เพื่อให้คุณไม่ต้องดาวน์โหลดซ้ำอีกในภายหลัง เมื่อรันคำสั่งเสร็จเรียบร้อยแล้ว คุณสามารถลบโฟลเดอร์ `get-dependencies` ทิ้งได้ทันที และหลังจากนี้ คุณสามารถเพิ่มแฟล็ก `--offline` ต่อท้ายคำสั่ง `cargo` ในตัวอย่างอื่นๆ ของหนังสือ เพื่อทำงานแบบออฟไลน์ได้โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต
