## การติดตั้ง

ขั้นตอนแรกคือการติดตั้ง Rust เราจะดาวน์โหลด Rust ผ่าน `rustup` ซึ่งเป็นเครื่องมือบรรทัดคำสั่งสำหรับจัดการเวอร์ชันของ Rust และเครื่องมือที่เกี่ยวข้อง คุณจะต้องมีอินเทอร์เน็ตสำหรับการดาวน์โหลด

> หมายเหตุ: หากคุณไม่อยากใช้ `rustup` ด้วยเหตุผลบางประการ โปรดดู[หน้าวิธีติดตั้ง Rust วิธีอื่นๆ][otherinstall] สำหรับทางเลือกเพิ่มเติม

ขั้นตอนต่อไปนี้จะติดตั้ง Rust คอมไพเลอร์เวอร์ชันเสถียรล่าสุด การรับประกันความเสถียรของ Rust ทำให้มั่นใจได้ว่าตัวอย่างทั้งหมดในหนังสือที่คอมไพล์ผ่านจะยังคงคอมไพล์ผ่านกับ Rust เวอร์ชันใหม่กว่าได้ เอาต์พุตอาจแตกต่างกันเล็กน้อยระหว่างเวอร์ชัน เพราะ Rust มักปรับปรุงข้อความแสดงข้อผิดพลาดและคำเตือนอยู่เสมอ กล่าวอีกนัยหนึ่ง Rust เวอร์ชันเสถียรใหม่กว่าใดๆ ที่คุณติดตั้งด้วยขั้นตอนเหล่านี้ ควรใช้งานได้ตามที่คาดหวังกับเนื้อหาของหนังสือเล่มนี้

> ### สัญกรณ์บรรทัดคำสั่ง
>
> ในบทนี้และตลอดทั้งเล่ม เราจะแสดงคำสั่งที่ใช้ในเทอร์มินัล บรรทัดที่คุณต้องป้อนในเทอร์มินัลจะขึ้นต้นด้วย `$` เสมอ คุณไม่จำเป็นต้องพิมพ์เครื่องหมาย `$` เพราะมันคือพรอมต์บรรทัดคำสั่งที่แสดงเพื่อบอกจุดเริ่มต้นของแต่ละคำสั่ง บรรทัดที่ไม่ขึ้นต้นด้วย `$` มักแสดงเอาต์พุตของคำสั่งก่อนหน้า นอกจากนี้ ตัวอย่างเฉพาะของ PowerShell จะใช้ `>` แทน `$`

### การติดตั้ง `rustup` บน Linux หรือ macOS

หากคุณใช้ Linux หรือ macOS ให้เปิดเทอร์มินัลแล้วป้อนคำสั่งต่อไปนี้:

```console
$ curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh
```

คำสั่งนี้จะดาวน์โหลดสคริปต์และเริ่มติดตั้งเครื่องมือ `rustup` ซึ่งจะติดตั้ง Rust เวอร์ชันเสถียรล่าสุด คุณอาจถูกขอให้ป้อนรหัสผ่าน หากติดตั้งสำเร็จ จะมีบรรทัดต่อไปนี้ปรากฏขึ้น:

```text
Rust is installed now. Great!
```

คุณจะต้องมี _ตัวเชื่อมโยง_ (linker) ซึ่งเป็นโปรแกรมที่ Rust ใช้รวมผลลัพธ์ที่คอมไพล์แล้วให้เป็นไฟล์เดียว คุณน่าจะมีอยู่แล้ว หากคุณพบข้อผิดพลาดเกี่ยวกับตัวเชื่อมโยง คุณควรติดตั้งคอมไพเลอร์ C ซึ่งโดยทั่วไปจะมาพร้อมตัวเชื่อมโยง คอมไพเลอร์ C ยังมีประโยชน์เพราะแพ็กเกจ Rust ที่ใช้กันทั่วไปบางตัวพึ่งพาโค้ด C และจำเป็นต้องใช้คอมไพเลอร์ C

บน macOS คุณสามารถติดตั้งคอมไพเลอร์ C ได้โดยรัน:

```console
$ xcode-select --install
```

ผู้ใช้ Linux โดยทั่วไปควรติดตั้ง GCC หรือ Clang ตามเอกสารของดิสทริบิวชันที่ใช้ ตัวอย่างเช่น หากคุณใช้ Ubuntu คุณสามารถติดตั้งแพ็กเกจ `build-essential` ได้

### การติดตั้ง `rustup` บน Windows

บน Windows ให้ไปที่ [https://www.rust-lang.org/tools/install][install]<!-- ignore --> และทำตามคำแนะนำในการติดตั้ง Rust ในขั้นตอนใดขั้นตอนหนึ่งของการติดตั้ง คุณจะถูกขอให้ติดตั้ง Visual Studio ซึ่งจะให้ตัวเชื่อมโยงและไลบรารีเนทีฟที่จำเป็นสำหรับการคอมไพล์โปรแกรม หากคุณต้องการความช่วยเหลือเพิ่มเติมในขั้นตอนนี้ ดูได้ที่ [https://rust-lang.github.io/rustup/installation/windows-msvc.html][msvc]<!-- ignore -->.

ส่วนที่เหลือของหนังสือเล่มนี้ใช้คำสั่งที่ทำงานได้ทั้งใน _cmd.exe_ และ PowerShell หากมีความแตกต่างเฉพาะเจาะจง เราจะอธิบายว่าควรใช้อย่างไหน

### การแก้ปัญหา

หากต้องการตรวจสอบว่าคุณติดตั้ง Rust ถูกต้องหรือไม่ ให้เปิดเชลล์แล้วป้อนบรรทัดนี้:

```console
$ rustc --version
```

คุณควรเห็นหมายเลขเวอร์ชัน แฮชคอมมิต และวันที่คอมมิตของเวอร์ชันเสถียรล่าสุดที่เผยแพร่ ในรูปแบบต่อไปนี้:

```text
rustc x.y.z (abcabcabc yyyy-mm-dd)
```

หากคุณเห็นข้อมูลนี้ แสดงว่าคุณติดตั้ง Rust สำเร็จแล้ว! หากไม่เห็น ให้ตรวจสอบว่า Rust อยู่ในตัวแปรระบบ `%PATH%` ของคุณหรือไม่ ดังนี้

ใน Windows CMD ให้ใช้:

```console
> echo %PATH%
```

ใน PowerShell ให้ใช้:

```powershell
> echo $env:Path
```

ใน Linux และ macOS ให้ใช้:

```console
$ echo $PATH
```

หากทุกอย่างถูกต้องแล้วแต่ Rust ยังใช้งานไม่ได้ มีหลายที่ที่คุณขอความช่วยเหลือได้ ดูวิธีติดต่อกับ Rustacean คนอื่นๆ (ชื่อเล่นตลกๆ ที่เราใช้เรียกตัวเอง) ได้ที่[หน้าชุมชน][community]

### การอัปเดตและการถอนการติดตั้ง

เมื่อติดตั้ง Rust ผ่าน `rustup` แล้ว การอัปเดตเป็นเวอร์ชันใหม่ที่เผยแพร่ก็เป็นเรื่องง่าย จากเชลล์ของคุณ ให้รันสคริปต์อัปเดตต่อไปนี้:

```console
$ rustup update
```

หากต้องการถอนการติดตั้ง Rust และ `rustup` ให้รันสคริปต์ถอนการติดตั้งต่อไปนี้จากเชลล์ของคุณ:

```console
$ rustup self uninstall
```

### การอ่านเอกสารในเครื่อง

การติดตั้ง Rust ยังรวมสำเนาเอกสารไว้ในเครื่องด้วย เพื่อให้คุณอ่านแบบออฟไลน์ได้ รัน `rustup doc` เพื่อเปิดเอกสารในเครื่องในเบราว์เซอร์

เมื่อใดก็ตามที่ชนิดข้อมูลหรือฟังก์ชันมาจากไลบรารีมาตรฐาน และคุณไม่แน่ใจว่ามันทำอะไรหรือใช้อย่างไร ให้ใช้เอกสารส่วนติดต่อโปรแกรม (API) เพื่อค้นหาคำตอบ!

### การใช้โปรแกรมแก้ไขข้อความและ IDE

หนังสือเล่มนี้ไม่ตั้งสมมติฐานว่าคุณใช้เครื่องมืออะไรในการเขียนโค้ด Rust โปรแกรมแก้ไขข้อความแทบทุกตัวก็ทำงานนี้ได้! อย่างไรก็ตาม โปรแกรมแก้ไขข้อความและสภาพแวดล้อมการพัฒนาแบบบูรณาการ (IDE) หลายตัวมีการรองรับ Rust ในตัว คุณสามารถดูรายชื่อโปรแกรมแก้ไขข้อความและ IDE ที่ค่อนข้างเป็นปัจจุบันได้ที่[หน้าเครื่องมือ][tools]บนเว็บไซต์ของ Rust

### การทำงานแบบออฟไลน์กับหนังสือเล่มนี้

ในตัวอย่างหลายตัวอย่าง เราจะใช้แพ็กเกจ Rust ที่อยู่นอกไลบรารีมาตรฐาน ในการทำตัวอย่างเหล่านั้นให้สำเร็จ คุณจะต้องมีอินเทอร์เน็ตหรือดาวน์โหลดดีเพนเดนซีเหล่านั้นไว้ล่วงหน้า หากต้องการดาวน์โหลดดีเพนเดนซีไว้ล่วงหน้า คุณสามารถรันคำสั่งต่อไปนี้ (เราจะอธิบายว่า `cargo` คืออะไรและแต่ละคำสั่งทำอะไรโดยละเอียดในภายหลัง)
