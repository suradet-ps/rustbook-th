## ภาคผนวก A: คำสงวน

รายการต่อไปนี้ประกอบด้วยคำสงวน (keyword) ที่ถูกสงวนไว้สำหรับการใช้งานในปัจจุบันหรือในอนาคตของภาษา Rust ด้วยเหตุนี้จึงไม่สามารถใช้เป็นชื่อเรียก (identifier) ได้ (ยกเว้นเมื่อใช้เป็นชื่อเรียกแบบ raw (raw identifier) ดังที่เราพูดคุยกันในหัวข้อ[“ชื่อเรียกแบบ raw”][raw-identifiers]<!-- ignore -->) _ชื่อเรียก_ คือชื่อของฟังก์ชัน ตัวแปร พารามิเตอร์ ฟิลด์ของ struct มอดูล เครต (crate) ค่าคงที่ มาโคร (macro) ค่าสแตติก แอตทริบิวต์ (attribute) ชนิดข้อมูล เทรต (trait) หรือไลฟ์ไทม์ (lifetime)

[raw-identifiers]: #raw-identifiers

### คำสงวนที่ใช้อยู่ในปัจจุบัน

ต่อไปนี้คือรายการคำสงวนที่ใช้อยู่ในปัจจุบัน พร้อมคำอธิบายการทำงานของแต่ละคำ

- **`as`**: ทำการแคสต์ชนิดพื้นฐาน แก้ความกำกวมของเทรตที่เฉพาะเจาะจงซึ่งบรรจุรายการ หรือเปลี่ยนชื่อรายการในสเตตเมนต์ `use`
- **`async`**: คืนค่า `Future` แทนการบล็อกเธรด (thread) ปัจจุบัน
- **`await`**: ระงับการทำงานจนกว่าผลลัพธ์ของ `Future` จะพร้อม
- **`break`**: ออกจากลูปทันที
- **`const`**: นิยามรายการค่าคงที่หรือพอยน์เตอร์ดิบ (raw pointer) ที่เป็นค่าคงที่
- **`continue`**: ไปยังการวนซ้ำ (iteration) รอบถัดไปของลูป
- **`crate`**: ในพาธของมอดูล อ้างถึงรากของเครต
- **`dyn`**: การดิสแพตช์แบบไดนามิก (dynamic dispatch) ไปยังเทรตออบเจกต์ (trait object)
- **`else`**: ทางเลือกสำรองสำหรับโครงสร้างการควบคุมโฟลว์ `if` และ `if let`
- **`enum`**: นิยาม enum
- **`extern`**: เชื่อมโยงฟังก์ชันหรือตัวแปรภายนอก
- **`false`**: ลิเทอรัลเท็จของบูลีน (boolean)
- **`fn`**: นิยามฟังก์ชันหรือชนิดพอยน์เตอร์ของฟังก์ชัน
- **`for`**: วนซ้ำรายการจากอิเทอเรเตอร์ (iterator) อิมพลีเมนต์เทรต หรือระบุไลฟ์ไทม์แบบ higher ranked
- **`if`**: แยกกิ่งตามผลลัพธ์ของเอ็กซ์เพรสชันเงื่อนไข
- **`impl`**: อิมพลีเมนต์ฟังก์ชันการทำงานแบบ inherent หรือของเทรต
- **`in`**: ส่วนหนึ่งของวากยสัมพันธ์ลูป `for`
- **`let`**: ผูกค่าตัวแปร
- **`loop`**: วนซ้ำโดยไม่มีเงื่อนไข
- **`match`**: จับคู่ค่ากับแพตเทิร์น
- **`mod`**: นิยามมอดูล
- **`move`**: ทำให้โคลเชอร์ (closure) รับความเป็นเจ้าของค่าที่มันจับมาทั้งหมด
- **`mut`**: ระบุความสามารถในการเปลี่ยนแปลงค่า (mutability) ในเรเฟอเรนซ์ พอยน์เตอร์ดิบ หรือการผูกค่าแพตเทิร์น
- **`pub`**: ระบุการมองเห็นแบบสาธารณะ (public) ในฟิลด์ของ struct บล็อก `impl` หรือมอดูล
- **`ref`**: ผูกค่าด้วยเรเฟอเรนซ์
- **`return`**: คืนค่าจากฟังก์ชัน
- **`Self`**: นามแฝงชนิดข้อมูลสำหรับชนิดข้อมูลที่เรากำลังนิยามหรืออิมพลีเมนต์
- **`self`**: ตัวรับของเมธอดหรือมอดูลปัจจุบัน
- **`static`**: ตัวแปรส่วนกลางหรือไลฟ์ไทม์ที่คงอยู่ตลอดการทำงานทั้งหมดของโปรแกรม
- **`struct`**: นิยาม struct
- **`super`**: มอดูลแม่ของมอดูลปัจจุบัน
- **`trait`**: นิยามเทรต
- **`true`**: ลิเทอรัลจริงของบูลีน
- **`type`**: นิยามนามแฝงชนิดข้อมูลหรือชนิดข้อมูลที่เชื่อมโยงกัน (associated type)
- **`union`**: นิยาม [union][union]<!-- ignore -->; เป็นคำสงวนเฉพาะเมื่อใช้ในการประกาศ union
- **`unsafe`**: ระบุโค้ด ฟังก์ชัน เทรต หรือการอิมพลีเมนต์ที่เป็น unsafe
- **`use`**: นำสัญลักษณ์ (symbol) เข้าสู่สโคป (scope)
- **`where`**: ระบุข้อกำหนดที่จำกัดชนิดข้อมูล
- **`while`**: วนซ้ำตามเงื่อนไขโดยอิงจากผลลัพธ์ของเอ็กซ์เพรสชัน

[union]: ../reference/items/unions.html

### คำสงวนที่สงวนไว้สำหรับใช้ในอนาคต

คำสงวนต่อไปนี้ยังไม่มีฟังก์ชันการทำงานใดๆ แต่ถูกสงวนไว้โดย Rust สำหรับการใช้งานในอนาคตที่อาจเป็นไปได้:

- `abstract`
- `become`
- `box`
- `do`
- `final`
- `gen`
- `macro`
- `override`
- `priv`
- `try`
- `typeof`
- `unsized`
- `virtual`
- `yield`

### ชื่อเรียกแบบ raw

_ชื่อเรียกแบบ raw_ เป็นวากยสัมพันธ์ที่ให้คุณใช้คำสงวนในจุดที่ปกติแล้วไม่อนุญาตให้ใช้ คุณใช้ชื่อเรียกแบบ raw โดยเติมคำนำหน้า `r#` ให้คำสงวน

ตัวอย่างเช่น `match` เป็นคำสงวน หากคุณพยายามคอมไพล์ฟังก์ชันต่อไปนี้ที่ใช้ `match` เป็นชื่อของมัน:

<span class="filename">ชื่อไฟล์: src/main.rs</span>

```rust,ignore,does_not_compile
fn match(needle: &str, haystack: &str) -> bool {
    haystack.contains(needle)
}
```

คุณจะได้รับข้อผิดพลาดนี้:

```text
error: expected identifier, found keyword `match`
 --> src/main.rs:4:4
  |
4 | fn match(needle: &str, haystack: &str) -> bool {
  |    ^^^^^ expected identifier, found keyword
```

ข้อผิดพลาดนี้แสดงให้เห็นว่าคุณไม่สามารถใช้คำสงวน `match` เป็นชื่อเรียกของฟังก์ชันได้ หากต้องการใช้ `match` เป็นชื่อฟังก์ชัน คุณต้องใช้ชื่อเรียกแบบ raw ดังนี้:

<span class="filename">ชื่อไฟล์: src/main.rs</span>

```rust
fn r#match(needle: &str, haystack: &str) -> bool {
    haystack.contains(needle)
}

fn main() {
    assert!(r#match("foo", "foobar"));
}
```

โค้ดนี้จะคอมไพล์ผ่านโดยไม่มีข้อผิดพลาดใดๆ โปรดสังเกตคำนำหน้า `r#` ที่ชื่อฟังก์ชันทั้งในนิยามของมันและในจุดที่ฟังก์ชันถูกเรียกใน `main`

ชื่อเรียกแบบ raw ช่วยให้คุณใช้คำใดก็ได้ที่คุณเลือกเป็นชื่อเรียก แม้ว่าคำนั้นบังเอิญเป็นคำสงวนก็ตาม สิ่งนี้ให้อิสระแก่เรามากขึ้นในการเลือกชื่อเรียก และยังช่วยให้เราเชื่อมต่อกับโปรแกรมที่เขียนด้วยภาษาซึ่งคำเหล่านี้ไม่ใช่คำสงวนได้ด้วย นอกจากนี้ ชื่อเรียกแบบ raw ยังให้คุณใช้ไลบรารีที่เขียนด้วย Rust ฉบับ (edition) ที่ต่างจากที่เครตของคุณใช้ได้ ตัวอย่างเช่น `try` ไม่ใช่คำสงวนในฉบับ 2015 แต่เป็นคำสงวนในฉบับ 2018, 2021 และ 2024 หากคุณพึ่งพาไลบรารีที่เขียนด้วยฉบับ 2015 และมีฟังก์ชัน `try` คุณจะต้องใช้ชื่อเรียกแบบ raw ซึ่งในกรณีนี้คือ `r#try` เพื่อเรียกฟังก์ชันนั้นจากโค้ดของคุณบนฉบับที่ใหม่กว่า ดู[ภาคผนวก E][appendix-e]<!-- ignore --> สำหรับข้อมูลเพิ่มเติมเกี่ยวกับฉบับของ Rust
