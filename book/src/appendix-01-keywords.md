## ภาคผนวก A: คำสงวน

รายการต่อไปนี้รวบรวมคำสงวน (keywords) ที่ถูกสงวนไว้สำหรับการใช้งานในปัจจุบันหรือในอนาคตของภาษา Rust ด้วยเหตุนี้ คำเหล่านี้จึงไม่สามารถนำมาตั้งเป็นตัวระบุหรือชื่อเรียก (identifiers) ได้ (ยกเว้นเมื่อใช้งานในรูปแบบ raw identifier ดังที่เราจะกล่าวถึงในหัวข้อ[“ชื่อเรียกแบบ raw”][raw-identifiers]<!-- ignore -->) โดยคำว่า _ตัวระบุ (identifiers)_ หมายถึงชื่อของฟังก์ชัน ตัวแปร พารามิเตอร์ ฟิลด์ของ struct มอดูล เครต (crate) ค่าคงที่ มาโคร (macro) ค่าสแตติก แอตทริบิวต์ (attribute) ชนิดข้อมูล เทรต (trait) หรือช่วงอายุ (lifetime)

[raw-identifiers]: #ชือเรียกแบบ-raw

### คำสงวนที่ใช้อยู่ในปัจจุบัน

ต่อไปนี้คือรายการคำสงวนที่ใช้อยู่ในปัจจุบัน พร้อมคำอธิบายการทำงานของแต่ละคำ

- **`as`**: ทำการแคสต์ชนิดข้อมูลพื้นฐาน, ช่วยแยกความกำกวมของเทรตเฉพาะที่มีไอเท็มนั้นอยู่ หรือใช้เปลี่ยนชื่อไอเท็มในสเตตเมนต์ `use`
- **`async`**: คืนค่าเป็น `Future` แทนที่จะทำการบล็อกเธรด (thread) ปัจจุบัน
- **`await`**: พักการทำงานชั่วคราวไว้จนกว่าผลลัพธ์ของ `Future` จะพร้อมใช้งาน
- **`break`**: ออกจากลูปการทำงานทันที
- **`const`**: นิยามค่าคงที่ หรือ raw pointer ที่เป็นค่าคงที่
- **`continue`**: ข้ามไปยังรอบถัดไปของลูปการทำงาน
- **`crate`**: ในพาธของมอดูล ใช้อ้างอิงถึงรูทของเครต (crate root)
- **`dyn`**: ส่งต่อการทำงานแบบไดนามิก (dynamic dispatch) ไปยังเทรตออบเจกต์ (trait object)
- **`else`**: ทางเลือกสำรองในโครงสร้างควบคุมทิศทางการทำงานแบบ `if` และ `if let`
- **`enum`**: นิยามประเภทข้อมูลแจงนับ (enumeration)
- **`extern`**: เชื่อมโยงฟังก์ชันหรือตัวแปรภายนอก
- **`false`**: ค่าลิเทอรัลเท็จของชนิดข้อมูลบูลีน (boolean)
- **`fn`**: นิยามฟังก์ชัน หรือชนิดข้อมูลพอยน์เตอร์ของฟังก์ชัน
- **`for`**: วนลูปประมวลผลสมาชิกจากอิเทอเรเตอร์ (iterator), อิมพลีเมนต์เทรต หรือระบุช่วงอายุแบบ higher-ranked
- **`if`**: แตกกิ่งการทำงานตามผลลัพธ์ของนิพจน์เงื่อนไข
- **`impl`**: อิมพลีเมนต์ฟังก์ชันการทำงานเฉพาะตัว (inherent) หรือของเทรต
- **`in`**: ส่วนหนึ่งของไวยากรณ์ลูป `for`
- **`let`**: ผูกค่าตัวแปร
- **`loop`**: วนลูปซ้ำแบบไม่มีเงื่อนไข
- **`match`**: จับคู่ค่ากับแพตเทิร์น
- **`mod`**: นิยามมอดูล
- **`move`**: กำหนดให้โคลเชอร์ (closure) รับสิทธิ์ความเป็นเจ้าของในตัวแปรทั้งหมดที่แคปเจอร์มา
- **`mut`**: ระบุความสามารถในการเปลี่ยนแปลงค่า (mutability) ในการอ้างอิง, raw pointer หรือการผูกค่าแพตเทิร์น
- **`pub`**: กำหนดระดับการเข้าถึงเป็นแบบสาธารณะ (public) ในฟิลด์ของ struct, บล็อก `impl` หรือมอดูล
- **`ref`**: ผูกค่าด้วยการอ้างอิง (reference)
- **`return`**: คืนค่าออกจากฟังก์ชัน
- **`Self`**: นามแฝงชนิดข้อมูลสำหรับชนิดข้อมูลที่เรากำลังนิยามหรืออิมพลีเมนต์อยู่
- **`self`**: ตัวรับของเมธอด (method subject) หรือมอดูลปัจจุบัน
- **`static`**: ตัวแปรส่วนกลาง (global variable) หรือช่วงอายุที่คงอยู่ตลอดอายุการทำงานของโปรแกรม
- **`struct`**: นิยามโครงสร้างข้อมูล (struct)
- **`super`**: มอดูลแม่ของมอดูลปัจจุบัน
- **`trait`**: นิยามเทรต (trait)
- **`true`**: ค่าลิเทอรัลจริงของชนิดข้อมูลบูลีน
- **`type`**: นิยามนามแฝงชนิดข้อมูล (type alias) หรือชนิดข้อมูลร่วม (associated type)
- **`union`**: นิยาม [union][union]<!-- ignore -->; ถือเป็นคำสงวนเฉพาะเมื่อใช้ในการประกาศ union เท่านั้น
- **`unsafe`**: ระบุโค้ด ฟังก์ชัน เทรต หรือการอิมพลีเมนต์ที่อาจไม่ปลอดภัย (unsafe)
- **`use`**: นำสัญลักษณ์ (symbols) เข้ามาสู่ขอบเขตการทำงาน (scope)
- **`where`**: ระบุข้อกำหนดเงื่อนไข (clauses) ที่ใช้จำกัดชนิดข้อมูล
- **`while`**: วนลูปตามเงื่อนไขโดยอิงจากผลลัพธ์ของนิพจน์

[union]: ../reference/items/unions.html

### คำสงวนที่สงวนไว้สำหรับใช้ในอนาคต

คำสงวนต่อไปนี้ยังไม่มีฟังก์ชันการทำงานใด ๆ ในปัจจุบัน แต่ถูกสงวนไว้โดยภาษา Rust เผื่อสำหรับการใช้งานในอนาคต:

- `abstract`
- `become`
- `box`
- `do`
- `final`
- `gen`
- `macro`
- `override`
- `priv`
- `try`
- `typeof`
- `unsized`
- `virtual`
- `yield`

### ชื่อเรียกแบบ raw

_ชื่อเรียกแบบ raw (raw identifiers)_ คือไวยากรณ์พิเศษที่ช่วยให้คุณสามารถนำคำสงวนมาใช้ในตำแหน่งที่ปกติแล้วไม่อนุญาตให้ใช้ได้ โดยใช้งานด้วยการใส่คำนำหน้า `r#` กำกับไว้หน้าคำสงวน

ตัวอย่างเช่น `match` เป็นคำสงวน หากคุณพยายามคอมไพล์ฟังก์ชันต่อไปนี้ที่ใช้ `match` เป็นชื่อของมัน:

<span class="filename">ชื่อไฟล์: src/main.rs</span>

```rust,ignore,does_not_compile
fn match(needle: &str, haystack: &str) -> bool {
    haystack.contains(needle)
}
```

คุณจะได้รับข้อผิดพลาดนี้:

```text
error: expected identifier, found keyword `match`
 --> src/main.rs:4:4
  |
4 | fn match(needle: &str, haystack: &str) -> bool {
  |    ^^^^^ expected identifier, found keyword
```

ข้อผิดพลาดนี้แสดงให้เห็นว่าคุณไม่สามารถใช้คำสงวน `match` เป็นชื่อเรียกของฟังก์ชันได้ หากต้องการใช้ `match` เป็นชื่อฟังก์ชัน คุณต้องใช้ชื่อเรียกแบบ raw ดังนี้:

<span class="filename">ชื่อไฟล์: src/main.rs</span>

```rust
fn r#match(needle: &str, haystack: &str) -> bool {
    haystack.contains(needle)
}

fn main() {
    assert!(r#match("foo", "foobar"));
}
```

โค้ดชุดนี้จะคอมไพล์ผ่านได้โดยไม่มีข้อผิดพลาดใด ๆ สังเกตการใส่คำนำหน้า `r#` ที่ชื่อฟังก์ชัน ทั้งในจุดที่นิยามฟังก์ชันและจุดที่เรียกใช้ฟังก์ชันใน `main`

ชื่อเรียกแบบ raw ช่วยให้คุณสามารถเลือกใช้คำใดก็ได้เป็นตัวระบุ แม้ว่าคำนั้นจะตรงกับคำสงวนก็ตาม วิธีนี้ช่วยให้เรามีอิสระในการตั้งชื่อตัวระบุมากขึ้น และยังช่วยให้สามารถทำงานร่วมกับโปรแกรมที่เขียนด้วยภาษาอื่นที่คำเหล่านี้ไม่ได้เป็นคำสงวนได้เป็นอย่างดี นอกจากนี้ ชื่อเรียกแบบ raw ยังช่วยให้คุณสามารถเรียกใช้ไลบรารีที่เขียนขึ้นด้วยฉบับ (edition) ของ Rust ที่แตกต่างจากฉบับที่เครตของคุณใช้อยู่ได้ ตัวอย่างเช่น คำว่า `try` ไม่ได้เป็นคำสงวนในฉบับ 2015 แต่ถูกกำหนดเป็นคำสงวนในฉบับ 2018, 2021 และ 2024 หากคุณต้องพึ่งพาไลบรารีที่เขียนด้วยฉบับ 2015 ซึ่งมีฟังก์ชันชื่อ `try` คุณจะต้องใช้ไวยากรณ์ชื่อเรียกแบบ raw ในรูปแบบ `r#try` เพื่อเรียกใช้งานฟังก์ชันดังกล่าวจากโค้ดของคุณในฉบับที่ใหม่กว่า สามารถดูรายละเอียดเพิ่มเติมเกี่ยวกับฉบับต่าง ๆ ของ Rust ได้ใน[ภาคผนวก E][appendix-e]<!-- ignore -->
