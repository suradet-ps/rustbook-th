## รับอาร์กิวเมนต์จากบรรทัดคำสั่ง

มาสร้างโปรเจกต์ใหม่ด้วย `cargo new` เหมือนเช่นเคย เราจะเรียกโปรเจกต์ของเราว่า `minigrep` เพื่อแยกความแตกต่างจากเครื่องมือ `grep` ที่คุณอาจมีอยู่ในระบบของคุณแล้ว:

```console
$ cargo new minigrep
     Created binary (application) `minigrep` project
$ cd minigrep
```

งานแรกคือทำให้ `minigrep` รับอาร์กิวเมนต์ (argument) บรรทัดคำสั่ง (command line) สองตัวของมัน: พาธไฟล์และสตริงที่ต้องการค้นหา นั่นคือ เราต้องการให้รันโปรแกรมของเราด้วย `cargo run` ตามด้วยขีดกลางสองตัวเพื่อบ่งชี้ว่าอาร์กิวเมนต์ถัดไปเป็นของโปรแกรมของเราไม่ใช่ของ `cargo` สตริงที่ต้องการค้นหา และพาธของไฟล์ที่ต้องการค้นหา ดังนี้:

```console
$ cargo run -- searchstring example-filename.txt
```

ตอนนี้ โปรแกรมที่ถูกสร้างโดย `cargo new` ยังไม่สามารถประมวลผลอาร์กิวเมนต์ที่เราส่งให้มันได้ ไลบรารีที่มีอยู่แล้วบางตัวบน [crates.io](https://crates.io/) ช่วยเขียนโปรแกรมที่รับอาร์กิวเมนต์บรรทัดคำสั่งได้ แต่เนื่องจากคุณเพิ่งเรียนรู้แนวคิดนี้ มาอิมพลีเมนต์ความสามารถนี้ด้วยตัวเองกันเถอะ

### การอ่านค่าอาร์กิวเมนต์

เพื่อให้ `minigrep` อ่านค่าของอาร์กิวเมนต์บรรทัดคำสั่งที่เราส่งให้มันได้ เราจะต้องใช้ฟังก์ชัน `std::env::args` ที่ไลบรารีมาตรฐานของ Rust จัดเตรียมไว้ ฟังก์ชันนี้คืนค่าอิเทอเรเตอร์ (iterator) ของอาร์กิวเมนต์บรรทัดคำสั่งที่ถูกส่งให้ `minigrep` เราจะครอบคลุมอิเทอเรเตอร์อย่างเต็มรูปแบบใน[บทที่ 13][ch13]<!-- ignore --> สำหรับตอนนี้ คุณเพียงต้องรู้รายละเอียดสองอย่างเกี่ยวกับอิเทอเรเตอร์: อิเทอเรเตอร์ผลิตค่าออกมาเป็นชุด และเราเรียกเมธอด `collect` บนอิเทอเรเตอร์เพื่อแปลงมันเป็นคอลเลกชัน (collection) เช่นเวกเตอร์ (vector) ที่บรรจุสมาชิกทั้งหมดที่อิเทอเรเตอร์ผลิตออกมาได้

ก่อนอื่น เรานำมอดูล `std::env` เข้าสู่สโคปด้วยสเตตเมนต์ `use` เพื่อให้เราใช้ฟังก์ชัน `args` ของมันได้ โปรดสังเกตว่าฟังก์ชัน `std::env::args` ซ้อนอยู่ภายในมอดูลสองระดับ ดังที่เราได้พูดคุยใน[บทที่ 7][ch7-idiomatic-use]<!-- ignore --> ในกรณีที่ฟังก์ชันที่ต้องการซ้อนอยู่ในมอดูลมากกว่าหนึ่งระดับ เราเลือกนำมอดูลแม่เข้าสู่สโคปแทนที่จะนำฟังก์ชัน การทำเช่นนี้ทำให้เราใช้ฟังก์ชันอื่นๆ จาก `std::env` ได้ง่าย และยังคลุมเครือน้อยกว่าการเพิ่ม `use std::env::args` แล้วเรียกฟังก์ชันด้วย `args` เฉยๆ เพราะ `args` อาจถูกเข้าใจผิดว่าเป็นฟังก์ชันที่นิยามในมอดูลปัจจุบันได้ง่าย

> ### ฟังก์ชัน `args` และ Unicode ที่ไม่ถูกต้อง
>
> โปรดสังเกตว่า `std::env::args` จะแพนิก (panic) หากอาร์กิวเมนต์ใดบรรจุ Unicode ที่ไม่ถูกต้อง หากโปรแกรมของคุณต้องการรับอาร์กิวเมนต์ที่มี Unicode ไม่ถูกต้อง ให้ใช้ `std::env::args_os` แทน ฟังก์ชันนั้นคืนค่าอิเทอเรเตอร์ที่ผลิตค่า `OsString` แทนค่า `String` เราเลือกใช้ `std::env::args` ที่นี่เพื่อความง่าย เพราะค่า `OsString` แตกต่างกันไปในแต่ละแพลตฟอร์มและซับซ้อนต่อการใช้งานมากกว่าค่า `String`

ในบรรทัดแรกของ `main` เราเรียก `env::args` และเราใช้ `collect` ทันทีเพื่อแปลงอิเทอเรเตอร์เป็นเวกเตอร์ที่บรรจุค่าทั้งหมดที่อิเทอเรเตอร์ผลิตออกมา เราใช้ฟังก์ชัน `collect` เพื่อสร้างคอลเลกชันได้หลายชนิด เราจึงระบุชนิดของ `args` อย่างชัดแจ้งเพื่อบอกว่าเราต้องการเวกเตอร์ของสตริง แม้ว่าคุณแทบจะไม่ต้องระบุชนิดข้อมูลใน Rust เลย แต่ `collect` เป็นฟังก์ชันหนึ่งที่คุณมักต้องระบุบ่อย เพราะ Rust ไม่สามารถอนุมานชนิดของคอลเลกชันที่คุณต้องการได้
