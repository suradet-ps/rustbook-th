## ภาคผนวก B: ตัวดำเนินการและสัญลักษณ์

ภาคผนวกนี้รวบรวมอภิธานศัพท์ไวยากรณ์ (syntax) ของภาษา Rust ซึ่งครอบคลุมทั้งตัวดำเนินการ (operators) และสัญลักษณ์ (symbols) อื่น ๆ ที่ปรากฏแบบเดี่ยว ๆ หรือใช้ในบริบทของพาธ (paths), เจเนอริก (generics), ข้อกำหนดเทรต (trait bounds), มาโคร (macros), แอตทริบิวต์ (attributes), คอมเมนต์ (comments), ทูเพิล (tuples) และวงเล็บรูปแบบต่าง ๆ

### ตัวดำเนินการ

ตารางที่ B-1 รวบรวมตัวดำเนินการต่าง ๆ ใน Rust พร้อมตัวอย่างการใช้งานในบริบท คำอธิบายโดยสังเขป และระบุว่าตัวดำเนินการนั้นสามารถโอเวอร์โหลด (overload) ได้หรือไม่ หากสามารถโอเวอร์โหลดได้ จะระบุเทรตที่เกี่ยวข้องซึ่งใช้ในการโอเวอร์โหลดตัวดำเนินการดังกล่าวไว้ด้วย

### สัญลักษณ์ที่ไม่ใช่ตัวดำเนินการ

ตารางต่อไปนี้รวบรวมสัญลักษณ์ทั้งหมดที่ไม่ได้ทำหน้าที่เป็นตัวดำเนินการ กล่าวคือ สัญลักษณ์เหล่านี้ไม่ได้มีพฤติกรรมเสมือนการเรียกฟังก์ชันหรือเมธอด

ตารางที่ B-2 แสดงสัญลักษณ์ที่ปรากฏเดี่ยวๆ และใช้ได้ในหลากหลายตำแหน่ง

<span class="caption">ตารางที่ B-2: ไวยากรณ์แบบเดี่ยว</span>

| สัญลักษณ์ | คำอธิบาย |
| --- | --- |
| `'ident` | ช่วงอายุที่มีชื่อหรือป้ายกำกับของลูป |
| ตัวเลขที่ตามด้วย `u8`, `i32`, `f64`, `usize` และอื่นๆ ทันที | ลิเทอรัลตัวเลขที่มีชนิดข้อมูลระบุกำกับไว้ |
| `"..."` | สตริงลิเทอรัล |
| `r"..."`, `r#"..."#`, `r##"..."##` และอื่นๆ | สตริงลิเทอรัลแบบ raw โดยไม่มีการแปลง escape characters |
| `b"..."` | ไบต์สตริงลิเทอรัล; สร้างอาร์เรย์ของไบต์แทนสตริง |
| `br"..."`, `br#"..."#`, `br##"..."##` และอื่นๆ | ไบต์สตริงลิเทอรัลแบบ raw; การผสมผสานของสตริงลิเทอรัลแบบ raw และไบต์สตริงลิเทอรัล |
| `'...'` | อักขระลิเทอรัล |
| `b'...'` | ไบต์ลิเทอรัล ASCII |
| <code>&vert;...&vert; expr</code> | โคลเชอร์ |
| `!` | ชนิด bottom type ที่ว่างเปล่าเสมอสำหรับฟังก์ชันที่ไม่คืนค่ากลับ |
| `_` | การผูกค่าแพตเทิร์นแบบ “ไม่สนใจค่า”; ยังใช้คั่นตัวเลขจำนวนเต็มเพื่อให้อ่านง่ายขึ้น |

ตารางที่ B-3 แสดงสัญลักษณ์ที่ปรากฏในบริบทของพาธที่ลากผ่านลำดับชั้นของมอดูลไปยังไอเท็ม

<span class="caption">ตารางที่ B-3: ไวยากรณ์ที่เกี่ยวกับพาธ</span>

| สัญลักษณ์ | คำอธิบาย |
| --- | --- |
| `ident::ident` | พาธของเนมสเปซ |
| `::path` | พาธที่สัมพัทธ์กับรูทของเครต (พาธแบบสัมบูรณ์อย่างชัดเจน) |
| `self::path` | พาธที่สัมพัทธ์กับมอดูลปัจจุบัน (พาธแบบสัมพัทธ์อย่างชัดเจน) |
| `super::path` | พาธที่สัมพัทธ์กับมอดูลแม่ของมอดูลปัจจุบัน |
| `type::ident`, `<type as trait>::ident` | ค่าคงที่ ฟังก์ชัน และชนิดข้อมูลร่วม (associated items) |
| `<type>::...` | ไอเท็มร่วมของชนิดข้อมูลที่ไม่สามารถระบุชื่อได้โดยตรง (ตัวอย่างเช่น `<&T>::...`, `<[T]>::...` และอื่นๆ) |
| `trait::method(...)` | การแยกความกำกวมของการเรียกเมธอดโดยระบุชื่อเทรตที่นิยามเมธอดนั้น |
| `type::method(...)` | การแยกความกำกวมของการเรียกเมธอดโดยระบุชื่อชนิดข้อมูลที่นิยามเมธอดนั้น |
| `<type as trait>::method(...)` | การแยกความกำกวมของการเรียกเมธอดโดยระบุทั้งชื่อเทรตและชนิดข้อมูล |

ตารางที่ B-4 แสดงสัญลักษณ์ที่ปรากฏในบริบทของการใช้พารามิเตอร์ชนิดข้อมูลเจเนอริก

<span class="caption">ตารางที่ B-4: เจเนอริก</span>

| สัญลักษณ์ | คำอธิบาย |
| --- | --- |
| `path<...>` | ระบุพารามิเตอร์ให้กับชนิดเจเนอริกในชนิดข้อมูล (ตัวอย่างเช่น `Vec<u8>`) |
| `path::<...>`, `method::<...>` | ระบุพารามิเตอร์ให้กับชนิดเจเนอริก ฟังก์ชัน หรือเมธอดในนิพจน์; มักเรียกกันว่า _เทอร์โบฟิช_ (turbofish) (ตัวอย่างเช่น `"42".parse::<i32>()`) |
| `fn ident<...> ...` | นิยามฟังก์ชันเจเนอริก |
| `struct ident<...> ...` | นิยาม struct เจเนอริก |
| `enum ident<...> ...` | นิยาม enum เจเนอริก |
| `impl<...> ...` | นิยามการอิมพลีเมนต์เจเนอริก |
| `for<...> type` | ข้อกำหนดช่วงอายุแบบ higher-ranked (higher-ranked lifetime bounds) |
| `type<ident=type>` | ชนิดเจเนอริกที่กำหนดค่าเฉพาะให้กับชนิดข้อมูลร่วมหนึ่งตัวหรือมากกว่า (ตัวอย่างเช่น `Iterator<Item=T>`) |

ตารางที่ B-5 แสดงสัญลักษณ์ที่ปรากฏในบริบทของการจำกัดพารามิเตอร์ชนิดข้อมูลเจเนอริกด้วยข้อกำหนดเทรต

<span class="caption">ตารางที่ B-5: ข้อจำกัดจากข้อกำหนดเทรต</span>

| สัญลักษณ์ | คำอธิบาย |
| --- | --- |
| `T: U` | พารามิเตอร์เจเนอริก `T` ถูกจำกัดให้ใช้กับชนิดข้อมูลที่อิมพลีเมนต์เทรต `U` |
| `T: 'a` | ชนิดเจเนอริก `T` ต้องมีช่วงอายุยืนยาวกว่าช่วงอายุ `'a` (หมายความว่าชนิดข้อมูลนั้นต้องไม่มีการอ้างอิงที่มีช่วงอายุสั้นกว่า `'a` ปะปนอยู่ แม้โดยอ้อม) |
| `T: 'static` | ชนิดเจเนอริก `T` ต้องไม่มีการอ้างอิงที่ถูกยืมอื่นใดนอกจากที่เป็น `'static` |
| `'b: 'a` | ช่วงอายุเจเนอริก `'b` ต้องยืนยาวกว่าช่วงอายุ `'a` |
| `T: ?Sized` | ยินยอมให้พารามิเตอร์ชนิดข้อมูลเจเนอริกเป็นชนิดข้อมูลขนาดไม่คงที่ขณะคอมไพล์ได้ |
| `'a + trait`, `trait + trait` | ข้อกำหนดชนิดข้อมูลแบบผสม |

ตารางที่ B-10 แสดงบริบทที่มีการใช้วงเล็บเหลี่ยม

<span class="caption">ตารางที่ B-10: วงเล็บเหลี่ยม</span>

| บริบท | คำอธิบาย |
| --- | --- |
| `[...]` | ลิเทอรัลอาร์เรย์ |
| `[expr; len]` | ลิเทอรัลอาร์เรย์ที่บรรจุ `expr` ซ้ำกันจำนวน `len` ตัว |
| `[type; len]` | ชนิดข้อมูลอาร์เรย์ที่บรรจุสมาชิกชนิด `type` จำนวน `len` อินสแตนซ์ |
| `expr[expr]` | การเข้าถึงสมาชิกคอลเลกชันด้วยดัชนี; โอเวอร์โหลดได้ (`Index`, `IndexMut`) |
| `expr[..]`, `expr[a..]`, `expr[..b]`, `expr[a..b]` | การเข้าถึงสมาชิกคอลเลกชันในลักษณะการตัดสไลซ์ โดยใช้ `Range`, `RangeFrom`, `RangeTo` หรือ `RangeFull` เป็น “ดัชนี” |
