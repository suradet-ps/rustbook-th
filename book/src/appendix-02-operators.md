## ภาคผนวก B: ตัวดำเนินการและสัญลักษณ์

ภาคผนวกนี้ประกอบด้วยอภิธานศัพท์ของวากยสัมพันธ์ (syntax) ของ Rust ซึ่งรวมถึงตัวดำเนินการ (operator) และสัญลักษณ์ (symbol) อื่นๆ ที่ปรากฏเดี่ยวๆ หรือในบริบทของพาธ (path) เจเนอริก (generic) บาวด์ของเทรต (trait bound) มาโคร (macro) แอตทริบิวต์ (attribute) คอมเมนต์ (comment) ทูเพิล (tuple) และวงเล็บ

### ตัวดำเนินการ

ตารางที่ B-1 ประกอบด้วยตัวดำเนินการใน Rust ตัวอย่างการปรากฏของตัวดำเนินการในบริบท คำอธิบายสั้นๆ และระบุว่าตัวดำเนินการนั้นโอเวอร์โหลด (overload) ได้หรือไม่ หากตัวดำเนินการใดโอเวอร์โหลดได้ เทรตที่เกี่ยวข้องซึ่งใช้โอเวอร์โหลดตัวดำเนินการนั้นจะถูกระบุไว้

| ตัวดำเนินการ | ตัวอย่าง | คำอธิบาย | โอเวอร์โหลดได้หรือไม่ |
| --- | --- | --- | --- |

| `%=` | `var %= expr` | เศษจากการหารทางคณิตศาสตร์และการกำหนดค่า | `RemAssign` |
| `&` | `&expr`, `&mut expr` | การยืม | |
| `&` | `&type`, `&mut type`, `&'a type`, `&'a mut type` | ชนิดพอยน์เตอร์ที่ถูกยืม | |

| `-` | `- expr` | การทำให้เป็นลบทางคณิตศาสตร์ | `Neg` |
| `-` | `expr - expr` | การลบทางคณิตศาสตร์ | `Sub` |
| `-=` | `var -= expr` | การลบทางคณิตศาสตร์และการกำหนดค่า | `SubAssign` |
| `->` | `fn(...) -> type`, <code>&vert;...&vert; -> type</code> | ชนิดค่าที่คืนกลับของฟังก์ชันและโคลเชอร์ (closure) | |
| `.` | `expr.ident` | การเข้าถึงฟิลด์ | |
| `.` | `expr.ident(expr, ...)` | การเรียกเมธอด | |
| `.` | `expr.0`, `expr.1` และอื่นๆ | การจัดดัชนีทูเพิล | |
| `..` | `..`, `expr..`, `..expr`, `expr..expr` | ลิเทอรัลเรนจ์แบบไม่รวมขอบขวา | `PartialOrd` |
| `..=` | `..=expr`, `expr..=expr` | ลิเทอรัลเรนจ์แบบรวมขอบขวา | `PartialOrd` |
| `..` | `..expr` | วากยสัมพันธ์อัปเดตลิเทอรัล struct | |
| `..` | `variant(x, ..)`, `struct_type { x, .. }` | การผูกค่าแพตเทิร์นแบบ “และที่เหลือ” | |
| `...` | `expr...expr` | (เลิกใช้แล้ว ให้ใช้ `..=` แทน) ในแพตเทิร์น: แพตเทิร์นเรนจ์แบบรวมขอบเขต | |

| `;` | `expr;` | ตัวปิดท้ายสเตตเมนต์และรายการ | |

| `<<` | `expr << expr` | การเลื่อนบิตไปทางซ้าย | `Shl` |

| `<=` | `expr <= expr` | การเปรียบเทียบน้อยกว่าหรือเท่ากับ | `PartialOrd` |

| `>` | `expr > expr` | การเปรียบเทียบมากกว่า | `PartialOrd` |
| `>=` | `expr >= expr` | การเปรียบเทียบมากกว่าหรือเท่ากับ | `PartialOrd` |

### สัญลักษณ์ที่ไม่ใช่ตัวดำเนินการ

ตารางต่อไปนี้ประกอบด้วยสัญลักษณ์ทั้งหมดที่ไม่ได้ทำหน้าที่เป็นตัวดำเนินการ กล่าวคือ สัญลักษณ์เหล่านี้ไม่ได้ทำงานเหมือนการเรียกฟังก์ชันหรือเมธอด

ตารางที่ B-2 แสดงสัญลักษณ์ที่ปรากฏเดี่ยวๆ และใช้ได้ในตำแหน่งต่างๆ มากมาย

<span class="caption">ตารางที่ B-2: วากยสัมพันธ์แบบเดี่ยว</span>

| สัญลักษณ์ | คำอธิบาย |
| --- | --- |
| `'ident` | ไลฟ์ไทม์ที่มีชื่อหรือป้ายกำกับลูป |
| ตัวเลขที่ตามด้วย `u8`, `i32`, `f64`, `usize` และอื่นๆ ทันที | ลิเทอรัลตัวเลขที่มีชนิดเฉพาะ |
| `"..."` | สตริงลิเทอรัล |
| `r"..."`, `r#"..."#`, `r##"..."##` และอื่นๆ | สตริงลิเทอรัลแบบ raw; อักขระ escape ไม่ถูกประมวลผล |
| `b"..."` | ไบต์สตริงลิเทอรัล; สร้างอาร์เรย์ของไบต์แทนสตริง |
| `br"..."`, `br#"..."#`, `br##"..."##` และอื่นๆ | ไบต์สตริงลิเทอรัลแบบ raw; การผสมกันของสตริงลิเทอรัลแบบ raw และไบต์สตริงลิเทอรัล |
| `'...'` | อักขระลิเทอรัล |
| `b'...'` | ไบต์ลิเทอรัล ASCII |
| <code>&vert;...&vert; expr</code> | โคลเชอร์ |
| `!` | ชนิด bottom ที่ว่างเปล่าเสมอสำหรับฟังก์ชันที่ไม่คืนค่ากลับ |
| `_` | การผูกค่าแพตเทิร์นแบบ “ไม่สนใจ”; ยังใช้เพื่อทำให้ลิเทอรัลจำนวนเต็มอ่านง่ายขึ้น |

ตารางที่ B-3 แสดงสัญลักษณ์ที่ปรากฏในบริบทของพาธที่ลากผ่านลำดับชั้นของมอดูลไปยังรายการ

<span class="caption">ตารางที่ B-3: วากยสัมพันธ์ที่เกี่ยวกับพาธ</span>

| สัญลักษณ์ | คำอธิบาย |
| --- | --- |
| `ident::ident` | พาธของเนมสเปซ |
| `::path` | พาธที่สัมพัทธ์กับรากของเครต (นั่นคือ พาธแบบสัมบูรณ์อย่างชัดเจน) |
| `self::path` | พาธที่สัมพัทธ์กับมอดูลปัจจุบัน (นั่นคือ พาธแบบสัมพัทธ์อย่างชัดเจน) |
| `super::path` | พาธที่สัมพัทธ์กับมอดูลแม่ของมอดูลปัจจุบัน |
| `type::ident`, `<type as trait>::ident` | ค่าคงที่ ฟังก์ชัน และชนิดข้อมูลที่เชื่อมโยงกัน |
| `<type>::...` | รายการที่เชื่อมโยงกันของชนิดข้อมูลที่ไม่สามารถระบุชื่อได้โดยตรง (ตัวอย่างเช่น `<&T>::...`, `<[T]>::...` และอื่นๆ) |
| `trait::method(...)` | การแก้ความกำกวมของการเรียกเมธอดโดยระบุชื่อเทรตที่นิยามมัน |
| `type::method(...)` | การแก้ความกำกวมของการเรียกเมธอดโดยระบุชื่อชนิดข้อมูลที่มันถูกนิยาม |
| `<type as trait>::method(...)` | การแก้ความกำกวมของการเรียกเมธอดโดยระบุชื่อเทรตและชนิดข้อมูล |

ตารางที่ B-4 แสดงสัญลักษณ์ที่ปรากฏในบริบทของการใช้พารามิเตอร์ชนิดข้อมูลเจเนอริก

<span class="caption">ตารางที่ B-4: เจเนอริก</span>

| สัญลักษณ์ | คำอธิบาย |
| --- | --- |
| `path<...>` | ระบุพารามิเตอร์ให้กับชนิดเจเนอริกในชนิดข้อมูล (ตัวอย่างเช่น `Vec<u8>`) |
| `path::<...>`, `method::<...>` | ระบุพารามิเตอร์ให้กับชนิดเจเนอริก ฟังก์ชัน หรือเมธอดในเอ็กซ์เพรสชัน; มักถูกเรียกว่า _เทอร์โบฟิช_ (turbofish) (ตัวอย่างเช่น `"42".parse::<i32>()`) |
| `fn ident<...> ...` | นิยามฟังก์ชันเจเนอริก |
| `struct ident<...> ...` | นิยาม struct เจเนอริก |
| `enum ident<...> ...` | นิยาม enum เจเนอริก |
| `impl<...> ...` | นิยามการอิมพลีเมนต์เจเนอริก |
| `for<...> type` | บาวด์ของไลฟ์ไทม์แบบ higher-ranked |
| `type<ident=type>` | ชนิดเจเนอริกที่ชนิดข้อมูลที่เชื่อมโยงกันหนึ่งตัวหรือมากกว่าถูกกำหนดค่าเฉพาะเจาะจง (ตัวอย่างเช่น `Iterator<Item=T>`) |

ตารางที่ B-5 แสดงสัญลักษณ์ที่ปรากฏในบริบทของการจำกัดพารามิเตอร์ชนิดข้อมูลเจเนอริกด้วยบาวด์ของเทรต

<span class="caption">ตารางที่ B-5: ข้อจำกัดจากบาวด์ของเทรต</span>

| สัญลักษณ์ | คำอธิบาย |
| --- | --- |
| `T: U` | พารามิเตอร์เจเนอริก `T` ถูกจำกัดให้ใช้กับชนิดข้อมูลที่อิมพลีเมนต์ `U` |
| `T: 'a` | ชนิดเจเนอริก `T` ต้องมีไลฟ์ไทม์ยาวนานกว่าไลฟ์ไทม์ `'a` (หมายความว่าชนิดข้อมูลนั้นไม่สามารถมีเรเฟอเรนซ์ที่มีไลฟ์ไทม์สั้นกว่า `'a` ซ้อนอยู่ได้แม้โดยอ้อม) |
| `T: 'static` | ชนิดเจเนอริก `T` ไม่มีเรเฟอเรนซ์ที่ถูกยืมอื่นใดนอกจากที่เป็น `'static` |
| `'b: 'a` | ไลฟ์ไทม์เจเนอริก `'b` ต้องมีอายุยาวนานกว่าไลฟ์ไทม์ `'a` |
| `T: ?Sized` | อนุญาตให้พารามิเตอร์ชนิดข้อมูลเจเนอริกเป็นชนิดข้อมูลขนาดไม่คงที่ได้ |
| `'a + trait`, `trait + trait` | ข้อจำกัดชนิดคอมพาวด์ |

ตารางที่ B-10 แสดงบริบทที่มีการใช้วงเล็บเหลี่ยม

<span class="caption">ตารางที่ B-10: วงเล็บเหลี่ยม</span>

| บริบท | คำอธิบาย |
| --- | --- |
| `[...]` | ลิเทอรัลอาร์เรย์ |
| `[expr; len]` | ลิเทอรัลอาร์เรย์ที่บรรจุ `expr` จำนวน `len` สำเนา |
| `[type; len]` | ชนิดข้อมูลอาร์เรย์ที่บรรจุ `type` จำนวน `len` อินสแตนซ์ |
| `expr[expr]` | การจัดดัชนีคอลเลกชัน; โอเวอร์โหลดได้ (`Index`, `IndexMut`) |
| `expr[..]`, `expr[a..]`, `expr[..b]`, `expr[a..b]` | การจัดดัชนีคอลเลกชันที่ทำตัวเสมือนเป็นการสไลซ์คอลเลกชัน โดยใช้ `Range`, `RangeFrom`, `RangeTo` หรือ `RangeFull` เป็น “ดัชนี” |
