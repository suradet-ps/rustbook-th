ยินดีต้อนรับสู่ _The Rust Programming Language_ หนังสือแนะนำภาษา Rust ภาษาโปรแกรม Rust ช่วยให้คุณพัฒนาซอฟต์แวร์ได้อย่างรวดเร็วและเชื่อถือได้ยิ่งขึ้น โดยทั่วไปแล้ว ในการออกแบบภาษาโปรแกรม ความสะดวกในการใช้งานระดับสูงกับความสามารถในการควบคุมระดับล่างมักเป็นสิ่งที่ขัดแย้งกัน แต่ Rust ก้าวข้ามข้อจำกัดนั้น ด้วยการผสานสมดุลระหว่างขีดความสามารถทางเทคนิคอันทรงพลัง เข้ากับประสบการณ์การพัฒนาที่ยอดเยี่ยม Rust เปิดโอกาสให้คุณควบคุมรายละเอียดระดับล่างได้ตามต้องการ (เช่น การบริหารจัดการหน่วยความจำ) โดยไม่ต้องเผชิญกับความยุ่งยากซับซ้อนที่มักจะตามมา

## Rust เหมาะกับใคร

Rust เหมาะอย่างยิ่งสำหรับผู้คนหลากหลายกลุ่มด้วยเหตุผลที่แตกต่างกัน มาดูกลุ่มที่สำคัญที่สุดบางกลุ่มกัน:

### ทีมนักพัฒนา

Rust พิสูจน์แล้วว่าเป็นเครื่องมือที่ช่วยเพิ่มประสิทธิภาพการทำงานร่วมกันในทีมนักพัฒนาขนาดใหญ่ที่มีระดับความรู้ด้านการเขียนโปรแกรมระดับระบบ (systems programming) แตกต่างกัน โค้ดระดับล่างมักมีโอกาสเกิดบั๊กที่ตรวจพบได้ยาก ซึ่งในภาษาส่วนใหญ่ บั๊กเหล่านี้จะตรวจพบได้ก็ต่อเมื่อผ่านการทดสอบอย่างเข้มข้นและการตรวจทานโค้ดอย่างละเอียดโดยนักพัฒนาผู้เชี่ยวชาญเท่านั้น แต่ใน Rust คอมไพเลอร์จะทำหน้าที่เป็นปราการด่านสำคัญ คอยปฏิเสธการคอมไพล์โค้ดที่มีบั๊กแฝงเร้นเหล่านี้ รวมถึงบั๊กที่เกิดจากการทำงานพร้อมกัน (concurrency bugs) เมื่อมีคอมไพเลอร์คอยตรวจสอบ ทีมจึงสามารถทุ่มเทสมาธิไปกับตรรกะของโปรแกรมได้อย่างเต็มที่ แทนที่จะต้องเสียเวลาตามไล่ล่าหาบั๊ก

นอกจากนี้ Rust ยังนำเครื่องมือพัฒนาร่วมสมัยมาสู่โลกของการเขียนโปรแกรมระดับระบบ:

- Cargo ตัวจัดการดีเพนเดนซีและเครื่องมือบิลด์ที่ติดตั้งมาพร้อมกับ Rust ช่วยให้การเพิ่ม คอมไพล์ และจัดการดีเพนเดนซีเป็นไปอย่างง่ายดายและเป็นมาตรฐานเดียวกันทั่วทั้งระบบนิเวศของ Rust
- เครื่องมือจัดรูปแบบโค้ด `rustfmt` ช่วยดูแลให้สไตล์การเขียนโค้ดเป็นรูปแบบเดียวกันเสมอในทีมนักพัฒนา
- Rust Language Server ช่วยขับเคลื่อนการทำงานร่วมกับโปรแกรมแก้ไขโค้ดและสภาพแวดล้อมการพัฒนาแบบบูรณาการ (IDE) ทั้งการเติมโค้ดอัตโนมัติและการแสดงข้อผิดพลาดแบบอินไลน์

ด้วยการผสานเครื่องมือเหล่านี้และเครื่องมืออื่นๆ ในระบบนิเวศของ Rust นักพัฒนาจึงสามารถทำงานได้อย่างมีประสิทธิภาพสูงสุดแม้จะเขียนโค้ดระดับระบบก็ตาม

### นักเรียนและนักศึกษา

Rust เหมาะสำหรับนักเรียน นักศึกษา และผู้ที่สนใจศึกษาแนวคิดเชิงลึกเกี่ยวกับระบบ หลายคนใช้ Rust ในการศึกษาหัวข้ออย่างการพัฒนาระบบปฏิบัติการ ชุมชน Rust ยินดีต้อนรับและพร้อมให้คำแนะนำแก่นักเรียนนักศึกษาเสมอ ทีมงาน Rust มุ่งหวังที่จะทำให้แนวคิดเชิงระบบเข้าถึงผู้คนได้ง่ายขึ้นผ่านสื่อการเรียนรู้อย่างหนังสือเล่มนี้ โดยเฉพาะอย่างยิ่งสำหรับผู้ที่เพิ่งเริ่มต้นก้าวสู่วงการเขียนโปรแกรม

### องค์กรและภาคธุรกิจ

บริษัทหลายร้อยแห่งทั้งขนาดเล็กและใหญ่ต่างนำ Rust ไปใช้งานจริงในโปรดักชันสำหรับงานหลากหลายประเภท ไม่ว่าจะเป็นเครื่องมือบรรทัดคำสั่ง บริการเว็บ เครื่องมือ DevOps ระบบฝังตัว (embedded devices) การวิเคราะห์และแปลงรหัสเสียงและวิดีโอ สกุลเงินดิจิทัล ชีวสารสนเทศศาสตร์ เครื่องมือค้นหา แอปพลิเคชันอินเทอร์เน็ตของสรรพสิ่ง (IoT) การเรียนรู้ของเครื่อง (machine learning) และแม้กระทั่งส่วนประกอบหลักของเว็บเบราว์เซอร์ Firefox

### นักพัฒนาโอเพนซอร์ส

Rust เหมาะสำหรับผู้ที่ต้องการร่วมสร้างและพัฒนาภาษา Rust ชุมชน เครื่องมือนักพัฒนา ตลอดจนไลบรารีต่างๆ เรายินดีเป็นอย่างยิ่งหากคุณจะมาร่วมเป็นส่วนหนึ่งในการมีส่วนร่วมกับภาษา Rust

### ผู้ที่ต้องการความเร็วและความเสถียร

Rust เหมาะสำหรับผู้ที่ต้องการทั้งความเร็วและความเสถียรจากภาษาโปรแกรม โดยคำว่าความเร็วในที่นี้ หมายถึงทั้งความเร็วในการประมวลผลโค้ดของ Rust และความเร็วที่ Rust ช่วยให้คุณพัฒนาโปรแกรมได้สำเร็จ การตรวจสอบของคอมไพเลอร์ Rust ช่วยรักษาเสถียรภาพของระบบไว้ได้อย่างมั่นคง แม้จะมีการเพิ่มฟีเจอร์ใหม่หรือทำการรีแฟกเตอร์โค้ด ซึ่งแตกต่างจากโค้ดระบบเก่าที่เปราะบางในภาษาที่ขาดระบบตรวจสอบเหล่านี้ จนทำให้นักพัฒนามักไม่กล้าแตะต้องแก้ไข ด้วยเป้าหมายสู่การจัดการนามธรรมแบบไร้ต้นทุนโสหุ้ย (zero-cost abstractions) ซึ่งเป็นการนำฟีเจอร์ระดับสูงมาใช้งานโดยคอมไพล์ออกมาเป็นโค้ดระดับล่างที่ทำงานได้รวดเร็วเทียบเท่าโค้ดที่เขียนปรับแต่งด้วยมือ Rust จึงมุ่งมั่นทำให้โค้ดที่ปลอดภัยเป็นโค้ดที่เร็วควบคู่กันไปด้วย

ภาษา Rust ยังพร้อมสนับสนุนผู้ใช้กลุ่มอื่นๆ อีกมากมาย โดยกลุ่มที่กล่าวถึงข้างต้นเป็นเพียงตัวแทนส่วนหนึ่งเท่านั้น ความมุ่งหวังสูงสุดของ Rust คือการก้าวข้ามข้อแลกเปลี่ยนที่โปรแกรมเมอร์ยอมรับกันมานานหลายทศวรรษ ด้วยการมอบทั้งความปลอดภัย _และ_ ประสิทธิภาพการทำงาน ความเร็ว _และ_ ความสะดวกสบายในการพัฒนา ลองสัมผัส Rust ดู แล้วคุณจะพบว่าแนวทางของภาษานี้ตอบโจทย์คุณหรือไม่

## หนังสือเล่มนี้เหมาะกับใคร

หนังสือเล่มนี้เขียนขึ้นโดยสมมติว่าคุณเคยเขียนโค้ดภาษาใดภาษาหนึ่งมาก่อน แต่ไม่ได้จำกัดว่าต้องเป็นภาษาใด เราพยายามเรียบเรียงเนื้อหาให้ครอบคลุมและเข้าถึงง่ายสำหรับผู้ที่มีพื้นฐานการเขียนโปรแกรมที่หลากหลาย เราไม่ได้ใช้เวลาอธิบายว่าการเขียนโปรแกรม _คืออะไร_ หรือมีหลักคิดพื้นฐานอย่างไร หากคุณเพิ่งเริ่มต้นเรียนรู้การเขียนโปรแกรมเป็นครั้งแรก การเริ่มต้นด้วยหนังสือที่ปูพื้นฐานการเขียนโปรแกรมโดยตรงจะช่วยให้คุณเข้าใจได้ดียิ่งขึ้น

## วิธีใช้หนังสือเล่มนี้

โดยทั่วไป แนะนำให้อ่านหนังสือเล่มนี้เรียงลำดับตั้งแต่บทแรกไปจนจบ เนื่องจากบทหลังๆ จะต่อยอดจากแนวคิดในบทก่อนหน้า และบางหัวข้อในบทแรกๆ อาจยังไม่ได้ลงลึกในรายละเอียดทันที แต่จะย้อนกลับมาเจาะลึกอีกครั้งในบทต่อๆ ไป

คุณจะพบบทเรียน 2 รูปแบบในหนังสือเล่มนี้ ได้แก่ บทเชิงแนวคิด และบทเชิงโปรเจกต์ ในบทเชิงแนวคิด คุณจะได้เรียนรู้แง่มุมต่างๆ ของ Rust ส่วนในบทเชิงโปรเจกต์ เราจะลงมือสร้างโปรแกรมเล็กๆ ไปพร้อมกันเพื่อนำความรู้ที่ได้เรียนมาประยุกต์ใช้ โดยบทที่ 2, บทที่ 12 และบทที่ 21 เป็นบทเชิงโปรเจกต์ ส่วนบทที่เหลือจะเป็นบทเชิงแนวคิด

**บทที่ 1** อธิบายขั้นตอนการติดตั้ง Rust วิธีเขียนโปรแกรม "Hello, world!" ตลอดจนวิธีใช้ Cargo ซึ่งเป็นตัวจัดการแพ็กเกจและเครื่องมือบิลด์ของ Rust **บทที่ 2** เป็นการปูพื้นฐานการเขียนโปรแกรม Rust ผ่านการลงมือปฏิบัติจริง โดยสร้างโปรเจกต์เกมทายตัวเลข ซึ่งจะช่วยให้เห็นภาพรวมของแนวคิดต่างๆ ก่อนที่บทต่อๆ ไปจะลงรายละเอียดเพิ่มเติม หากคุณชื่นชอบการลงมือทำจริงทันที บทที่ 2 คือจุดเริ่มต้นที่เหมาะอย่างยิ่ง แต่หากคุณเป็นผู้ที่ชอบศึกษาทุกรายละเอียดให้แจ่มแจ้งก่อนไปต่อ คุณสามารถข้ามบทที่ 2 ไปเริ่มที่ **บทที่ 3** ซึ่งครอบคลุมฟีเจอร์พื้นฐานของ Rust ที่คล้ายคลึงกับภาษาโปรแกรมทั่วไป แล้วจึงค่อยย้อนกลับมาทำโปรเจกต์ในบทที่ 2 เมื่อต้องการนำรายละเอียดที่ได้เรียนรู้มาฝึกฝน

ใน**บทที่ 4** คุณจะได้เรียนรู้ระบบสิทธิ์ความเป็นเจ้าของ (ownership) ซึ่งเป็นหัวใจสำคัญของ Rust **บทที่ 5** อธิบาย struct และเมธอด **บทที่ 6** ครอบคลุม enum, นิพจน์ `match` ตลอดจนโครงสร้างควบคุมทิศทางการทำงาน `if let` และ `let...else` เพื่อใช้ struct และ enum ในการสร้างชนิดข้อมูลที่กำหนดขึ้นเอง

ใน**บทที่ 7** คุณจะได้เรียนรู้ระบบมอดูลของ Rust และกฎความเป็นส่วนตัวเพื่อจัดระเบียบโค้ดและส่วนต่อประสานโปรแกรมประยุกต์ (API) สาธารณะ **บทที่ 8** อธิบายโครงสร้างข้อมูลแบบคอลเลกชันทั่วไปที่ไลบรารีมาตรฐานจัดเตรียมไว้ให้ ได้แก่ เวกเตอร์ สตริง และแฮชแมป **บทที่ 9** สำรวจปรัชญาและเทคนิคการจัดการข้อผิดพลาดใน Rust

**บทที่ 10** เจาะลึกเจเนอริก เทรต และไลฟ์ไทม์ ซึ่งช่วยให้คุณเขียนโค้ดที่ยืดหยุ่นและรองรับชนิดข้อมูลได้หลากหลาย **บทที่ 11** มุ่งเน้นเรื่องการทดสอบอย่างครบวงจร ซึ่งแม้ Rust จะรับประกันความปลอดภัยของหน่วยความจำ แต่การทดสอบก็ยังจำเป็นเพื่อยืนยันความถูกต้องของตรรกะในโปรแกรม ใน**บทที่ 12** เราจะร่วมกันสร้างเครื่องมือค้นหาข้อความในไฟล์ โดยจำลองฟังก์ชันการทำงานบางส่วนของเครื่องมือบรรทัดคำสั่ง `grep` ซึ่งจะได้นำแนวคิดจากบทก่อนๆ มาประยุกต์ใช้อย่างเต็มที่

**บทที่ 13** สำรวจโคลเชอร์และอิเทอเรเตอร์ ซึ่งเป็นฟีเจอร์ทรงพลังของ Rust ที่ได้รับแรงบันดาลใจจากภาษาเชิงฟังก์ชัน ใน**บทที่ 14** เราจะเจาะลึก Cargo มากยิ่งขึ้น พร้อมแนะนำแนวปฏิบัติที่ดีที่สุดในการแบ่งปันไลบรารีของคุณให้ผู้อื่นใช้งาน **บทที่ 15** อธิบายสมาร์ตพอยน์เตอร์ในไลบรารีมาตรฐานและเทรตที่ช่วยขับเคลื่อนความสามารถของสมาร์ตพอยน์เตอร์เหล่านั้น

ใน**บทที่ 16** เราจะพาคุณสำรวจรูปแบบต่างๆ ของการเขียนโปรแกรมแบบทำงานพร้อมกัน (concurrency) และวิธีที่ Rust ช่วยให้คุณพัฒนาโปรแกรมแบบมัลติเธรดได้อย่างมั่นใจไร้กังวล ใน**บทที่ 17** เราจะต่อยอดด้วยการสำรวจไวยากรณ์ async และ await ของ Rust พร้อมทั้งทาสก์ ฟิวเจอร์ สตรีม ตลอดจนโมเดลการทำงานพร้อมกันแบบประหยัดทรัพยากร (lightweight concurrency)

**บทที่ 18** เปรียบเทียบสำนวนของ Rust กับหลักการเขียนโปรแกรมเชิงวัตถุที่คุณอาจคุ้นเคย **บทที่ 19** เป็นคู่มืออ้างอิงเกี่ยวกับรูปแบบและการจับคู่รูปแบบ (patterns and pattern matching) ซึ่งเป็นวิธีอันทรงพลังในการถ่ายทอดแนวคิดทั่วทั้งโปรแกรม Rust **บทที่ 20** รวบรวมหัวข้อขั้นสูงที่น่าสนใจมากมาย ไม่ว่าจะเป็น unsafe Rust, มาโคร รวมถึงเนื้อหาเชิงลึกเกี่ยวกับไลฟ์ไทม์ เทรต ชนิดข้อมูล ฟังก์ชัน และโคลเชอร์

ใน**บทที่ 21** เราจะลงมือทำโปรเจกต์ส่งท้าย โดยร่วมกันพัฒนาเว็บเซิร์ฟเวอร์แบบมัลติเธรดระดับล่างด้วยตนเอง!

สุดท้ายนี้ ส่วนภาคผนวกได้รวบรวมข้อมูลที่เป็นประโยชน์เกี่ยวกับภาษาไว้ในรูปแบบเอกสารอ้างอิง ได้แก่ **ภาคผนวก A** รวบรวมคำสงวนของ Rust, **ภาคผนวก B** รวบรวมตัวดำเนินการและสัญลักษณ์, **ภาคผนวก C** อธิบายเทรตที่ derive ได้ในไลบรารีมาตรฐาน, **ภาคผนวก D** แนะนำเครื่องมือพัฒนาที่มีประโยชน์ และ**ภาคผนวก E** อธิบายฉบับต่างๆ ของ Rust (editions) ส่วนใน**ภาคผนวก F** คุณจะพบข้อมูลฉบับแปลของหนังสือเล่มนี้ และใน**ภาคผนวก G** จะอธิบายกระบวนการพัฒนาภาษา Rust และทำความรู้จักกับ nightly Rust

ไม่มีวิธีใดที่ผิดในการอ่านหนังสือเล่มนี้: หากคุณต้องการข้ามไปอ่านบทที่สนใจก่อน ก็สามารถทำได้ทันที! คุณอาจเพียงแค่ต้องย้อนกลับมาเปิดดูบทก่อนหน้าเมื่อพบประเด็นที่สงสัย เลือกแนวทางที่เหมาะสมกับตัวคุณที่สุดได้เลย

<span id="ferris"></span>

สิ่งสำคัญอย่างยิ่งในการเรียนรู้ภาษา Rust คือการฝึกอ่านข้อความแจ้งข้อผิดพลาดที่คอมไพเลอร์แสดงออกมา เพราะข้อความเหล่านี้คือเข็มทิศนำทางคุณไปสู่โค้ดที่ถูกต้องและทำงานได้จริง ด้วยเหตุนี้ เราจึงได้เตรียมตัวอย่างโค้ดที่คอมไพล์ไม่ผ่านไว้มากมาย พร้อมข้อความข้อผิดพลาดที่คอมไพเลอร์จะแสดงในแต่ละสถานการณ์ โปรดทราบว่า หากคุณทดลองพิมพ์และรันตัวอย่างบางอัน ตัวอย่างนั้นอาจคอมไพล์ไม่ผ่านโดยตั้งใจ! อย่าลืมอ่านคำอธิบายประกอบรอบๆ ตัวอย่างเพื่อดูว่าโค้ดนั้นมีเจตนาให้เกิดข้อผิดพลาดหรือไม่ ซึ่งในเกือบทุกกรณี เราจะแนะนำโค้ดเวอร์ชันที่ถูกต้องตามมาเสมอ นอกจากนี้ เจ้าปู Ferris ยังจะช่วยส่งสัญญาณบอกใบ้เกี่ยวกับพฤติกรรมของโค้ดให้คุณสังเกตได้ง่ายขึ้น:
