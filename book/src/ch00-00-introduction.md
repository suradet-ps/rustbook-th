ยินดีต้อนรับสู่ _The Rust Programming Language_ หนังสือแนะนำภาษา Rust ภาษาโปรแกรม Rust ช่วยให้คุณเขียนซอฟต์แวร์ได้เร็วขึ้นและเชื่อถือได้มากขึ้น โดยทั่วไปแล้ว ความสะดวกในการใช้งานระดับสูงกับความสามารถในการควบคุมระดับต่ำมักขัดแย้งกันในการออกแบบภาษาโปรแกรม แต่ Rust ท้าทายความขัดแย้งนั้น ด้วยการสร้างสมดุลระหว่างขีดความสามารถทางเทคนิคอันทรงพลังกับประสบการณ์ที่ดีเยี่ยมสำหรับนักพัฒนา Rust เปิดโอกาสให้คุณควบคุมรายละเอียดระดับต่ำได้ (เช่น การใช้หน่วยความจำ) โดยไม่ต้องพบกับความยุ่งยากที่มักมาพร้อมกับการควบคุมเช่นนั้น

## Rust เหมาะกับใคร

Rust เหมาะอย่างยิ่งกับผู้คนหลากหลายกลุ่มด้วยเหตุผลที่แตกต่างกัน มาดูกลุ่มที่สำคัญที่สุดบางกลุ่มกัน

### ทีมนักพัฒนา

Rust พิสูจน์แล้วว่าเป็นเครื่องมือที่เพิ่มผลิตภาพสำหรับการทำงานร่วมกันในทีมนักพัฒนาขนาดใหญ่ที่มีระดับความรู้ด้านการเขียนโปรแกรมระดับระบบแตกต่างกัน โค้ดระดับต่ำมีแนวโน้มที่จะเกิดบั๊กที่หาตัวจับยากหลากหลายรูปแบบ ซึ่งในภาษาส่วนใหญ่ บั๊กเหล่านั้นจะถูกจับได้ก็ต่อเมื่อผ่านการทดสอบอย่างละเอียดและการรีวิวโค้ดอย่างรอบคอบโดยนักพัฒนาที่มีประสบการณ์เท่านั้น ใน Rust คอมไพเลอร์ทำหน้าที่เป็นผู้เฝ้าประตู คอยปฏิเสธที่จะคอมไพล์โค้ดที่มีบั๊กจับยากเหล่านี้ รวมถึงบั๊กที่เกิดจากการทำงานพร้อมกัน เมื่อทำงานร่วมกับคอมไพเลอร์ ทีมจึงสามารถใช้เวลาไปกับการจดจ่อที่ตรรกะของโปรแกรม แทนที่จะไล่ล่าหาบั๊ก

Rust ยังนำเครื่องมือนักพัฒนาสมัยใหม่มาสู่โลกของการเขียนโปรแกรมระดับระบบ:

- Cargo ตัวจัดการดีเพนเดนซีและเครื่องมือบิลด์ที่มาพร้อมกับ Rust ทำให้การเพิ่ม คอมไพล์ และจัดการดีเพนเดนซีเป็นเรื่องง่ายและสม่ำเสมอทั่วทั้งระบบนิเวศของ Rust
- เครื่องมือจัดรูปแบบ `rustfmt` ช่วยให้สไตล์การเขียนโค้ดเป็นแบบเดียวกันในหมู่นักพัฒนา
- Rust Language Server ขับเคลื่อนการทำงานร่วมกับสภาพแวดล้อมการพัฒนาแบบบูรณาการ (IDE) สำหรับการเติมโค้ดอัตโนมัติและข้อความแสดงข้อผิดพลาดแบบอินไลน์

ด้วยการใช้เครื่องมือเหล่านี้และเครื่องมืออื่นๆ ในระบบนิเวศของ Rust นักพัฒนาจึงมีผลิตภาพสูงขณะเขียนโค้ดระดับระบบ

### นักเรียนนักศึกษา

Rust เหมาะกับนักเรียนนักศึกษาและผู้ที่สนใจเรียนรู้แนวคิดเกี่ยวกับระบบ หลายคนใช้ Rust เรียนรู้หัวข้ออย่างการพัฒนาระบบปฏิบัติการ ชุมชนของ Rust ยินดีต้อนรับและพร้อมตอบคำถามของนักเรียนนักศึกษาเสมอ ผ่านความพยายามอย่างหนังสือเล่มนี้ ทีมงาน Rust ต้องการทำให้แนวคิดเกี่ยวกับระบบเข้าถึงผู้คนได้มากขึ้น โดยเฉพาะผู้ที่เพิ่งเริ่มเขียนโปรแกรม

### บริษัทต่างๆ

บริษัทหลายร้อยแห่งทั้งขนาดใหญ่และเล็กใช้ Rust ในการผลิตจริงสำหรับงานหลากหลายประเภท รวมถึงเครื่องมือบรรทัดคำสั่ง บริการเว็บ เครื่องมือ DevOps อุปกรณ์ฝังตัว การวิเคราะห์และแปลงรหัสเสียงและวิดีโอ คริปโตเคอร์เรนซี ชีวสารสนเทศศาสตร์ เครื่องมือค้นหา แอปพลิเคชันอินเทอร์เน็ตของสรรพสิ่ง การเรียนรู้ของเครื่อง และแม้กระทั่งส่วนสำคัญๆ ของเว็บเบราว์เซอร์ Firefox

### นักพัฒนาโอเพนซอร์ส

Rust เหมาะกับผู้ที่ต้องการสร้างภาษาโปรแกรม Rust ชุมชน เครื่องมือนักพัฒนา และไลบรารี เรายินดีอย่างยิ่งหากคุณมาร่วมสมทบกับภาษา Rust

### ผู้ที่ให้ความสำคัญกับความเร็วและความเสถียร

Rust เหมาะกับผู้ที่โหยหาความเร็วและความเสถียรในภาษาโปรแกรม คำว่าความเร็วในที่นี้หมายถึงทั้งความเร็วในการรันโค้ด Rust และความเร็วที่ Rust ช่วยให้คุณเขียนโปรแกรมได้ การตรวจสอบของคอมไพเลอร์ Rust ช่วยรักษาเสถียรภาพแม้จะมีการเพิ่มฟีเจอร์หรือรีแฟกเตอร์โค้ด ซึ่งต่างจากโค้ดเก่าที่เปราะบางในภาษาที่ไม่มีการตรวจสอบเหล่านี้ ที่นักพัฒนามักไม่กล้าแก้ไข ด้วยการมุ่งสู่การนามธรรมแบบไม่มีค่าใช้จ่ายเพิ่ม (zero-cost abstractions) ซึ่งเป็นฟีเจอร์ระดับสูงที่คอมไพล์ออกมาเป็นโค้ดระดับต่ำที่เร็วพอๆ กับโค้ดที่เขียนขึ้นเองด้วยมือ Rust จึงพยายามทำให้โค้ดที่ปลอดภัยเป็นโค้ดที่เร็วด้วยเช่นกัน

ภาษา Rust ยังหวังที่จะสนับสนุนผู้ใช้กลุ่มอื่นๆ อีกมากมาย ผู้ที่กล่าวถึงในที่นี้เป็นเพียงกลุ่มผู้มีส่วนได้ส่วนเสียที่ใหญ่ที่สุดบางส่วนเท่านั้น โดยรวมแล้ว ความทะเยอทะยานสูงสุดของ Rust คือการขจัดข้อแลกเปลี่ยนที่โปรแกรมเมอร์ยอมรับกันมานานหลายทศวรรษ ด้วยการมอบทั้งความปลอดภัย _และ_ ผลิตภาพ ความเร็ว _และ_ ความสะดวกในการใช้งาน ลองใช้ Rust ดูสิ แล้วคุณจะรู้ว่าทางเลือกของมันเหมาะกับคุณหรือไม่

## หนังสือเล่มนี้เหมาะกับใคร

หนังสือเล่มนี้สมมติว่าคุณเคยเขียนโค้ดในภาษาโปรแกรมอื่นมาบ้าง แต่ไม่ได้ตั้งสมมติฐานว่าเป็นภาษาใด เราพยายามทำให้เนื้อหานี้เข้าถึงได้กว้างขวางสำหรับผู้คนที่มีพื้นฐานการเขียนโปรแกรมหลากหลายรูปแบบ เราไม่ได้ใช้เวลามากนักในการพูดถึงว่าการเขียนโปรแกรม _คืออะไร_ หรือควรคิดเกี่ยวกับมันอย่างไร หากคุณเป็นผู้เริ่มต้นเขียนโปรแกรมโดยสิ้นเชิง การอ่านหนังสือที่ให้ความรู้เบื้องต้นเกี่ยวกับการเขียนโปรแกรมโดยเฉพาะจะให้ประโยชน์กับคุณมากกว่า

## วิธีใช้หนังสือเล่มนี้

โดยทั่วไป หนังสือเล่มนี้สมมติว่าคุณอ่านเรียงลำดับจากหน้าแรกไปจนจบ บทหลังๆ ต่อยอดจากแนวคิดในบทก่อนๆ และบทก่อนๆ อาจไม่ลงรายละเอียดของหัวข้อใดหัวข้อหนึ่ง แต่จะกลับมาพูดถึงหัวข้อนั้นอีกครั้งในบทหลัง

คุณจะพบบทอยู่สองประเภทในหนังสือเล่มนี้ คือบทแนวคิดและบทโปรเจกต์ ในบทแนวคิด คุณจะได้เรียนรู้แง่มุมต่างๆ ของ Rust ส่วนในบทโปรเจกต์ เราจะสร้างโปรแกรมเล็กๆ ด้วยกัน โดยนำสิ่งที่คุณเรียนรู้มาประยุกต์ใช้ บทที่ 2 บทที่ 12 และบทที่ 21 เป็นบทโปรเจกต์ ส่วนบทที่เหลือเป็นบทแนวคิด

**บทที่ 1** อธิบายวิธีการติดตั้ง Rust วิธีเขียนโปรแกรม "Hello, world!" และวิธีใช้ Cargo ตัวจัดการแพ็กเกจและเครื่องมือบิลด์ของ Rust **บทที่ 2** เป็นการแนะนำการเขียนโปรแกรมด้วย Rust แบบลงมือทำ โดยให้คุณสร้างเกมทายตัวเลขขึ้นมา ในบทนี้ เราจะพูดถึงแนวคิดต่างๆ ในระดับภาพรวม และบทหลังๆ จะให้รายละเอียดเพิ่มเติม หากคุณอยากลงมือเขียนทันที บทที่ 2 คือจุดที่ควรเริ่ม หากคุณเป็นผู้เรียนที่พิถีพิถันเป็นพิเศษและชอบเรียนรู้ทุกรายละเอียดก่อนจะไปต่อ คุณอาจข้ามบทที่ 2 ไปเริ่มที่ **บทที่ 3** ซึ่งครอบคลุมฟีเจอร์ของ Rust ที่คล้ายคลึงกับภาษาโปรแกรมอื่นๆ จากนั้นจึงค่อยกลับมาที่บทที่ 2 เมื่อคุณอยากลงมือทำโปรเจกต์โดยใช้รายละเอียดที่ได้เรียนมา

ใน**บทที่ 4** คุณจะได้เรียนรู้เกี่ยวกับระบบความเป็นเจ้าของของ Rust **บทที่ 5** กล่าวถึง struct และเมธอด **บทที่ 6** ครอบคลุม enum เอ็กซ์เพรสชัน `match` และโครงสร้างควบคุมโฟลว์ `if let` กับ `let...else` คุณจะใช้ struct และ enum เพื่อสร้างชนิดข้อมูลกำหนดเอง

ใน**บทที่ 7** คุณจะได้เรียนรู้เกี่ยวกับระบบมอดูลของ Rust และกฎความเป็นส่วนตัวสำหรับจัดระเบียบโค้ดกับส่วนติดต่อโปรแกรม (API) สาธารณะ **บทที่ 8** กล่าวถึงโครงสร้างข้อมูลแบบคอลเลกชันที่ใช้บ่อยซึ่งไลบรารีมาตรฐานมีให้ ได้แก่ เวกเตอร์ สตริง และแฮชแมป **บทที่ 9** สำรวจปรัชญาและเทคนิคการจัดการข้อผิดพลาดของ Rust

**บทที่ 10** เจาะลึกเจเนอริก เทรต และไลฟ์ไทม์ ซึ่งให้พลังแก่คุณในการนิยามโค้ดที่ใช้ได้กับหลายชนิดข้อมูล **บทที่ 11** ว่าด้วยเรื่องการทดสอบทั้งหมด ซึ่งแม้ Rust จะมีการรับประกันความปลอดภัย แต่การทดสอบก็ยังจำเป็นเพื่อให้แน่ใจว่าตรรกะของโปรแกรมถูกต้อง ใน**บทที่ 12** เราจะสร้างอิมพลีเมนต์ของเราเองสำหรับชุดฟังก์ชันบางส่วนจากเครื่องมือบรรทัดคำสั่ง `grep` ที่ใช้ค้นหาข้อความภายในไฟล์ สำหรับโปรเจกต์นี้ เราจะใช้แนวคิดหลายอย่างที่พูดคุยกันในบทก่อนๆ

**บทที่ 13** สำรวจโคลเชอร์และอิเทอเรเตอร์ ซึ่งเป็นฟีเจอร์ของ Rust ที่มาจากภาษาการเขียนโปรแกรมเชิงฟังก์ชัน ใน**บทที่ 14** เราจะพิจารณา Cargo อย่างลึกซึ้งยิ่งขึ้น และพูดถึงแนวปฏิบัติที่ดีที่สุดในการแบ่งปันไลบรารีของคุณให้ผู้อื่น **บทที่ 15** กล่าวถึงสมาร์ตพอยน์เตอร์ที่ไลบรารีมาตรฐานมีให้ และเทรตที่ทำให้มันทำงานได้

ใน**บทที่ 16** เราจะเดินสำรวจโมเดลต่างๆ ของการเขียนโปรแกรมแบบทำงานพร้อมกัน และพูดถึงวิธีที่ Rust ช่วยให้คุณเขียนโปรแกรมแบบหลายเธรดได้อย่างไม่ต้องกลัว ใน**บทที่ 17** เราจะต่อยอดจากบทที่แล้วด้วยการสำรวจวากยสัมพันธ์ async และ await ของ Rust พร้อมทั้งทาสก์ ฟิวเจอร์ และสตรีม ตลอดจนโมเดลการทำงานพร้อมกันแบบน้ำหนักเบาที่พวกมันทำให้เกิดขึ้น

**บทที่ 18** พิจารณาว่าสำนวนของ Rust เปรียบเทียบกับหลักการเขียนโปรแกรมเชิงวัตถุที่คุณอาจคุ้นเคยได้อย่างไร **บทที่ 19** เป็นเอกสารอ้างอิงเกี่ยวกับแพตเทิร์นและการจับคู่แพตเทิร์น ซึ่งเป็นวิธีอันทรงพลังในการถ่ายทอดแนวคิดทั่วทั้งโปรแกรม Rust **บทที่ 20** อัดแน่นด้วยหัวข้อขั้นสูงที่น่าสนใจมากมาย รวมถึง unsafe Rust มาโคร และเรื่องเพิ่มเติมเกี่ยวกับไลฟ์ไทม์ เทรต ชนิดข้อมูล ฟังก์ชัน และโคลเชอร์

ใน**บทที่ 21** เราจะทำโปรเจกต์ให้สำเร็จ โดยเราจะอิมพลีเมนต์เว็บเซิร์ฟเวอร์แบบหลายเธรดระดับต่ำด้วยตัวเอง!

สุดท้ายนี้ ภาคผนวกบางส่วนรวบรวมข้อมูลที่เป็นประโยชน์เกี่ยวกับภาษาไว้ในรูปแบบที่คล้ายเอกสารอ้างอิง **ภาคผนวก A** ครอบคลุมคำสงวนของ Rust **ภาคผนวก B** ครอบคลุมตัวดำเนินการและสัญลักษณ์ของ Rust **ภาคผนวก C** ครอบคลุมเทรตที่ derive ได้ซึ่งไลบรารีมาตรฐานมีให้ **ภาคผนวก D** ครอบคลุมเครื่องมือพัฒนาที่มีประโยชน์บางอย่าง และ**ภาคผนวก E** อธิบายฉบับของ Rust (editions) ใน**ภาคผนวก F** คุณจะพบคำแปลของหนังสือเล่มนี้ และใน**ภาคผนวก G** เราจะพูดถึงว่า Rust ถูกสร้างขึ้นมาอย่างไร และ nightly Rust คืออะไร

ไม่มีการอ่านหนังสือเล่มนี้แบบไหนที่ผิด: หากคุณอยากข้ามไปข้างหน้า ก็ทำได้เลย! คุณอาจต้องย้อนกลับไปอ่านบทก่อนๆ หากรู้สึกสับสน แต่จะทำวิธีไหนก็ได้ที่ได้ผลสำหรับคุณ

<span id="ferris"></span>

ส่วนสำคัญอย่างหนึ่งของกระบวนการเรียนรู้ Rust คือการฝึกอ่านข้อความแสดงข้อผิดพลาดที่คอมไพเลอร์แสดงออกมา เพราะข้อความเหล่านี้จะนำทางคุณไปสู่โค้ดที่ใช้งานได้ ด้วยเหตุนี้ เราจึงมีตัวอย่างจำนวนมากที่คอมไพล์ไม่ผ่าน พร้อมกับข้อความแสดงข้อผิดพลาดที่คอมไพเลอร์จะแสดงในแต่ละกรณี โปรดทราบว่า หากคุณนำตัวอย่างใดตัวอย่างหนึ่งไปป้อนและรัน มันอาจคอมไพล์ไม่ผ่านก็ได้! อย่าลืมอ่านข้อความรอบๆ ตัวอย่าง เพื่อดูว่าตัวอย่างที่คุณกำลังลองรันนั้นตั้งใจให้เกิดข้อผิดพลาดหรือไม่ ในสถานการณ์ส่วนใหญ่ เราจะพาคุณไปสู่โค้ดเวอร์ชันที่ถูกต้องของทุกตัวอย่างที่คอมไพล์ไม่ผ่าน Ferris ยังช่วยให้คุณแยกแยะโค้ดที่ไม่ได้ตั้งใจให้ทำงานได้ด้วย:
