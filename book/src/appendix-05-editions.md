## ภาคผนวก E: ฉบับของ Rust

ในบทที่ 1 คุณได้เห็นว่า `cargo new` เพิ่มเมทาดาทาเล็กน้อยเกี่ยวกับฉบับ (edition) ลงในไฟล์ _Cargo.toml_ ของคุณ ภาคผนวกนี้จะพูดถึงว่าสิ่งนั้นหมายความว่าอย่างไร!

ภาษา Rust และคอมไพเลอร์ (compiler) มีรอบการเผยแพร่ทุกหกสัปดาห์ หมายความว่าผู้ใช้จะได้รับกระแสของฟีเจอร์ใหม่ๆ อย่างต่อเนื่อง ภาษาการเขียนโปรแกรมอื่นๆ เผยแพร่การเปลี่ยนแปลงครั้งใหญ่กว่าในความถี่ที่น้อยกว่า ส่วน Rust เผยแพร่การอัปเดตที่เล็กกว่าในความถี่ที่มากกว่า เมื่อเวลาผ่านไป การเปลี่ยนแปลงเล็กๆ น้อยๆ เหล่านี้ก็รวมกันเข้าจนมีนัยสำคัญ แต่เมื่อเทียบการเผยแพร่แต่ละครั้ง การมองย้อนกลับไปแล้วพูดว่า “ว้าว ระหว่าง Rust 1.10 กับ Rust 1.31 Rust เปลี่ยนแปลงไปเยอะมาก!” อาจเป็นเรื่องยาก

ประมาณทุกสามปี ทีม Rust จะผลิต_ฉบับ_ใหม่ของ Rust แต่ละฉบับรวบรวมฟีเจอร์ที่ได้ลงสู่ระบบแล้วเข้าเป็นแพ็กเกจที่ชัดเจน พร้อมเอกสารประกอบและเครื่องมือที่อัปเดตครบถ้วน ฉบับใหม่ๆ ถูกเผยแพร่เป็นส่วนหนึ่งของกระบวนการเผยแพร่ทุกหกสัปดาห์ตามปกติ

ฉบับต่างๆ มีจุดประสงค์ที่แตกต่างกันสำหรับผู้คนที่แตกต่างกัน:

- สำหรับผู้ใช้ Rust ที่ใช้งานอยู่ ฉบับใหม่จะรวบรวมการเปลี่ยนแปลงทีละเล็กทีละน้อยเข้าเป็นแพ็กเกจที่เข้าใจง่าย
- สำหรับผู้ที่ยังไม่ใช้งาน ฉบับใหม่เป็นสัญญาณว่ามีความก้าวหน้าครั้งสำคัญบางอย่างได้ลงสู่ระบบแล้ว ซึ่งอาจทำให้ Rust น่าลองดูอีกครั้ง
- สำหรับผู้ที่พัฒนา Rust เอง ฉบับใหม่เป็นจุดรวมพลังให้กับโปรเจกต์โดยรวม

ณ เวลาที่เขียนนี้ มี Rust อยู่สี่ฉบับที่ใช้งานได้: Rust 2015, Rust 2018, Rust 2021 และ Rust 2024 หนังสือเล่มนี้เขียนขึ้นโดยใช้สำนวนของ Rust ฉบับ 2024

คีย์ `edition` ใน _Cargo.toml_ ระบุว่าคอมไพเลอร์ควรใช้ฉบับใดกับโค้ดของคุณ หากไม่มีคีย์นี้ Rust จะใช้ `2015` เป็นค่าฉบับด้วยเหตุผลด้านความเข้ากันได้ย้อนหลัง

แต่ละโปรเจกต์สามารถเลือกใช้ฉบับอื่นนอกเหนือจากฉบับ 2015 ที่เป็นค่าเริ่มต้นได้ ฉบับต่างๆ อาจมีการเปลี่ยนแปลงที่ไม่เข้ากันได้ เช่น การเพิ่มคำสงวน (keyword) ใหม่ที่ขัดแย้งกับชื่อเรียก (identifier) ในโค้ด อย่างไรก็ตาม หากคุณไม่เลือกเปิดใช้การเปลี่ยนแปลงเหล่านั้น โค้ดของคุณจะยังคงคอมไพล์ผ่านต่อไปแม้คุณจะอัปเกรดเวอร์ชันคอมไพเลอร์ Rust ที่ใช้อยู่

คอมไพเลอร์ Rust ทุกเวอร์ชันรองรับฉบับใดก็ตามที่มีอยู่ก่อนการเผยแพร่ของคอมไพเลอร์เวอร์ชันนั้น และสามารถลิงก์เครต (crate) ของฉบับใดก็ได้ที่รองรับเข้าด้วยกันได้ การเปลี่ยนแปลงของฉบับมีผลเพียงวิธีที่คอมไพเลอร์แยกวิเคราะห์โค้ดในตอนแรกเท่านั้น ดังนั้น หากคุณใช้ Rust 2015 และดีเพนเดนซี (dependency) ตัวหนึ่งของคุณใช้ Rust 2018 โปรเจกต์ของคุณจะคอมไพล์ผ่านและใช้ดีเพนเดนซีนั้นได้ กรณีตรงกันข้ามที่โปรเจกต์ของคุณใช้ Rust 2018 และดีเพนเดนซีใช้ Rust 2015 ก็ใช้งานได้เช่นกัน

เพื่อความชัดเจน: ฟีเจอร์ส่วนใหญ่จะใช้ได้ในทุกฉบับ นักพัฒนาที่ใช้ Rust ฉบับใดก็ตามจะยังคงเห็นการปรับปรุงต่างๆ เมื่อมีการเผยแพร่เวอร์ชันเสถียรใหม่ๆ อย่างไรก็ตาม ในบางกรณี โดยเฉพาะเมื่อมีการเพิ่มคำสงวนใหม่ ฟีเจอร์ใหม่บางอย่างอาจใช้ได้เฉพาะในฉบับหลังๆ เท่านั้น คุณจะต้องสลับฉบับหากคุณต้องการใช้ประโยชน์จากฟีเจอร์ดังกล่าว

สำหรับรายละเอียดเพิ่มเติม โปรดดู[_The Rust Edition Guide_][edition-guide] นี่คือหนังสือฉบับสมบูรณ์ที่แจกแจงความแตกต่างระหว่างฉบับต่างๆ และอธิบายวิธีอัปเกรดโค้ดของคุณไปยังฉบับใหม่โดยอัตโนมัติผ่าน `cargo fix`
