# เริ่มต้นใช้งาน

มาเริ่มต้นการเดินทางสู่โลกของ Rust กันเลย! ยังมีสิ่งใหม่ๆ ให้เรียนรู้อีกมากมาย แต่ทุกการเดินทางย่อมมีจุดเริ่มต้นเสมอ ในบทนี้ เราจะเรียนรู้เกี่ยวกับ:

- การติดตั้ง Rust บน Linux, macOS และ Windows
- การเขียนโปรแกรมแสดงข้อความ `Hello, world!`
- การใช้งาน `cargo` ตัวจัดการแพ็กเกจและระบบบิลด์ของ Rust
