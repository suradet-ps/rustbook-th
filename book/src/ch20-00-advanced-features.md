# ฟีเจอร์ขั้นสูง

ตอนนี้ คุณได้เรียนรู้ส่วนที่ใช้บ่อยที่สุดของภาษาการเขียนโปรแกรม Rust แล้ว ก่อนที่เราจะทำโปรเจกต์อีกหนึ่งโปรเจกต์ในบทที่ 21 เราจะดูแง่มุมบางประการของภาษาที่คุณอาจพบเจอเป็นครั้งคราวแต่คุณอาจไม่ได้ใช้ทุกวัน คุณสามารถใช้บทนี้เป็นข้อมูลอ้างอิงเมื่อคุณพบเจอสิ่งที่ยังไม่รู้จัก ฟีเจอร์ที่ครอบคลุมในที่นี้มีประโยชน์ในสถานการณ์ที่เฉพาะเจาะจงมาก แม้ว่าคุณอาจไม่ค่อยหยิบมาใช้บ่อยนัก เราก็อยากทำให้แน่ใจว่าคุณเข้าใจฟีเจอร์ทั้งหมดที่ Rust มีให้

ในบทนี้ เราจะครอบคลุม:

- Unsafe Rust: วิธีเลือกงดเว้นจากการรับประกันบางประการของ Rust และรับผิดชอบในการรักษาการรับประกันเหล่านั้นด้วยตัวเอง
- เทรต (trait) ขั้นสูง: ชนิดข้อมูลที่เชื่อมโยง (associated type) พารามิเตอร์ชนิดข้อมูลเริ่มต้น (default type parameter) วากยสัมพันธ์แบบเต็มรูปแบบ (fully qualified syntax) ซูเปอร์เทรต (supertrait) และแพตเทิร์นนิวไทป์ (newtype pattern) ที่เกี่ยวข้องกับเทรต
- ชนิดข้อมูลขั้นสูง: เพิ่มเติมเกี่ยวกับแพตเทิร์นนิวไทป์ นามแฝงชนิดข้อมูล (type alias) ชนิดข้อมูล never (never type) และชนิดข้อมูลที่มีขนาดเปลี่ยนแปลงได้ (dynamically sized type)
- ฟังก์ชันและโคลเชอร์ (closure) ขั้นสูง: พอยน์เตอร์ฟังก์ชัน (function pointer) และการคืนค่าโคลเชอร์
- มาโคร (macro): วิธีนิยามโค้ดที่นิยามโค้ดเพิ่มเติมในตอนคอมไพล์

เป็นชุดฟีเจอร์ Rust อันหลากหลายที่มีบางอย่างสำหรับทุกคน! มาดำดิ่งกันเลย!
