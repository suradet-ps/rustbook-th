# ฟีเจอร์ขั้นสูง

ถึงตอนนี้ คุณได้เรียนรู้ส่วนที่ใช้งานบ่อยที่สุดของภาษาโปรแกรม Rust ไปแล้ว ก่อนที่เราจะลงมือทำโปรเจกต์ส่งท้ายอีกหนึ่งโปรเจกต์ในบทที่ 21 เราจะมาสำรวจแง่มุมบางประการของภาษาที่คุณอาจได้พบเจอเป็นครั้งคราว แต่อาจไม่ได้หยิบมาใช้งานในชีวิตประจำวันทุกวัน คุณสามารถใช้บทนี้เป็นคู่มืออ้างอิงเมื่อพบเจอสิ่งที่ไม่คุ้นเคย โดยฟีเจอร์ที่เราจะกล่าวถึงในบทนี้มีประโยชน์อย่างยิ่งในสถานการณ์เฉพาะเจาะจง แม้คุณอาจไม่ได้ใช้งานบ่อยนัก แต่เราก็อยากให้คุณมีความเข้าใจและคุ้นเคยกับฟีเจอร์ทั้งหมดที่ Rust มีให้

ในบทนี้ เราจะครอบคลุมหัวข้อต่าง ๆ ดังนี้:

- Unsafe Rust: วิธีเลือกปิดการรับประกันความปลอดภัยบางประการของ Rust และรับหน้าที่ดูแลความปลอดภัยเหล่านั้นด้วยตัวเอง
- เทรต (trait) ขั้นสูง: ชนิดข้อมูลที่เชื่อมโยง (associated type), พารามิเตอร์ชนิดข้อมูลเริ่มต้น (default type parameter), ไวยากรณ์แบบระบุชื่อเต็ม (fully qualified syntax), ซูเปอร์เทรต (supertrait) และรูปแบบนิวไทป์ (newtype pattern) ที่เกี่ยวข้องกับเทรต
- ชนิดข้อมูลขั้นสูง: เจาะลึกเพิ่มเติมเกี่ยวกับรูปแบบนิวไทป์, นามแฝงชนิดข้อมูล (type alias), ชนิดข้อมูล never (never type) และชนิดข้อมูลที่กำหนดขนาดแบบไดนามิก (dynamically sized types)
- ฟังก์ชันและโคลเชอร์ (closure) ขั้นสูง: พอยน์เตอร์ฟังก์ชัน (function pointer) และการคืนค่าโคลเชอร์จากฟังก์ชัน
- มาโคร (macro): วิธีการเขียนโค้ดเพื่อสร้างโค้ดอื่นเพิ่มเติมในขณะคอมไพล์

บทนี้รวบรวมฟีเจอร์อันทรงพลังมากมายของ Rust ที่มีประโยชน์สำหรับทุกคน มาเริ่มลุยกันเลย!
