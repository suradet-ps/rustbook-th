## ติดตั้งไบนารีด้วย `cargo install`

คำสั่ง `cargo install` ช่วยให้คุณสามารถติดตั้งและเรียกใช้งานเครตไบนารี (binary crate) บนเครื่องของคุณได้ เป้าหมายของคำสั่งนี้ไม่ได้มีไว้เพื่อแทนที่ตัวจัดการแพ็กเกจของระบบปฏิบัติการ แต่มันเป็นวิธีที่สะดวกสบายสำหรับนักพัฒนา Rust ในการติดตั้งเครื่องมือต่าง ๆ ที่มีผู้อื่นแบ่งปันไว้บน [crates.io](https://crates.io/)<!-- ignore --> โปรดสังเกตว่าคุณจะสามารถติดตั้งได้เฉพาะแพ็กเกจที่มีเป้าหมายเป็นไบนารี (binary target) เท่านั้น โดย _ไบนารีทาร์เก็ต (binary target)_ คือโปรแกรมที่สามารถรันได้ ซึ่งจะถูกสร้างขึ้นเมื่อเครตมีไฟล์ _src/main.rs_ หรือไฟล์อื่นที่กำหนดไว้ให้เป็นไบนารี ซึ่งต่างจากไลบรารีทาร์เก็ต (library target) ที่ไม่สามารถรันแยกเดี่ยวได้ด้วยตนเอง แต่เหมาะสำหรับการนำไปรวมไว้ในโปรแกรมอื่น ๆ โดยปกติแล้วแต่ละเครตจะมีข้อมูลในไฟล์ README ที่ระบุไว้ชัดเจนว่าเครตนั้นเป็นไลบรารี, มีไบนารีทาร์เก็ต หรือมีทั้งสองอย่าง

ไบนารีทั้งหมดที่ติดตั้งผ่าน `cargo install` จะถูกเก็บไว้ในโฟลเดอร์ _bin_ ภายใต้ไดเรกทอรีรากของการติดตั้ง (installation root) หากคุณติดตั้ง Rust โดยใช้ _rustup.rs_ และไม่ได้ปรับแต่งการตั้งค่าใด ๆ เป็นพิเศษ ไดเรกทอรีนี้จะอยู่ที่ *$HOME/.cargo/bin* โปรดตรวจสอบให้แน่ใจว่าไดเรกทอรีดังกล่าวถูกเพิ่มไว้ในตัวแปรสภาพแวดล้อม `$PATH` ของคุณแล้ว เพื่อให้สามารถเรียกใช้โปรแกรมที่คุณติดตั้งผ่าน `cargo install` ได้จากทุกที่

ตัวอย่างเช่น ในบทที่ 12 เราได้กล่าวถึงเครื่องมือค้นหาข้อความในไฟล์ที่เขียนด้วย Rust เพื่อเลียนแบบเครื่องมือ `grep` ซึ่งมีชื่อว่า `ripgrep` ในการติดตั้ง `ripgrep` เราสามารถรันคำสั่งต่อไปนี้:

บรรทัดรองสุดท้ายของเอาต์พุตจะแสดงตำแหน่งและชื่อของไฟล์ไบนารีที่ติดตั้ง ซึ่งในกรณีของ `ripgrep` ก็คือคำสั่ง `rg` ตราบใดที่ไดเรกทอรีติดตั้งถูกรวมไว้ใน `$PATH` ของคุณแล้วตามที่กล่าวไปก่อนหน้านี้ คุณก็สามารถรันคำสั่ง `rg --help` และเริ่มใช้งานเครื่องมือค้นหาไฟล์ที่รวดเร็วและมีความเป็น Rust ยิ่งกว่าได้ทันที!
