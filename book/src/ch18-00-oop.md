# ฟีเจอร์การเขียนโปรแกรมเชิงวัตถุ

<!-- Old headings. Do not remove or links may break. -->

<a id="object-oriented-programming-features-of-rust"></a>

การเขียนโปรแกรมเชิงวัตถุ (object-oriented programming หรือ OOP) เป็นกระบวนทัศน์หนึ่งในการจำลองและสร้างแบบจำลองของโปรแกรม แนวคิดเรื่องออบเจกต์ (object) ในการเขียนโปรแกรมถูกนำมาใช้ครั้งแรกในภาษา Simula ในช่วงทศวรรษ 1960 แนวคิดออบเจกต์เหล่านั้นมีอิทธิพลต่อสถาปัตยกรรมการเขียนโปรแกรมของ Alan Kay ซึ่งออบเจกต์จะส่งข้อความถึงกันและกัน และเพื่ออธิบายสถาปัตยกรรมนี้ เขาจึงได้บัญญัติคำว่า _การเขียนโปรแกรมเชิงวัตถุ_ ขึ้นในปี 1967 มีคำนิยามที่หลากหลายและแตกต่างกันไปว่า OOP คืออะไร ซึ่งหากมองตามคำนิยามบางข้อ Rust ก็ถือเป็นภาษาเชิงวัตถุ แต่หากมองตามคำนิยามอื่นๆ ก็อาจจะไม่ใช่ ในบทนี้ เราจะสำรวจคุณลักษณะบางประการที่มักถูกพิจารณาว่าเป็นเชิงวัตถุ และดูว่าคุณลักษณะเหล่านั้นถ่ายทอดมาเป็นแนวทางตามธรรมเนียมปฏิบัติ (idiomatic) ของ Rust อย่างไร จากนั้นเราจะแสดงวิธีอิมพลีเมนต์แพตเทิร์นการออกแบบเชิงวัตถุใน Rust พร้อมทั้งร่วมพูดคุยถึงข้อแลกเปลี่ยน (trade-offs) ของการเลือกใช้วิธีดังกล่าว เทียบกับการแก้ปัญหาโดยใช้จุดแข็งเฉพาะตัวของ Rust แทน
