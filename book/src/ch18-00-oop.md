# ฟีเจอร์การเขียนโปรแกรมเชิงวัตถุ

<!-- Old headings. Do not remove or links may break. -->

<a id="object-oriented-programming-features-of-rust"></a>

การเขียนโปรแกรมเชิงวัตถุ (object-oriented programming หรือ OOP) เป็นวิธีหนึ่งในการจำลองโปรแกรม ออบเจกต์ (object) ในฐานะแนวคิดเชิงการเขียนโปรแกรมถูกนำเข้ามาในภาษา Simula ในทศวรรษ 1960 ออบเจกต์เหล่านั้นมีอิทธิพลต่อสถาปัตยกรรมการเขียนโปรแกรมของ Alan Kay ซึ่งออบเจกต์ส่งข้อความถึงกันและกัน เพื่ออธิบายสถาปัตยกรรมนี้ เขาจึงบัญญัติคำว่า _การเขียนโปรแกรมเชิงวัตถุ_ ขึ้นในปี 1967 คำนิยามมากมายที่แข่งขันกันอธิบายว่าการเขียนโปรแกรมเชิงวัตถุคืออะไร และตามคำนิยามบางข้อ Rust เป็นภาษาเชิงวัตถุ แต่ตามคำนิยามอื่นๆ มันไม่ใช่ ในบทนี้ เราจะสำรวจคุณลักษณะบางประการที่มักถูกมองว่าเป็นเชิงวัตถุ และวิธีที่คุณลักษณะเหล่านั้นถ่ายทอดมาเป็น Rust ในสำนวนของ Rust จากนั้นเราจะแสดงวิธีอิมพลีเมนต์แพตเทิร์นการออกแบบเชิงวัตถุใน Rust และอภิปรายข้อแลกเปลี่ยน (trade-off) ของการทำเช่นนั้น เทียบกับการอิมพลีเมนต์วิธีแก้ปัญหาโดยใช้จุดแข็งบางประการของ Rust แทน
