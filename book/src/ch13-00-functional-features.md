# ฟีเจอร์ภาษาเชิงฟังก์ชัน: อิเทอเรเตอร์และโคลเชอร์

การออกแบบของภาษา Rust ได้รับแรงบันดาลใจมาจากภาษาและเทคนิคมากมายที่มีอยู่ก่อนหน้า และหนึ่งในอิทธิพลที่สำคัญอย่างยิ่งก็คือ _การเขียนโปรแกรมเชิงฟังก์ชัน_ (functional programming) ซึ่งการเขียนโปรแกรมในสไตล์เชิงฟังก์ชันนี้ มักจะรวมถึงการปฏิบัติต่อฟังก์ชันในฐานะที่เป็นค่าของข้อมูล เช่น การส่งฟังก์ชันเป็นอาร์กิวเมนต์, การส่งคืนฟังก์ชันกลับมาจากฟังก์ชันอื่น, การกำหนดฟังก์ชันให้กับตัวแปรเพื่อเรียกใช้งานในภายหลัง และอื่น ๆ

ในบทนี้ เราจะไม่ถกเถียงกันในประเด็นเชิงทฤษฎีว่าอะไรคือหรือไม่คือการเขียนโปรแกรมเชิงฟังก์ชัน แต่เราจะมาพูดคุยกันถึงฟีเจอร์ต่าง ๆ ใน Rust ที่มีลักษณะคล้ายคลึงกับฟีเจอร์ในภาษาอื่น ๆ ที่มักถูกจัดว่าเป็นภาษาเชิงฟังก์ชันแทน

โดยเฉพาะอย่างยิ่ง เราจะเรียนรู้เกี่ยวกับเรื่องต่อไปนี้:

- _โคลเชอร์_ (closures) โครงสร้างที่มีลักษณะการทำงานคล้ายฟังก์ชันซึ่งคุณสามารถนำไปเก็บไว้ในตัวแปรได้
- _อิเทอเรเตอร์_ (iterators) เครื่องมือสำหรับวนลูปประมวลผลลำดับของชุดข้อมูล
- วิธีการนำโคลเชอร์และอิเทอเรเตอร์มาใช้ปรับปรุงโปรเจกต์ I/O จากบทที่ 12
- ประสิทธิภาพของโคลเชอร์และอิเทอเรเตอร์ (แอบสปอยล์ไว้ก่อนเลยว่า: มันทำงานได้เร็วกว่าที่คุณคิดไว้แน่นอน!)

เราได้เรียนรู้ฟีเจอร์อื่น ๆ ของ Rust กันไปแล้ว เช่น การจับคู่แพตเทิร์น (pattern matching) และ enum ซึ่งต่างก็ได้รับอิทธิพลมาจากสไตล์เชิงฟังก์ชันเช่นเดียวกัน และเนื่องจากการทำความเข้าใจโคลเชอร์และอิเทอเรเตอร์อย่างเชี่ยวชาญนั้นเป็นหัวใจสำคัญของการเขียนโค้ด Rust ให้ทำงานได้รวดเร็วและเป็นไปตามสำนวนของภาษา (idiomatic) เราจึงขออุทิศเนื้อหาตลอดทั้งบทนี้ให้กับหัวข้อดังกล่าวโดยเฉพาะ
