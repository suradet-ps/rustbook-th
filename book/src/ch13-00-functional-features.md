# ฟีเจอร์ภาษาเชิงฟังก์ชัน: อิเทอเรเตอร์และโคลเชอร์

การออกแบบของ Rust ได้รับแรงบันดาลใจจากภาษาและเทคนิคที่มีอยู่มากมาย และอิทธิพลสำคัญอย่างหนึ่งคือ_การเขียนโปรแกรมเชิงฟังก์ชัน_ (functional programming) การเขียนโปรแกรมในสไตล์เชิงฟังก์ชันมักรวมถึงการใช้ฟังก์ชันเป็นค่า โดยส่งมันเป็นอาร์กิวเมนต์ คืนมันจากฟังก์ชันอื่น กำหนดมันให้กับตัวแปรเพื่อเรียกใช้ในภายหลัง และอื่นๆ

ในบทนี้ เราจะไม่โต้เถียงประเด็นว่าอะไรคือการเขียนโปรแกรมเชิงฟังก์ชันและอะไรไม่ใช่ แต่จะพูดคุยถึงฟีเจอร์บางอย่างของ Rust ที่คล้ายกับฟีเจอร์ในหลายภาษาที่มักถูกเรียกว่าเป็นภาษาเชิงฟังก์ชันแทน

เจาะจงยิ่งกว่านั้น เราจะครอบคลุม:

- _โคลเชอร์_ (closure) โครงสร้างที่คล้ายฟังก์ชันซึ่งคุณเก็บไว้ในตัวแปรได้
- _อิเทอเรเตอร์_ (iterator) วิธีประมวลผลลำดับของสมาชิก
- วิธีใช้โคลเชอร์และอิเทอเรเตอร์เพื่อปรับปรุงโปรเจกต์ I/O ในบทที่ 12
- ประสิทธิภาพของโคลเชอร์และอิเทอเรเตอร์ (คำเตือนสปอยล์: มันเร็วกว่าที่คุณอาจคิด!)

เราได้ครอบคลุมฟีเจอร์อื่นๆ ของ Rust ไปแล้ว เช่น การจับคู่แพตเทิร์นและ enum ซึ่งได้รับอิทธิพลจากสไตล์เชิงฟังก์ชันเช่นกัน เพราะการเชี่ยวชาญโคลเชอร์และอิเทอเรเตอร์เป็นส่วนสำคัญของการเขียนโค้ด Rust ที่รวดเร็วและเป็นสำนวน เราจึงอุทิศบทนี้ทั้งบทให้กับมัน
