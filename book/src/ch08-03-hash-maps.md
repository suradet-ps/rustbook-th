## เก็บคีย์พร้อมค่าที่เชื่อมโยงกันในแฮชแมป

คอลเลกชันพื้นฐานตัวสุดท้ายที่เราจะพูดถึงคือ *แฮชแมป (hash map)* โดยประเภท `HashMap<K, V>` จะเก็บการจับคู่ระหว่างคีย์ประเภท `K` กับค่าประเภท `V` โดยอาศัย *ฟังก์ชันแฮช (hashing function)* ซึ่งเป็นตัวกำหนดวิธีการจัดวางคีย์และค่าเหล่านี้ลงในหน่วยความจำ ภาษาโปรแกรมหลายภาษารองรับโครงสร้างข้อมูลแบบนี้ แต่มักเรียกด้วยชื่อที่ต่างกันไป เช่น *hash*, *map*, *object*, *hash table*, *dictionary* หรือ *associative array*

แฮชแมปมีประโยชน์เมื่อคุณต้องการค้นหาข้อมูลด้วยคีย์ (ซึ่งเป็นประเภทข้อมูลใดก็ได้) แทนที่จะค้นหาด้วยดัชนีเหมือนกับเวกเตอร์ ตัวอย่างเช่น ในเกม คุณสามารถใช้แฮชแมปเก็บคะแนนของแต่ละทีม โดยใช้ชื่อทีมเป็นคีย์ และคะแนนของทีมนั้นเป็นค่า เพียงแค่ระบุชื่อทีม คุณก็สามารถดึงคะแนนของทีมดังกล่าวออกมาได้ทันที

ในหัวข้อนี้เราจะแนะนำ API พื้นฐานของแฮชแมป แต่ยังมีฟังก์ชันและลูกเล่นอีกมากมายที่ไลบรารีมาตรฐานนิยามไว้สำหรับ `HashMap<K, V>` ซึ่งคุณสามารถดูรายละเอียดเพิ่มเติมได้จากเอกสารประกอบของไลบรารีมาตรฐานเช่นเคย

#### การเพิ่มคีย์และค่าเฉพาะเมื่อยังไม่มีคีย์นั้น

การตรวจสอบว่าคีย์ใดคีย์หนึ่งมีอยู่ในแฮชแมปพร้อมกับค่าอยู่แล้วหรือไม่ แล้วดำเนินการตามเงื่อนไขต่อไปนี้ถือเป็นกรณีที่พบได้บ่อย: ถ้าคีย์นั้นมีอยู่ในแฮชแมปอยู่แล้ว ก็ให้คงค่าเดิมไว้เช่นนั้น แต่ถ้ายังไม่มีคีย์นั้นอยู่ ให้แทรกคีย์และค่าใหม่เข้าไป

แฮชแมปมี API พิเศษสำหรับงานนี้โดยเฉพาะชื่อว่า `entry` ซึ่งรับคีย์ที่คุณต้องการตรวจสอบเป็นพารามิเตอร์ ค่าที่ส่งกลับจากเมธอด `entry` คือ enum ชื่อ `Entry` ซึ่งเป็นตัวแทนของค่าที่อาจจะมีอยู่หรือไม่มีอยู่ก็ได้ สมมติว่าเราต้องการตรวจสอบว่าคีย์ของทีม Yellow มีค่าผูกอยู่แล้วหรือไม่ ถ้ายังไม่มี เราต้องการแทรกค่า `50` เข้าไป และทำแบบเดียวกันนี้กับทีม Blue เมื่อใช้ API `entry` โค้ดจะเขียนได้ดังลิสติ้ง 8-24

เมธอด `split_whitespace` จะคืนค่าเป็นตัววนซ้ำ (iterator) บนสับสไลซ์ที่ถูกคั่นด้วยช่องว่างของข้อความใน `text` ส่วนเมธอด `or_insert` จะคืนค่าเป็นเรเฟอเรนซ์แบบเปลี่ยนแปลงได้ (`&mut V`) ไปยังค่าของคีย์ที่ระบุ ในที่นี้เราจัดเก็บเรเฟอเรนซ์แบบเปลี่ยนแปลงได้ดังกล่าวไว้ในตัวแปร `count` ดังนั้นหากต้องการกำหนดค่าใหม่ให้กับค่านั้น เราจะต้องดีเรเฟอเรนซ์ (dereference) `count` โดยใช้เครื่องหมายดอกจัน (`*`) เสียก่อน และเรเฟอเรนซ์แบบเปลี่ยนแปลงได้นี้จะหลุดออกจากขอบเขตเมื่อจบลูป `for` แต่ละรอบ การแก้ไขค่าทั้งหมดนี้จึงปลอดภัยและถูกต้องตามกฎการยืมทุกประการ

### ฟังก์ชันแฮช

โดยค่าเริ่มต้น `HashMap` จะใช้ฟังก์ชันแฮชที่ชื่อว่า *SipHash* ซึ่งมีความสามารถในการป้องกันการโจมตีแบบปฏิเสธการให้บริการ (denial-of-service หรือ DoS) ที่พุ่งเป้าไปที่ตารางแฮช[^siphash]<!-- ignore --> แม้นี่จะไม่ใช่อัลกอริทึมการแฮชที่เร็วที่สุด แต่ข้อแลกเปลี่ยนในเรื่องความปลอดภัยที่เพิ่มขึ้นเพื่อแลกกับประสิทธิภาพที่ลดลงเล็กน้อยนั้นถือว่าคุ้มค่า หากคุณทำโพรไฟล์ (profile) โค้ดแล้วพบว่าฟังก์ชันแฮชเริ่มต้นนี้ทำงานช้าเกินไปสำหรับความต้องการของคุณ คุณสามารถสลับไปใช้ฟังก์ชันอื่นได้โดยการระบุแฮชเชอร์ (hasher) ตัวอื่น โดย *แฮชเชอร์* คือประเภทข้อมูลที่อิมพลีเมนต์เทรต `BuildHasher` ซึ่งเราจะพูดถึงเทรตและวิธีอิมพลีเมนต์เทรตใน [บทที่ 10][traits]<!-- ignore --> และคุณไม่จำเป็นต้องเขียนแฮชเชอร์ขึ้นมาเองตั้งแต่ต้นเสมอไป เพราะบน [crates.io](https://crates.io/)<!-- ignore --> มีไลบรารีที่ชุมชนผู้ใช้ Rust ร่วมกันแบ่งปัน ซึ่งมีแฮชเชอร์ที่อิมพลีเมนต์อัลกอริทึมแฮชยอดนิยมต่างๆ ไว้อย่างครบถ้วน

[^siphash]: [https://en.wikipedia.org/wiki/SipHash](https://en.wikipedia.org/wiki/SipHash)

## สรุป

เวกเตอร์, สตริง และแฮชแมปช่วยมอบความสามารถมากมายที่จำเป็นสำหรับโปรแกรมเวลาที่คุณต้องจัดเก็บ เข้าถึง และแก้ไขข้อมูล ต่อไปนี้คือแบบฝึกหัดที่คุณน่าจะพร้อมลงมือทำได้แล้วในตอนนี้:

1. กำหนดรายการของจำนวนเต็มมาให้ ให้ใช้เวกเตอร์ในการหาและส่งคืนค่ามัธยฐาน (median ซึ่งเมื่อเรียงลำดับแล้วคือค่าที่อยู่ตำแหน่งกึ่งกลาง) และฐานนิยม (mode ซึ่งเป็นค่าที่ปรากฏบ่อยที่สุด โดยแฮชแมปจะมีประโยชน์มากในส่วนนี้) ของรายการนั้น
1. แปลงข้อความสตริงเป็นภาษาพิกละติน (Pig Latin) โดยพยัญชนะตัวแรกของแต่ละคำจะถูกย้ายไปไว้ท้ายคำแล้วต่อท้ายด้วย *-ay* ดังนั้นคำว่า *first* จะกลายเป็น *irst-fay* ส่วนคำที่ขึ้นต้นด้วยสระ ให้เติม *-hay* ต่อท้ายแทน (เช่น *apple* จะกลายเป็น *apple-hay*) และอย่าลืมคำนึงถึงรายละเอียดเกี่ยวกับการเข้ารหัส UTF-8 ด้วย!
1. ใช้แฮชแมปและเวกเตอร์เพื่อสร้างอินเทอร์เฟซแบบข้อความที่อนุญาตให้ผู้ใช้เพิ่มชื่อพนักงานเข้าสู่แผนกต่างๆ ของบริษัทได้ เช่น “Add Sally to Engineering” หรือ “Add Amir to Sales” จากนั้นเปิดให้ผู้ใช้สามารถเรียกดูรายชื่อพนักงานทั้งหมดในแผนกใดแผนกหนึ่ง หรือพนักงานทุกคนในบริษัทโดยจัดกลุ่มตามแผนก และเรียงลำดับตามตัวอักษร

เอกสาร API ของไลบรารีมาตรฐานมีคำอธิบายเมธอดต่างๆ ของเวกเตอร์ สตริง และแฮชแมป ซึ่งจะเป็นประโยชน์อย่างยิ่งสำหรับแบบฝึกหัดเหล่านี้!

จากนี้ไปเรากำลังจะก้าวเข้าสู่การเขียนโปรแกรมที่มีความซับซ้อนยิ่งขึ้น ซึ่งการทำงานต่างๆ อาจเกิดข้อผิดพลาดขึ้นได้ ดังนั้นจึงเป็นจังหวะที่เหมาะสมที่สุดที่เราจะมาพูดคุยกันถึงเรื่องการจัดการข้อผิดพลาด (error handling) ในบทถัดไป!
