## เก็บคีย์พร้อมค่าที่เชื่อมโยงกันในแฮชแมป

คอลเลกชัน (collection) ที่ใช้บ่อยตัวสุดท้ายของเราคือแฮชแมป (hash map) ชนิด `HashMap<K, V>` จัดเก็บการเชื่อมโยงของคีย์ (key) ชนิด `K` ไปยังค่า (value) ชนิด `V` โดยใช้_ฟังก์ชันแฮช_ (hashing function) ซึ่งเป็นตัวกำหนดว่ามันวางคีย์และค่าเหล่านี้ลงในหน่วยความจำอย่างไร ภาษาโปรแกรมหลายภาษารองรับโครงสร้างข้อมูลชนิดนี้ แต่พวกมันมักใช้ชื่อที่แตกต่างออกไป เช่น _hash_, _map_, _object_, _hash table_, _dictionary_ หรือ _associative array_ เป็นต้น

แฮชแมปมีประโยชน์เมื่อคุณต้องการค้นหาข้อมูลโดยไม่ใช้ดัชนีอย่างที่ทำได้กับเวกเตอร์ (vector) แต่ใช้คีย์ซึ่งสามารถเป็นชนิดใดก็ได้ ตัวอย่างเช่น ในเกม คุณสามารถติดตามคะแนนของแต่ละทีมในแฮชแมป โดยแต่ละคีย์คือชื่อของทีมและค่าคือคะแนนของแต่ละทีม เมื่อกำหนดชื่อทีม คุณก็สามารถดึงคะแนนของทีมนั้นได้

เราจะพูดถึง API พื้นฐานของแฮชแมปในหัวข้อนี้ แต่ยังมีของดีอีกมากมายที่ซ่อนอยู่ในฟังก์ชันที่ไลบรารีมาตรฐานนิยามไว้บน `HashMap<K, V>` เช่นเคย ดูเอกสารประกอบของไลบรารีมาตรฐานเพื่อข้อมูลเพิ่มเติม

#### การเพิ่มคีย์และค่าเฉพาะเมื่อยังไม่มีคีย์นั้น

เป็นเรื่องปกติที่จะตรวจสอบว่าคีย์ใดคีย์หนึ่งมีอยู่ในแฮชแมปพร้อมค่าอยู่แล้วหรือไม่ แล้วดำเนินการดังต่อไปนี้: หากคีย์นั้นมีอยู่ในแฮชแมปอยู่แล้ว ค่าที่มีอยู่ควรคงไว้เหมือนเดิม; หากคีย์นั้นไม่มีอยู่ ให้แทรกคีย์นั้นและค่าสำหรับมัน

### ฟังก์ชันแฮช

โดยค่าเริ่มต้น `HashMap` ใช้ฟังก์ชันแฮชชื่อ _SipHash_ ที่สามารถต้านทานการโจมตีแบบปฏิเสธการให้บริการ (denial-of-service หรือ DoS) ที่เกี่ยวข้องกับตารางแฮช[^siphash]<!-- ignore --> นี่ไม่ใช่อัลกอริทึมแฮชที่เร็วที่สุดที่มีอยู่ แต่การแลกเปลี่ยนเพื่อความปลอดภัยที่ดีขึ้นซึ่งมาพร้อมกับประสิทธิภาพที่ลดลงนั้นคุ้มค่า หากคุณโปรไฟล์โค้ดของคุณแล้วพบว่าฟังก์ชันแฮชเริ่มต้นช้าเกินไปสำหรับจุดประสงค์ของคุณ คุณสามารถเปลี่ยนไปใช้ฟังก์ชันอื่นได้โดยระบุแฮชเชอร์ (hasher) ที่แตกต่างออกไป _แฮชเชอร์_ คือชนิดที่อิมพลีเมนต์เทรต `BuildHasher` เราจะพูดถึงเทรตและวิธีอิมพลีเมนต์เทรตเหล่านั้นใน[บทที่ 10][traits]<!-- ignore --> คุณไม่จำเป็นต้องอิมพลีเมนต์แฮชเชอร์ของคุณเองตั้งแต่ต้นก็ได้ [crates.io](https://crates.io/)<!-- ignore --> มีไลบรารีที่ผู้ใช้ Rust คนอื่นๆ แบ่งปันไว้ซึ่งจัดเตรียมแฮชเชอร์ที่อิมพลีเมนต์อัลกอริทึมแฮชที่พบได้ทั่วไปมากมาย

[^siphash]: [https://en.wikipedia.org/wiki/SipHash](https://en.wikipedia.org/wiki/SipHash)

## สรุป

เวกเตอร์ สตริง และแฮชแมปจะมอบฟังก์ชันการทำงานจำนวนมากที่จำเป็นในโปรแกรมเมื่อคุณต้องจัดเก็บ เข้าถึง และแก้ไขข้อมูล ต่อไปนี้คือแบบฝึกหัดที่ตอนนี้คุณควรมีความพร้อมที่จะแก้แล้ว:

1. จากรายการของจำนวนเต็ม ให้ใช้เวกเตอร์และคืนค่ามัธยฐาน (เมื่อเรียงลำดับแล้ว คือค่าที่อยู่ตรงตำแหน่งกลาง) และฐานนิยม (ค่าที่ปรากฏบ่อยที่สุด; แฮชแมปจะช่วยได้ในกรณีนี้) ของรายการนั้น
1. แปลงสตริงเป็นภาษาพิก (Pig Latin) พยัญชนะตัวแรกของแต่ละคำถูกย้ายไปท้ายคำและเติม _ay_ ต่อท้าย ดังนั้น _first_ จึงกลายเป็น _irst-fay_ ส่วนคำที่เริ่มต้นด้วยสระจะเติม _hay_ ต่อท้ายแทน (_apple_ กลายเป็น _apple-hay_) อย่าลืมรายละเอียดเกี่ยวกับการเข้ารหัส UTF-8 ด้วย!
1. ใช้แฮชแมปและเวกเตอร์ สร้างส่วนติดต่อแบบข้อความเพื่อให้ผู้ใช้เพิ่มชื่อพนักงานเข้าไปในแผนกของบริษัท เช่น “Add Sally to Engineering” หรือ “Add Amir to Sales” จากนั้นให้ผู้ใช้ดึงรายชื่อทุกคนในแผนกหนึ่งหรือทุกคนในบริษัทโดยแยกตามแผนก โดยเรียงตามตัวอักษร

เอกสาร API ของไลบรารีมาตรฐานอธิบายเมธอดที่เวกเตอร์ สตริง และแฮชแมปมี ซึ่งจะเป็นประโยชน์สำหรับแบบฝึกหัดเหล่านี้!

เรากำลังเข้าสู่โปรแกรมที่ซับซ้อนขึ้นซึ่งการดำเนินการต่างๆ อาจล้มเหลว นี่จึงเป็นเวลาที่เหมาะที่สุดที่จะพูดถึงการจัดการข้อผิดพลาด (error handling) เราจะพูดถึงเรื่องนั้นต่อไป!
