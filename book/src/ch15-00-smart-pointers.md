# สมาร์ตพอยน์เตอร์

พอยน์เตอร์ (pointer) เป็นแนวคิดทั่วไปของตัวแปรที่เก็บแอดเดรส (address) ในหน่วยความจำ โดยแอดเดรสนี้จะอ้างถึง หรือ “ชี้ไปที่” ข้อมูลอื่น ๆ ชนิดของพอยน์เตอร์ที่พบได้บ่อยที่สุดใน Rust ก็คือการอ้างอิงหรือเรเฟอเรนซ์ (reference) ซึ่งคุณได้เรียนรู้ไปแล้วในบทที่ 4 เรเฟอเรนซ์จะใช้สัญลักษณ์ `&` และทำหน้าที่ยืมค่าที่มันชี้ไป โดยไม่มีความสามารถพิเศษอื่นใดนอกจากการอ้างถึงข้อมูล และไม่มีต้นทุนการทำงานส่วนเกิน (overhead) ใด ๆ

ในทางกลับกัน _สมาร์ตพอยน์เตอร์ (smart pointer)_ คือโครงสร้างข้อมูลที่ทำงานเสมือนเป็นพอยน์เตอร์ แต่มีเมทาดาตา (metadata) และความสามารถเพิ่มเติม แนวคิดของสมาร์ตพอยน์เตอร์ไม่ได้มีเฉพาะใน Rust เท่านั้น แต่มีต้นกำเนิดมาจากภาษา C++ และมีอยู่ในภาษาอื่น ๆ ด้วยเช่นกัน ในไลบรารีมาตรฐานของ Rust มีสมาร์ตพอยน์เตอร์หลากหลายชนิดที่ให้ฟังก์ชันการทำงานเหนือกว่าเรเฟอเรนซ์ทั่วไป เพื่อทำความเข้าใจแนวคิดพื้นฐานนี้ เราจะไปดูตัวอย่างของสมาร์ตพอยน์เตอร์หลาย ๆ แบบ รวมถึงชนิดสมาร์ตพอยน์เตอร์แบบ_นับจำนวนการอ้างอิง (reference counting)_ พอยน์เตอร์ชนิดนี้จะช่วยให้ข้อมูลหนึ่งชิ้นสามารถมีเจ้าของหลายรายพร้อมกันได้ โดยจะคอยนับติดตามจำนวนเจ้าของที่มีอยู่ และเมื่อไม่มีเจ้าของเหลืออยู่แล้ว ก็จะคืนพื้นที่หน่วยความจำและเก็บกวาดข้อมูลนั้นโดยอัตโนมัติ

สำหรับ Rust ด้วยแนวคิดเรื่องความเป็นเจ้าของ (ownership) และการยืม (borrowing) จึงมีความแตกต่างที่ชัดเจนระหว่างเรเฟอเรนซ์กับสมาร์ตพอยน์เตอร์ กล่าวคือ ในขณะที่เรเฟอเรนซ์ทำหน้าที่เพียงแค่ยืมข้อมูล แต่ในหลายกรณี สมาร์ตพอยน์เตอร์จะเป็น_เจ้าของ_ข้อมูลที่มันชี้ไปด้วย

สมาร์ตพอยน์เตอร์มักจะถูกสร้างขึ้นด้วย struct แต่สิ่งที่ต่างจาก struct ทั่วไปคือ สมาร์ตพอยน์เตอร์จะอิมพลีเมนต์เทรต `Deref` และ `Drop` โดยเทรต `Deref` ช่วยให้อินสแตนซ์ของ struct สมาร์ตพอยน์เตอร์ทำงานเสมือนเรเฟอเรนซ์ได้ ทำให้คุณสามารถเขียนโค้ดที่ใช้งานได้ทั้งกับเรเฟอเรนซ์และสมาร์ตพอยน์เตอร์ ส่วนเทรต `Drop` จะเปิดโอกาสให้คุณกำหนดโค้ดที่ต้องการให้ทำงานโดยอัตโนมัติเมื่ออินสแตนซ์ของสมาร์ตพอยน์เตอร์หลุดออกจากขอบเขต (scope) ในบทนี้ เราจะมาเจาะลึกเทรตทั้งสองนี้และแสดงให้เห็นว่าเหตุใดพวกมันจึงสำคัญต่อสมาร์ตพอยน์เตอร์

เนื่องจากรูปแบบการออกแบบ (design pattern) ของสมาร์ตพอยน์เตอร์เป็นรูปแบบทั่วไปที่ใช้กันบ่อยมากใน Rust บทนี้จึงไม่ได้ครอบคลุมสมาร์ตพอยน์เตอร์ทั้งหมดที่มีอยู่ เพราะไลบรารีภายนอกหลายแห่งต่างก็สร้างสมาร์ตพอยน์เตอร์เป็นของตนเอง และคุณเองก็สามารถสร้างขึ้นมาใช้เองได้เช่นกัน ในบทนี้เราจะเน้นศึกษาเฉพาะสมาร์ตพอยน์เตอร์ตัวหลัก ๆ ที่พบบ่อยที่สุดในไลบรารีมาตรฐาน:

- `Box<T>`, สำหรับจัดสรรค่าบนฮีป (heap)
- `Rc<T>`, ชนิดข้อมูลแบบนับจำนวนการอ้างอิง ที่เปิดให้ข้อมูลมีเจ้าของได้หลายรายพร้อมกัน
- `Ref<T>` และ `RefMut<T>`, ซึ่งเข้าถึงผ่าน `RefCell<T>` เป็นชนิดข้อมูลที่ตรวจสอบและบังคับใช้กฎการยืมในขณะรันไทม์แทนที่จะเป็นตอนคอมไพล์

นอกจากนี้ เรายังจะศึกษาแพตเทิร์น_ความสามารถในการเปลี่ยนแปลงค่าภายใน (interior mutability)_ ซึ่งเป็นรูปแบบที่ชนิดข้อมูลแบบแก้ไขไม่ได้ (immutable) เปิดเผย API ให้เราแก้ไขค่าที่อยู่ข้างในได้ และเราจะมาพูดคุยกันถึงเรื่องวงรอบการอ้างอิง (reference cycle) ว่ามันทำให้หน่วยความจำรั่วไหล (memory leak) ได้อย่างไร และเราจะมีวิธีป้องกันได้อย่างไรบ้าง
