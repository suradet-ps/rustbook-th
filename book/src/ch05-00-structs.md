# การใช้ struct เพื่อจัดโครงสร้างข้อมูลที่เกี่ยวข้องกัน

_struct_ หรือ _โครงสร้าง_ (structure) เป็นชนิดข้อมูลกำหนดเอง (custom data type) ที่ให้คุณรวมและตั้งชื่อค่าที่เกี่ยวข้องกันหลายค่าเข้าด้วยกันเป็นกลุ่มที่มีความหมาย หากคุณคุ้นเคยกับภาษาเชิงวัตถุ (object-oriented) struct ก็เปรียบเสมือนแอตทริบิวต์ข้อมูลของออบเจกต์ ในบทนี้ เราจะเปรียบเทียบและเทียบความต่างของทูเพิล (tuple) กับ struct เพื่อต่อยอดจากสิ่งที่คุณรู้อยู่แล้ว และสาธิตว่าเมื่อใด struct จึงเป็นวิธีที่ดีกว่าในการจัดกลุ่มข้อมูล

เราจะสาธิตวิธีนิยามและสร้างอินสแตนซ์ (instance) ของ struct เราจะพูดคุยถึงวิธีนิยามฟังก์ชันที่เชื่อมโยงกับชนิดข้อมูล (associated function) โดยเฉพาะฟังก์ชันประเภทที่เรียกว่า _เมธอด_ (method) เพื่อระบุพฤติกรรมที่เชื่อมโยงกับชนิด struct struct และ enum (ซึ่งจะกล่าวถึงในบทที่ 6) เป็นชิ้นส่วนพื้นฐานสำหรับการสร้างชนิดข้อมูลใหม่ๆ ในโดเมนของโปรแกรมของคุณ เพื่อใช้ประโยชน์สูงสุดจากการตรวจสอบชนิดข้อมูลตอนคอมไพล์ของ Rust
