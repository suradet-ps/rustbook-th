# การใช้ struct เพื่อจัดโครงสร้างข้อมูลที่เกี่ยวข้องกัน

_struct_ หรือ _โครงสร้าง_ (structure) เป็นชนิดข้อมูลกำหนดเอง (custom data type) ที่เปิดโอกาสให้คุณรวมกลุ่มและตั้งชื่อให้กับค่าข้อมูลหลายค่าที่มีความเกี่ยวข้องกัน เพื่อประกอบขึ้นเป็นกลุ่มข้อมูลที่มีความหมาย หากคุณคุ้นเคยกับภาษาโปรแกรมเชิงวัตถุ (object-oriented language) `struct` ก็เปรียบเสมือนแอตทริบิวต์หรือฟิลด์ข้อมูลของออบเจกต์ ในบทนี้ เราจะเปรียบเทียบความเหมือนและความต่างระหว่างทูเพิล (tuple) กับ `struct` เพื่อต่อยอดจากสิ่งที่คุณได้เรียนรู้มาแล้ว และแสดงให้เห็นว่าในสถานการณ์ใดที่ `struct` จะเป็นวิธีที่ดีกว่าในการจัดกลุ่มข้อมูล

เราจะแสดงวิธีนิยามและสร้างอินสแตนซ์ (instance) ของ `struct` รวมถึงศึกษาวิธีนิยามฟังก์ชันประจำชนิดข้อมูล (associated function) โดยเฉพาะฟังก์ชันชนิดที่เรียกว่า _เมธอด_ (method) เพื่อกำหนดพฤติกรรมการทำงานให้กับ `struct` นั้นๆ ทั้ง `struct` และ `enum` (ซึ่งเราจะพูดถึงในบทที่ 6) ถือเป็นองค์ประกอบพื้นฐานที่สำคัญในการสร้างชนิดข้อมูลใหม่ๆ ในโดเมนของโปรแกรมคุณ เพื่อดึงเอาประสิทธิภาพสูงสุดจากการตรวจสอบชนิดข้อมูลตอนคอมไพล์ของ Rust มาใช้งาน
