# enum และการจับคู่แพตเทิร์น

ในบทนี้ เราจะมาเรียนรู้เรื่องการแจงนับ (enumeration) หรือที่นิยมเรียกสั้นๆ ว่า _enum_ โดย enum ช่วยให้คุณสามารถนิยามชนิดข้อมูลขึ้นมาได้ด้วยการแจกแจงค่าหรือรูปแบบที่เป็นไปได้ทั้งหมด ซึ่งเราเรียกว่า _วาเรียนต์_ (variant) ในตอนแรก เราจะมาดูวิธีนิยามและใช้งาน enum เพื่อทำความเข้าใจว่า enum สามารถสื่อความหมายควบคู่ไปกับการจัดเก็บข้อมูลได้อย่างไร จากนั้น เราจะไปสำรวจ enum ตัวสำคัญที่มีประโยชน์อย่างยิ่งตัวหนึ่ง นั่นก็คือ `Option` ซึ่งใช้แทนค่าที่อาจจะมีอยู่หรือไม่มีค่าใดๆ เลยก็ได้ ถัดมา เราจะไปดูว่าการจับคู่แพตเทิร์น (pattern matching) ด้วยนิพจน์ `match` ช่วยให้การเขียนโค้ดแยกการทำงานตามแต่ละวาเรียนต์ของ enum เป็นเรื่องง่ายและรัดกุมได้อย่างไร และสุดท้าย เราจะปิดท้ายด้วยโครงสร้าง `if let` ซึ่งเป็นอีกหนึ่งสำนวนภาษาที่สะดวกและกระชับสำหรับการจัดการกับค่า enum ในโค้ดของคุณ
