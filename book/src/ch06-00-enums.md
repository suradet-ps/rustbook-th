# enum และการจับคู่แพตเทิร์น

ในบทนี้ เราจะมาดูการแจกแจง (enumeration) ซึ่งเรียกอีกอย่างว่า _enum_ enum ช่วยให้คุณนิยามชนิดข้อมูลได้โดยการแจกแจงวาเรียนต์ (variant) ที่เป็นไปได้ของมัน ก่อนอื่นเราจะนิยามและใช้งาน enum เพื่อแสดงให้เห็นว่า enum สามารถเข้ารหัสความหมายไปพร้อมกับข้อมูลได้อย่างไร ต่อไป เราจะสำรวจ enum ที่มีประโยชน์เป็นพิเศษตัวหนึ่งชื่อ `Option` ซึ่งแสดงว่าค่าสามารถเป็นอะไรบางอย่างหรือไม่ใช่อะไรเลยก็ได้ จากนั้น เราจะมาดูว่าการจับคู่แพตเทิร์น (pattern matching) ในเอ็กซ์เพรสชัน `match` ทำให้การรันโค้ดที่แตกต่างกันสำหรับค่า enum ที่ต่างกันเป็นเรื่องง่ายได้อย่างไร สุดท้าย เราจะครอบคลุมว่าโครงสร้าง `if let` เป็นสำนวนที่สะดวกและกระชับอีกแบบหนึ่งสำหรับจัดการ enum ในโค้ดของคุณได้อย่างไร
