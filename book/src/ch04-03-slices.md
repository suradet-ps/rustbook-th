## ชนิดสไลซ์

_สไลซ์_ (slice) ช่วยให้คุณอ้างถึงลำดับที่ต่อเนื่องกันขององค์ประกอบใน[คอลเลกชัน (collection)](ch08-00-common-collections.md)<!-- ignore --> สไลซ์เป็นเรเฟอเรนซ์ชนิดหนึ่ง จึงไม่มีความเป็นเจ้าของ

นี่คือโจทย์การเขียนโปรแกรมเล็กๆ: จงเขียนฟังก์ชันที่รับสตริงของคำที่คั่นด้วยช่องว่าง และคืนคำแรกที่พบในสตริงนั้น หากฟังก์ชันไม่พบช่องว่างในสตริง สตริงทั้งสตริงก็ต้องเป็นคำเดียว จึงควรคืนสตริงทั้งหมดกลับมา

> หมายเหตุ: เพื่อจุดประสงค์ในการแนะนำสไลซ์ ในหัวข้อนี้เราสมมติว่าใช้เฉพาะ ASCII เท่านั้น ส่วนการอภิปรายเรื่องการจัดการ UTF-8 อย่างละเอียดกว่านี้อยู่ในหัวข้อ[“การจัดเก็บข้อความที่เข้ารหัส UTF-8 ด้วยสตริง”][strings]<!-- ignore --> ของบทที่ 8

มาลองทำความเข้าใจว่าเราจะเขียนซิกเนเจอร์ของฟังก์ชันนี้โดยไม่ใช้สไลซ์ได้อย่างไร เพื่อให้เข้าใจปัญหาที่สไลซ์จะเข้ามาแก้ไข:

```rust,ignore
fn first_word(s: &String) -> ?
```

ฟังก์ชัน `first_word` มีพารามิเตอร์ชนิด `&String` เราไม่จำเป็นต้องมีความเป็นเจ้าของ ดังนั้นแบบนี้ก็ใช้ได้ (ใน Rust ที่เป็นสำนวนนิยม ฟังก์ชันจะไม่รับความเป็นเจ้าของอาร์กิวเมนต์ของมัน เว้นแต่จำเป็น และเหตุผลของเรื่องนั้นจะชัดเจนขึ้นเมื่อเราศึกษาต่อไป) แต่เราควรคืนอะไรดี? เราไม่มีวิธีพูดถึง*บางส่วน*ของสตริงจริงๆ อย่างไรก็ตาม เราสามารถคืนดัชนีของจุดสิ้นสุดของคำ ซึ่งระบุได้ด้วยช่องว่าง ลองทำแบบนั้นกัน ดังที่แสดงในลิสติ้ง 4-7

_สตริงสไลซ์_ (string slice) คือเรเฟอเรนซ์ไปยังลำดับที่ต่อเนื่องกันขององค์ประกอบของ `String` และมันมีหน้าตาแบบนี้:

```rust
{{#rustdoc_include ../listings/ch04-understanding-ownership/no-listing-17-slice/src/main.rs:here}}
```

แทนที่จะเป็นเรเฟอเรนซ์ไปยัง `String` ทั้งอัน `hello` กลับเป็นเรเฟอเรนซ์ไปยังบางส่วนของ `String` ซึ่งระบุไว้ในส่วน `[0..5]` ที่เพิ่มเข้ามา เราสร้างสไลซ์โดยใช้เรนจ์ภายในวงเล็บเหลี่ยม โดยระบุ `[starting_index..ending_index]` โดยที่ _`starting_index`_ คือตำแหน่งแรกในสไลซ์ และ _`ending_index`_ คือหนึ่งมากกว่าตำแหน่งสุดท้ายในสไลซ์ ภายในแล้ว โครงสร้างข้อมูลสไลซ์เก็บตำแหน่งเริ่มต้นและความยาวของสไลซ์ ซึ่งเทียบเท่ากับ _`ending_index`_ ลบ _`starting_index`_ ดังนั้นในกรณีของ `let world = &s[6..11];` `world` จะเป็นสไลซ์ที่มีพอยน์เตอร์ไปยังไบต์ที่ดัชนี 6 ของ `s` โดยมีความยาวเป็น `5`

ด้วยวากยสัมพันธ์เรนจ์ `..` ของ Rust หากคุณต้องการเริ่มที่ดัชนี 0 คุณสามารถละค่าที่อยู่ก่อนจุดสองจุดได้ พูดอีกนัยหนึ่ง สิ่งเหล่านี้เทียบเท่ากัน:

```rust
let s = String::from("hello");

let slice = &s[0..2];
let slice = &s[..2];
```

ในทำนองเดียวกัน หากสไลซ์ของคุณรวมไบต์สุดท้ายของ `String` ด้วย คุณสามารถละตัวเลขที่ต่อท้ายได้ นั่นหมายความว่าสิ่งเหล่านี้เทียบเท่ากัน:

```rust
let s = String::from("hello");

let len = s.len();

let slice = &s[3..len];
let slice = &s[3..];
```

คุณยังสามารถละทั้งสองค่าเพื่อตัดสไลซ์ของสตริงทั้งหมดได้ ดังนั้นสิ่งเหล่านี้เทียบเท่ากัน:

```rust
let s = String::from("hello");

let len = s.len();

let slice = &s[0..len];
let slice = &s[..];
```

> หมายเหตุ: ดัชนีช่วงของสตริงสไลซ์ต้องอยู่บนขอบเขตอักขระ UTF-8 ที่ถูกต้อง หากคุณพยายามสร้างสตริงสไลซ์ที่กึ่งกลางของอักขระหลายไบต์ โปรแกรมของคุณจะออกจากการทำงานพร้อมข้อผิดพลาด

#### สตริงลิเทอรัลในฐานะสไลซ์

ย้อนนึกถึงที่เราได้พูดถึงว่าสตริงลิเทอรัลถูกเก็บไว้ภายในไฟล์ไบนารี ตอนนี้เมื่อเรารู้จักสไลซ์แล้ว เราจึงเข้าใจสตริงลิเทอรัลได้อย่างถูกต้อง:

```rust
let s = "Hello, world!";
```

ชนิดของ `s` ตรงนี้คือ `&str`: มันเป็นสไลซ์ที่ชี้ไปยังจุดเฉพาะเจาะจงนั้นของไฟล์ไบนารี นี่ก็เป็นเหตุผลว่าทำไมสตริงลิเทอรัลจึงเป็นแบบเปลี่ยนแปลงไม่ได้ด้วย เพราะ `&str` เป็นเรเฟอเรนซ์แบบเปลี่ยนแปลงไม่ได้

### สไลซ์แบบอื่นๆ

สตริงสไลซ์นั้นเจาะจงเฉพาะกับสตริงอย่างที่คุณอาจคาดเดาได้ แต่ยังมีชนิดสไลซ์ที่ทั่วไปกว่านั้นด้วย พิจารณาอาร์เรย์นี้:

```rust
let a = [1, 2, 3, 4, 5];
```

เช่นเดียวกับที่เราอาจต้องการอ้างถึงบางส่วนของสตริง เราอาจต้องการอ้างถึงบางส่วนของอาร์เรย์ เราจะทำแบบนี้:

```rust
let a = [1, 2, 3, 4, 5];

let slice = &a[1..3];

assert_eq!(slice, &[2, 3]);
```

สไลซ์นี้มีชนิด `&[i32]` มันทำงานแบบเดียวกับสตริงสไลซ์ คือเก็บเรเฟอเรนซ์ไปยังองค์ประกอบแรกและความยาว คุณจะใช้สไลซ์ชนิดนี้กับคอลเลกชันอื่นๆ หลากหลายแบบ เราจะพูดถึงคอลเลกชันเหล่านี้โดยละเอียดเมื่อเราพูดถึงเวกเตอร์ในบทที่ 8
