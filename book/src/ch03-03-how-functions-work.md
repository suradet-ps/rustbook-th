## ฟังก์ชัน

ฟังก์ชัน (function) เป็นสิ่งที่พบเห็นได้ทั่วไปในโค้ด Rust คุณได้เห็นหนึ่งในฟังก์ชันที่สำคัญที่สุดของภาษาแล้ว นั่นคือฟังก์ชัน `main` ซึ่งเป็นจุดเริ่มต้นของโปรแกรมหลายโปรแกรม คุณยังได้เห็นคำสงวน `fn` ซึ่งช่วยให้คุณประกาศฟังก์ชันใหม่ได้

โค้ด Rust ใช้_สเนกเคส_ (snake case) เป็นสไตล์ตามธรรมเนียมสำหรับชื่อฟังก์ชันและตัวแปร ซึ่งตัวอักษรทั้งหมดเป็นตัวพิมพ์เล็กและใช้ขีดล่างคั่นระหว่างคำ นี่คือโปรแกรมที่มีตัวอย่างการนิยามฟังก์ชัน:

<span class="filename">ชื่อไฟล์: src/main.rs</span>

```rust
{{#rustdoc_include ../listings/ch03-common-programming-concepts/no-listing-16-functions/src/main.rs}}
```

เรานิยามฟังก์ชันใน Rust โดยป้อน `fn` ตามด้วยชื่อฟังก์ชันและวงเล็บหนึ่งคู่ วงเล็บปีกกาบอกคอมไพเลอร์ว่าบอดี้ (body) ของฟังก์ชันเริ่มและสิ้นสุดที่ใด

เราสามารถเรียกฟังก์ชันใดก็ได้ที่เรานิยามไว้โดยป้อนชื่อของมันตามด้วยวงเล็บหนึ่งคู่ เพราะ `another_function` ถูกนิยามไว้ในโปรแกรม จึงสามารถเรียกได้จากภายในฟังก์ชัน `main` โปรดสังเกตว่าเรานิยาม `another_function` _หลังจาก_ฟังก์ชัน `main` ในซอร์สโค้ด เราก็สามารถนิยามมันก่อนหน้านั้นได้เช่นกัน Rust ไม่สนใจว่าคุณนิยามฟังก์ชันไว้ที่ใด ขอเพียงแต่มันถูกนิยามไว้ที่ใดที่หนึ่งในสโคปที่ผู้เรียกเห็นได้ก็พอ

มาเริ่มโปรเจกต์ไบนารีใหม่ชื่อ _functions_ เพื่อสำรวจฟังก์ชันเพิ่มเติมกัน วางตัวอย่าง `another_function` ลงใน _src/main.rs_ แล้วรันมัน คุณควรเห็นเอาต์พุตต่อไปนี้:

```console
{{#include ../listings/ch03-common-programming-concepts/no-listing-16-functions/output.txt}}
```

บรรทัดต่างๆ ทำงานตามลำดับที่มันปรากฏในฟังก์ชัน `main` ขั้นแรกข้อความ “Hello, world!” ถูกพิมพ์ จากนั้น `another_function` ถูกเรียกและข้อความของมันถูกพิมพ์

### พารามิเตอร์

เราสามารถนิยามฟังก์ชันให้มี_พารามิเตอร์_ (parameter) ซึ่งเป็นตัวแปรพิเศษที่เป็นส่วนหนึ่งของซิกเนเจอร์ของฟังก์ชัน เมื่อฟังก์ชันมีพารามิเตอร์ คุณสามารถส่งค่าจริงให้กับพารามิเตอร์เหล่านั้นได้ ในทางเทคนิค ค่าจริงเหล่านี้เรียกว่า_อาร์กิวเมนต์_ (argument) แต่ในการพูดคุยทั่วไป ผู้คนมักใช้คำว่า_พารามิเตอร์_และ_อาร์กิวเมนต์_แทนกันได้ ไม่ว่าจะหมายถึงตัวแปรในการนิยามฟังก์ชันหรือค่าจริงที่ส่งเข้ามาเมื่อคุณเรียกฟังก์ชัน

การประกาศ `another_function` มีพารามิเตอร์หนึ่งตัวชื่อ `x` ชนิดของ `x` ถูกระบุเป็น `i32` เมื่อเราส่ง `5` เข้าไปใน `another_function` มาโคร (macro) `println!` จะวาง `5` ไว้ตรงตำแหน่งของวงเล็บปีกกาคู่ที่บรรจุ `x` อยู่ในสตริงรูปแบบ

ในซิกเนเจอร์ของฟังก์ชัน คุณ_ต้อง_ประกาศชนิดของพารามิเตอร์แต่ละตัว นี่เป็นการตัดสินใจโดยเจตนาในการออกแบบของ Rust การบังคับให้มีการระบุชนิดข้อมูลในการนิยามฟังก์ชันหมายความว่าคอมไพเลอร์แทบไม่จำเป็นต้องให้คุณระบุชนิดข้อมูลที่อื่นในโค้ดเพื่อหาว่าคุณหมายถึงชนิดใด คอมไพเลอร์ยังสามารถให้ข้อความแสดงข้อผิดพลาดที่เป็นประโยชน์มากขึ้นได้หากมันรู้ว่าฟังก์ชันคาดหวังชนิดใด

### สเตตเมนต์และเอ็กซ์เพรสชัน

บอดี้ของฟังก์ชันประกอบขึ้นจากชุดของสเตตเมนต์ (statement) ซึ่งอาจลงท้ายด้วยเอ็กซ์เพรสชัน (expression) ได้ จนถึงตอนนี้ ฟังก์ชันที่เรากล่าวถึงยังไม่มีเอ็กซ์เพรสชันที่ลงท้าย แต่คุณได้เห็นเอ็กซ์เพรสชันเป็นส่วนหนึ่งของสเตตเมนต์แล้ว เพราะ Rust เป็นภาษาที่อิงเอ็กซ์เพรสชัน ความแตกต่างนี้จึงเป็นเรื่องสำคัญที่ต้องเข้าใจ ภาษาอื่นไม่มีข้อแตกต่างแบบเดียวกันนี้ ดังนั้นมาดูกันว่าสเตตเมนต์และเอ็กซ์เพรสชันคืออะไร และความแตกต่างของมันส่งผลต่อบอดี้ของฟังก์ชันอย่างไร

- _สเตตเมนต์_ คือคำสั่งที่ทำงานบางอย่างและไม่คืนค่า
- _เอ็กซ์เพรสชัน_ ประเมินค่าแล้วได้ผลลัพธ์เป็นค่า
