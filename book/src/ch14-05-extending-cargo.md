## ขยายความสามารถของ Cargo ด้วยคำสั่งกำหนดเอง

Cargo ถูกออกแบบมาเพื่อให้คุณขยายมันด้วยคำสั่งย่อยใหม่ๆ ได้โดยไม่ต้องแก้ไขตัวมันเอง หากไบนารี (binary) ใน `$PATH` ของคุณมีชื่อว่า `cargo-something` คุณสามารถรันมันได้ราวกับว่ามันเป็นคำสั่งย่อยของ Cargo โดยรัน `cargo something` คำสั่งกำหนดเองเช่นนี้จะถูกแสดงในรายการด้วยเมื่อคุณรัน `cargo --list` การสามารถใช้ `cargo install` เพื่อติดตั้งส่วนขยายแล้วรันมันได้เหมือนกับเครื่องมือ Cargo ที่มีมาในตัว ถือเป็นข้อดีที่สะดวกสุดๆ ของการออกแบบ Cargo!

## สรุป

การแบ่งปันโค้ดด้วย Cargo และ [crates.io](https://crates.io/)<!-- ignore --> เป็นส่วนหนึ่งที่ทำให้ระบบนิเวศของ Rust มีประโยชน์กับงานที่แตกต่างกันมากมาย ไลบรารีมาตรฐานของ Rust มีขนาดเล็กและเสถียร แต่เครต (crate) นั้นแชร์ ใช้งาน และปรับปรุงได้ง่ายตามกรอบเวลาที่ต่างจากตัวภาษา อย่าอายที่จะแบ่งปันโค้ดที่มีประโยชน์ต่อคุณบน [crates.io](https://crates.io/)<!-- ignore --> มันมีแนวโน้มว่าจะมีประโยชน์ต่อคนอื่นเช่นกัน!
