## ขยายความสามารถของ Cargo ด้วยคำสั่งกำหนดเอง

Cargo ได้รับการออกแบบมาเพื่อให้คุณสามารถขยายความสามารถด้วยคำสั่งย่อยใหม่ ๆ ได้โดยไม่จำเป็นต้องแก้ไขตัวโปรแกรม Cargo เลยแม้แต่น้อย หากมีไฟล์ไบนารีใด ๆ ใน `$PATH` ของคุณที่ตั้งชื่อในรูปแบบ `cargo-something` คุณก็สามารถเรียกใช้งานมันได้เสมือนเป็นคำสั่งย่อยของ Cargo ด้วยคำสั่ง `cargo something` คำสั่งกำหนดเองเหล่านี้จะแสดงขึ้นมาในรายการคำสั่งด้วยเมื่อคุณรัน `cargo --list` ความสามารถในการใช้ `cargo install` เพื่อติดตั้งส่วนขยายแล้วเรียกใช้งานได้ทันทีราวกับเป็นเครื่องมือที่มีมาในตัวของ Cargo นั้น ถือเป็นข้อได้เปรียบที่ออกแบบมาได้อย่างสะดวกสบายเป็นอย่างยิ่ง!

## สรุป

การแบ่งปันโค้ดผ่าน Cargo และ [crates.io](https://crates.io/)<!-- ignore --> ถือเป็นหัวใจสำคัญอย่างหนึ่งที่ทำให้ระบบนิเวศของ Rust ทรงพลังและตอบโจทย์งานที่หลากหลาย ไลบรารีมาตรฐานของ Rust มีขนาดกะทัดรัดและเน้นความเสถียร แต่เครตในชุมชนนั้นง่ายต่อการแบ่งปัน นำไปใช้ และพัฒนาต่อยอดได้อย่างรวดเร็วโดยไม่ต้องรอรอบการอัปเดตของตัวภาษาเอง ดังนั้นอย่าลังเลที่จะแบ่งปันโค้ดที่คุณเขียนขึ้นและพบว่ามีประโยชน์ขึ้นสู่ [crates.io](https://crates.io/)<!-- ignore --> เพราะมันน่าจะเป็นประโยชน์สำหรับผู้อื่นด้วยเช่นกัน!
