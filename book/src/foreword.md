# คำนิยม

ภาษาโปรแกรม Rust ก้าวหน้ามาไกลมากในเวลาเพียงไม่กี่ปี จากจุดเริ่มต้นที่กำเนิดและฟูมฟักขึ้นโดยกลุ่มคนรักเทคโนโลยีกลุ่มเล็กๆ ที่เพิ่งก่อตัว จนเติบโตกลายเป็นหนึ่งในภาษาโปรแกรมที่ผู้คนรักและเป็นที่ต้องการมากที่สุดในโลก เมื่อมองย้อนกลับไป ย่อมเป็นธรรมดาที่ประสิทธิภาพและศักยภาพอันเปี่ยมคำมั่นสัญญาของ Rust จะสะกดทุกสายตาและหยั่งรากลึกในวงการเขียนโปรแกรมระดับระบบ (systems programming) ทว่า สิ่งที่ไม่ได้เกิดขึ้นเองตามธรรมชาติ คือคลื่นความสนใจและนวัตกรรมระดับโลกที่แผ่ขยายไปทั่วชุมชนโอเพนซอร์ส พร้อมจุดประกายให้เกิดการนำไปประยุกต์ใช้อย่างกว้างขวางในหลากหลายอุตสาหกรรม

ณ วันนี้ เป็นเรื่องง่ายที่จะชี้ให้เห็นถึงคุณสมบัติอันยอดเยี่ยมของ Rust เพื่ออธิบายถึงกระแสความนิยมและการเติบโตอย่างก้าวกระโดดนี้ ใครเล่าจะไม่อยากได้ทั้งความปลอดภัยของหน่วยความจำ *และ* ประสิทธิภาพความเร็วระดับสูง *และ* คอมไพเลอร์ที่พร้อมช่วยเหลือ *และ* เครื่องมือชั้นยอด ควบคู่ไปกับคุณสมบัติอันยอดเยี่ยมอื่นๆ อีกมากมาย ภาษา Rust ที่คุณเห็นในทุกวันนี้ ผสมผสานผลงานวิจัยยาวนานหลายปีด้านการเขียนโปรแกรมระดับระบบ เข้ากับภูมิปัญญาเชิงปฏิบัติของชุมชนที่เปี่ยมด้วยพลังและความมุ่งมั่น ภาษา Rust ได้รับการออกแบบอย่างมีเป้าหมายและรังสรรค์ขึ้นอย่างประณีต เพื่อมอบเครื่องมือที่ช่วยให้นักพัฒนาเขียนโค้ดที่ทั้งปลอดภัย รวดเร็ว และเชื่อถือได้ง่ายดายยิ่งขึ้น

ทว่าสิ่งที่ทำให้ Rust มีความพิเศษอย่างแท้จริง คือรากฐานที่มุ่งส่งเสริมและมอบพลังให้แก่คุณในฐานะผู้ใช้ เพื่อให้บรรลุเป้าหมายของตนเองได้อย่างราบรื่น นี่คือภาษาที่ปรารถนาให้คุณประสบความสำเร็จ และหลักการเสริมสร้างพลังนี้ไหลเวียนอยู่ในหัวใจของชุมชนผู้สร้าง ดูแล และผลักดันภาษานี้ตลอดมา นับตั้งแต่การพิมพ์ฉบับก่อนหน้าของตำราเล่มนี้ Rust ได้วิวัฒนาการจนกลายเป็นภาษาที่เป็นสากลและได้รับความไว้วางใจอย่างลึกซึ้ง ปัจจุบันโครงการ Rust ได้รับการสนับสนุนอย่างมั่นคงจาก Rust Foundation ซึ่งร่วมลงทุนในโครงการริเริ่มสำคัญๆ เพื่อให้มั่นใจว่า Rust จะปลอดภัย มีเสถียรภาพ และเติบโตอย่างยั่งยืนสืบไป

หนังสือ *The Rust Programming Language* ฉบับนี้เป็นการปรับปรุงครั้งใหญ่ที่ครอบคลุมทุกมิติ เพื่อสะท้อนพัฒนาการของภาษาตลอดหลายปีที่ผ่านมา พร้อมนำเสนอข้อมูลใหม่ๆ อันทรงคุณค่า ทว่าหนังสือเล่มนี้มิได้เป็นเพียงคู่มืออธิบายไวยากรณ์และไลบรารีเท่านั้น หากแต่เป็นบัตรเชิญให้คุณก้าวเข้าสู่ชุมชนที่ให้คุณค่ากับคุณภาพ ประสิทธิภาพ และการออกแบบที่คิดมาอย่างรอบคอบ ไม่ว่าคุณจะเป็นนักพัฒนาผู้ช่ำชองที่ต้องการสัมผัส Rust เป็นครั้งแรก หรือเป็นชาว Rustacean ผู้มีประสบการณ์ที่มองหาโอกาสขัดเกลาทักษะ หนังสือฉบับนี้มีสิ่งที่มีค่ายิ่งสำหรับทุกคนอย่างแน่นอน

การเดินทางของ Rust คือเส้นทางแห่งการร่วมมือ การเรียนรู้ และการพัฒนาอย่างต่อเนื่อง การเติบโตของภาษาและระบบนิเวศล้วนเป็นภาพสะท้อนโดยตรงของชุมชนอันหลากหลายและเปี่ยมชีวิตชีวาที่อยู่เบื้องหลัง การร่วมแรงร่วมใจของนักพัฒนาหลายพันคน ตั้งแต่นักออกแบบแกนกลางของภาษา ไปจนถึงผู้ร่วมสมทบผลงานเป็นครั้งคราว คือสิ่งที่หล่อหลอมให้ Rust กลายเป็นเครื่องมือที่มีเอกลักษณ์และทรงพลังยิ่ง การเปิดอ่านหนังสือเล่มนี้จึงมิใช่เพียงแค่การเรียนรู้ภาษาโปรแกรมใหม่เท่านั้น หากแต่เป็นการเข้าร่วมการเคลื่อนไหวเพื่อสร้างสรรค์ซอฟต์แวร์ที่ดียิ่งขึ้น ปลอดภัยยิ่งขึ้น และสนุกสนานเพลิดเพลินยิ่งขึ้นในการลงมือพัฒนา

ยินดีต้อนรับสู่ชุมชน Rust!
