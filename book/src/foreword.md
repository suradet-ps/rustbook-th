# คำนิยม

ภาษาโปรแกรม Rust เดินทางมาไกลมากในเวลาเพียงไม่กี่ปี จากการถือกำเนิดและฟูมฟักโดยชุมชนผู้หลงใหลกลุ่มเล็กๆ ที่เพิ่งก่อตัว มาจนกลายเป็นหนึ่งในภาษาโปรแกรมที่ได้รับความรักและเป็นที่ต้องการมากที่สุดในโลก เมื่อมองย้อนกลับไป การที่พลังและคำสัญญาของ Rust จะดึงดูดความสนใจและหยั่งรากในวงการเขียนโปรแกรมระดับระบบนั้นเป็นสิ่งที่เลี่ยงไม่ได้ แต่สิ่งที่ไม่ได้เกิดขึ้นเองตามธรรมชาติคือการเติบโตของความสนใจและนวัตกรรมในระดับโลก ที่แผ่ซ่านไปทั่วชุมชนโอเพนซอร์สและจุดชนวนให้เกิดการนำไปใช้อย่างกว้างขวางในหลากหลายอุตสาหกรรม

ณ จุดนี้ เป็นเรื่องง่ายที่จะชี้ไปที่ฟีเจอร์อันยอดเยี่ยมที่ Rust มอบให้ เพื่ออธิบายการเติบโตอย่างก้าวกระโดดของความสนใจและการนำไปใช้นี้ ใครล่ะจะไม่อยากได้ความปลอดภัยของหน่วยความจำ *และ* ประสิทธิภาพที่รวดเร็ว *และ* คอมไพเลอร์ที่เป็นมิตร *และ* เครื่องมือที่ยอดเยี่ยม รวมถึงฟีเจอร์วิเศษอื่นๆ อีกมากมาย ภาษา Rust ที่คุณเห็นในวันนี้ผสมผสานงานวิจัยหลายปีด้านการเขียนโปรแกรมระดับระบบเข้ากับภูมิปัญญาเชิงปฏิบัติของชุมชนที่มีชีวิตชีวาและเต็มไปด้วยความหลงใหล ภาษานี้ถูกออกแบบอย่างมีเป้าหมายและสร้างสรรค์อย่างพิถีพิถัน มอบเครื่องมือที่ช่วยให้นักพัฒนาเขียนโค้ดที่ปลอดภัย รวดเร็ว และเชื่อถือได้ง่ายขึ้น

แต่สิ่งที่ทำให้ Rust พิเศษอย่างแท้จริงคือรากฐานที่มุ่งเสริมพลังให้คุณในฐานะผู้ใช้บรรลุเป้าหมายของตัวเอง นี่คือภาษาที่ต้องการให้คุณประสบความสำเร็จ และหลักการเสริมพลังนี้ไหลเวียนอยู่ทั่วแกนกลางของชุมชนที่สร้าง ดูแลรักษา และผลักดันภาษานี้ นับตั้งแต่ฉบับก่อนของตำราอันเป็นมาตรฐานเล่มนี้ Rust ได้พัฒนาต่อจนกลายเป็นภาษาที่เป็นสากลและได้รับความไว้วางใจอย่างแท้จริง ทุกวันนี้โครงการ Rust ได้รับการสนับสนุนอย่างแข็งแกร่งจาก Rust Foundation ซึ่งยังลงทุนในโครงการสำคัญๆ เพื่อให้มั่นใจว่า Rust จะปลอดภัย เสถียร และยั่งยืน

ฉบับนี้ของ *The Rust Programming Language* เป็นการปรับปรุงครั้งใหญ่ที่ครอบคลุม สะท้อนวิวัฒนาการของภาษาที่ผ่านมา และนำเสนอข้อมูลใหม่ที่มีคุณค่า แต่หนังสือเล่มนี้ไม่ได้เป็นเพียงคู่มือว่าด้วยวากยสัมพันธ์และไลบรารีเท่านั้น หากยังเป็นคำเชิญให้คุณเข้าร่วมชุมชนที่ให้ความสำคัญกับคุณภาพ ประสิทธิภาพ และการออกแบบที่รอบคอบ ไม่ว่าคุณจะเป็นนักพัฒนาผู้ช่ำชองที่อยากลองสำรวจ Rust เป็นครั้งแรก หรือเป็น Rustacean ที่มีประสบการณ์และต้องการขัดเกลาทักษะ ฉบับนี้มีสิ่งที่มีค่าให้กับทุกคน

เส้นทางของ Rust คือเส้นทางแห่งการร่วมมือ การเรียนรู้ และการพัฒนาซ้ำแล้วซ้ำเล่า การเติบโตของภาษาและระบบนิเวศเป็นภาพสะท้อนโดยตรงของชุมชนที่มีชีวิตชีวาและหลากหลายที่อยู่เบื้องหลัง ผลงานของนักพัฒนาหลายพันคน ตั้งแต่นักออกแบบภาษาหลักไปจนถึงผู้ร่วมสมทบเป็นครั้งคราว คือสิ่งที่ทำให้ Rust เป็นเครื่องมือที่มีเอกลักษณ์และทรงพลังเช่นนี้ การหยิบหนังสือเล่มนี้ขึ้นมาอ่านไม่ได้หมายความว่าคุณกำลังเรียนภาษาโปรแกรมใหม่เพียงอย่างเดียว แต่คุณกำลังเข้าร่วมขบวนการที่ทำให้ซอฟต์แวร์ดีขึ้น ปลอดภัยขึ้น และสนุกกับการทำงานด้วยมากขึ้น

ยินดีต้อนรับสู่ชุมชน Rust!
