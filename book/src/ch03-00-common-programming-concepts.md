# แนวคิดพื้นฐานของการเขียนโปรแกรม

บทนี้ครอบคลุมแนวคิดที่ปรากฏในภาษาโปรแกรมแทบทุกภาษาและวิธีที่แนวคิดเหล่านั้นทำงานใน Rust ภาษาโปรแกรมหลายภาษามีส่วนแกนกลางที่เหมือนกันมากมาย ไม่มีแนวคิดใดที่นำเสนอในบทนี้เป็นเอกลักษณ์เฉพาะของ Rust แต่เราจะพูดคุยถึงแนวคิดเหล่านั้นในบริบทของ Rust และอธิบายธรรมเนียมปฏิบัติในการใช้งาน

โดยเฉพาะอย่างยิ่ง คุณจะได้เรียนรู้เกี่ยวกับตัวแปร ชนิดข้อมูลพื้นฐาน ฟังก์ชัน คอมเมนต์ และการควบคุมโฟลว์ พื้นฐานเหล่านี้จะอยู่ในทุกโปรแกรม Rust และการเรียนรู้สิ่งเหล่านี้ตั้งแต่เนิ่นๆ จะมอบแกนหลักที่แข็งแรงให้คุณเริ่มต้น

> #### คำสงวน
>
> ภาษา Rust มีชุดของ_คำสงวน_ (keyword) ที่สงวนไว้ให้ภาษาใช้เท่านั้น เช่นเดียวกับในภาษาอื่นๆ โปรดจำไว้ว่าคุณไม่สามารถใช้คำเหล่านี้เป็นชื่อของตัวแปรหรือฟังก์ชันได้ คำสงวนส่วนใหญ่มีความหมายพิเศษ และคุณจะใช้คำเหล่านี้ทำงานต่างๆ ในโปรแกรม Rust ของคุณ ส่วนคำอื่นๆ อีกไม่กี่คำไม่มีฟังก์ชันการทำงานที่เชื่อมโยงอยู่ในปัจจุบัน แต่ถูกสงวนไว้สำหรับฟังก์ชันการทำงานที่อาจถูกเพิ่มเข้ามาใน Rust ในอนาคต คุณสามารถดูรายการคำสงวนได้ที่[ภาคผนวก A][appendix_a]<!-- ignore -->
