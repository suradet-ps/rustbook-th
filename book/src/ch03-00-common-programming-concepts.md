# แนวคิดพื้นฐานของการเขียนโปรแกรม

บทนี้ครอบคลุมแนวคิดพื้นฐานที่ปรากฏในภาษาโปรแกรมแทบทุกภาษา พร้อมอธิบายการทำงานของแนวคิดเหล่านั้นในบริบทของภาษา Rust แม้ว่าแนวคิดต่างๆ ในบทนี้จะไม่ได้มีเฉพาะใน Rust เพียงภาษาเดียว แต่เราจะมาสำรวจแนวคิดเหล่านั้นพร้อมทั้งอธิบายธรรมเนียมปฏิบัติและแนวทางการใช้งานที่เป็นแบบฉบับของ Rust

โดยเฉพาะอย่างยิ่ง คุณจะได้เรียนรู้เกี่ยวกับตัวแปร, ชนิดข้อมูลพื้นฐาน, ฟังก์ชัน, คอมเมนต์ และการควบคุมทิศทางการทำงานของโปรแกรม (control flow) พื้นฐานเหล่านี้คือรากฐานสำคัญในทุกโปรแกรมของ Rust และการทำความเข้าใจสิ่งเหล่านี้ตั้งแต่เริ่มต้นจะช่วยสร้างพื้นฐานที่มั่นคงสำหรับการก้าวต่อไป

> #### คำสงวน
>
> เช่นเดียวกับภาษาโปรแกรมอื่นๆ ภาษา Rust มีชุดของ_คำสงวน_ (keywords) ที่สงวนไว้สำหรับการทำงานของภาษาโดยเฉพาะ ซึ่งคุณจะไม่สามารถนำคำเหล่านี้ไปใช้เป็นชื่อตัวแปรหรือชื่อฟังก์ชันได้ คำสงวนส่วนใหญ่มีความหมายเฉพาะตัวและใช้สำหรับสั่งการทำงานต่างๆ ในโปรแกรม Rust ของคุณ ขณะที่คำสงวนบางคำยังไม่ได้เปิดให้ใช้งานในปัจจุบัน แต่ถูกจองไว้สำหรับฟังก์ชันใหม่ๆ ที่อาจเพิ่มเข้ามาในอนาคต สามารถตรวจสอบรายชื่อคำสงวนทั้งหมดได้ที่[ภาคผนวก A][appendix_a]<!-- ignore -->
