# โปรเจกต์ I/O: สร้างโปรแกรมบรรทัดคำสั่ง

บทนี้จะเป็นการประมวลและทบทวนทักษะต่างๆ ที่คุณได้เรียนรู้มาทั้งหมดจนถึงตอนนี้ ควบคู่ไปกับการสำรวจฟีเจอร์เพิ่มเติมอีกเล็กน้อยของไลบรารีมาตรฐาน เราจะร่วมกันสร้างเครื่องมือคอมมานด์ไลน์ (command line tool) ที่มีการจัดการไฟล์และระบบอินพุต/เอาต์พุต เพื่อฝึกฝนและนำแนวคิดต่างๆ ในภาษา Rust ที่คุณได้สั่งสมมาประยุกต์ใช้ในการพัฒนาจริง

ทั้งความเร็ว ความปลอดภัย การให้ผลลัพธ์เป็นไฟล์ไบนารีเดี่ยวที่ทำงานได้ทันที ตลอดจนการรองรับการทำงานข้ามแพลตฟอร์ม ทำให้ Rust เป็นภาษาที่เหมาะสมอย่างยิ่งสำหรับการสร้างเครื่องมือคอมมานด์ไลน์ ดังนั้นสำหรับโปรเจกต์ของเรา เราจะสร้างเครื่องมือค้นหาข้อความคลาสสิกอย่าง `grep` (**g**lobally search a **r**egular **e**xpression and **p**rint) ในเวอร์ชันของเราเอง ในกรณีการใช้งานที่เรียบง่ายที่สุด `grep` จะทำหน้าที่ค้นหาข้อความสตริงที่ระบุภายในไฟล์ที่กำหนด โดยรับพาธของไฟล์และข้อความสตริงที่ต้องการค้นหาเป็นอาร์กิวเมนต์ (arguments) จากนั้นจะอ่านข้อมูลในไฟล์ ค้นหาทุกบรรทัดที่มีข้อความดังกล่าว แล้วพิมพ์บรรทัดเหล่านั้นออกมาแสดงผล

ตลอดเส้นทางการพัฒนา เราจะแสดงให้เห็นถึงวิธีทำให้เครื่องมือคอมมานด์ไลน์ของเราใช้งานฟีเจอร์ต่างๆ ของเทอร์มินัลเฉกเช่นเดียวกับเครื่องมือยอดนิยมอื่นๆ เราจะอ่านค่าจากตัวแปรสภาพแวดล้อม (environment variables) เพื่อเปิดให้ผู้ใช้สามารถปรับแต่งพฤติกรรมการทำงานของเครื่องมือได้ตามต้องการ นอกจากนี้ เรายังจะส่งข้อความแจ้งข้อผิดพลาดไปยังสตรีมข้อผิดพลาดมาตรฐาน (`stderr`) แทนที่จะส่งไปยังเอาต์พุตมาตรฐาน (`stdout`) เพื่อให้ผู้ใช้สามารถเปลี่ยนเส้นทาง (redirect) ผลลัพธ์ที่สำเร็จไปบันทึกลงในไฟล์ได้ โดยที่ยังคงมองเห็นข้อความแจ้งข้อผิดพลาดแสดงอยู่บนหน้าจอเทอร์มินัลตามปกติ

สมาชิกท่านหนึ่งในชุมชน Rust คือ Andrew Gallant ได้เคยสร้างเครื่องมือ `grep` ในเวอร์ชันที่มีฟีเจอร์ครบครันและทำงานได้อย่างรวดเร็วเป็นพิเศษในชื่อ `ripgrep` มาแล้ว แม้ว่าเวอร์ชันที่เรากำลังจะสร้างขึ้นร่วมกันนี้จะเรียบง่ายกว่ามากเมื่อเทียบกัน แต่บทนี้จะมอบความรู้พื้นฐานที่จำเป็นทั้งหมดสำหรับช่วยให้คุณเข้าใจโปรเจกต์ระดับการใช้งานจริงอย่าง `ripgrep` ได้เป็นอย่างดี

โปรเจกต์ `grep` ของเราจะนำแนวคิดหลากหลายด้านที่คุณได้เรียนรู้มาผสมผสานเข้าด้วยกัน:

- การจัดระเบียบโค้ดและโครงสร้างโปรเจกต์ ([บทที่ 7][ch7]<!-- ignore -->)
- การใช้งานเวกเตอร์ (vector) และสตริง (string) ([บทที่ 8][ch8]<!-- ignore -->)
- การจัดการข้อผิดพลาดอย่างเป็นระบบ ([บทที่ 9][ch9]<!-- ignore -->)
- การประยุกต์ใช้เทรต (trait) และไลฟ์ไทม์ (lifetime) อย่างเหมาะสม ([บทที่ 10][ch10]<!-- ignore -->)
- การเขียนชุดทดสอบอัตโนมัติ ([บทที่ 11][ch11]<!-- ignore -->)

นอกจากนี้ เรายังจะแนะนำแนวคิดเรื่องโคลเชอร์ (closures), อิเทอเรเตอร์ (iterators) และเทรตออบเจกต์ (trait objects) อย่างกระชับ ซึ่งจะมีเนื้อหาอธิบายอย่างละเอียดใน [บทที่ 13][ch13]<!-- ignore --> และ [บทที่ 18][ch18]<!-- ignore -->
