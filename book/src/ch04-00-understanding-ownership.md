# ทำความเข้าใจความเป็นเจ้าของ

ความเป็นเจ้าของ (ownership) เป็นฟีเจอร์ที่เป็นเอกลักษณ์ที่สุดของ Rust และมีนัยสำคัญอย่างลึกซึ้งต่อส่วนอื่นๆ ของภาษา มันช่วยให้ Rust รับประกันความปลอดภัยของหน่วยความจำได้โดยไม่ต้องมีตัวเก็บขยะ (garbage collector) ดังนั้นจึงเป็นเรื่องสำคัญที่จะเข้าใจว่าความเป็นเจ้าของทำงานอย่างไร ในบทนี้ เราจะพูดถึงความเป็นเจ้าของรวมถึงฟีเจอร์ที่เกี่ยวข้องอีกหลายอย่าง ได้แก่ การยืม (borrowing) สไลซ์ (slice) และวิธีที่ Rust จัดวางข้อมูลในหน่วยความจำ
