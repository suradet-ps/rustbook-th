# ทำความเข้าใจความเป็นเจ้าของ

ระบบความเป็นเจ้าของ (ownership) ถือเป็นฟีเจอร์ที่เป็นเอกลักษณ์โดดเด่นที่สุดของ Rust และส่งผลต่อการทำงานในส่วนอื่นๆ ทั้งหมดของภาษา โดยระบบนี้ช่วยให้ Rust สามารถรับประกันความปลอดภัยของหน่วยความจำ (memory safety) ได้โดยไม่จำเป็นต้องพึ่งพาตัวเก็บขยะ (garbage collector) ดังนั้นการทำความเข้าใจว่าระบบความเป็นเจ้าของทำงานอย่างไรจึงเป็นเรื่องที่สำคัญอย่างยิ่ง ในบทนี้ เราจะพูดถึงระบบความเป็นเจ้าของ รวมถึงฟีเจอร์ที่เกี่ยวข้องอีกหลายประการ ได้แก่ การยืมข้อมูล (borrowing), สไลซ์ (slice) ตลอดจนวิธีที่ Rust จัดวางและจัดการข้อมูลในหน่วยความจำ
