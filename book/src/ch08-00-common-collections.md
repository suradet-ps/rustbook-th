# คอลเลกชันที่ใช้บ่อย

ไลบรารีมาตรฐานของ Rust มาพร้อมโครงสร้างข้อมูลที่มีประโยชน์มากมายที่เรียกว่า _คอลเลกชัน_ (collection) ชนิดข้อมูลอื่นๆ ส่วนใหญ่แทนค่าเพียงค่าเดียว แต่คอลเลกชันสามารถบรรจุได้หลายค่า ต่างจากชนิดอาร์เรย์และทูเพิลที่มีมาให้ในตัว ข้อมูลที่คอลเลกชันเหล่านี้อ้างถึงถูกจัดเก็บบนฮีป (heap) ซึ่งหมายความว่าไม่จำเป็นต้องรู้ปริมาณข้อมูลตอนคอมไพล์ และข้อมูลสามารถเพิ่มขึ้นหรือลดลงได้ขณะโปรแกรมทำงาน คอลเลกชันแต่ละชนิดมีความสามารถและค่าใช้จ่ายที่แตกต่างกัน และการเลือกชนิดที่เหมาะสมกับสถานการณ์ปัจจุบันของคุณเป็นทักษะที่คุณจะพัฒนาไปเมื่อเวลาผ่านไป ในบทนี้ เราจะพูดถึงคอลเลกชันสามชนิดที่ถูกใช้บ่อยมากในโปรแกรม Rust:

- _เวกเตอร์_ (vector) ช่วยให้คุณจัดเก็บค่าจำนวนไม่คงที่ไว้ติดกัน
- _สตริง_ (string) คือคอลเลกชันของอักขระ เราได้กล่าวถึงชนิด `String` ไปก่อนหน้านี้แล้ว แต่ในบทนี้ เราจะพูดถึงมันอย่างละเอียด
- _แฮชแมป_ (hash map) ช่วยให้คุณเชื่อมโยงค่า (value) กับคีย์ (key) ที่เฉพาะเจาะจง มันเป็นการอิมพลีเมนต์เฉพาะของโครงสร้างข้อมูลทั่วไปที่เรียกว่า _แมป_ (map)

หากต้องการเรียนรู้เกี่ยวกับคอลเลกชันชนิดอื่นๆ ที่ไลบรารีมาตรฐานมีให้ ดู[เอกสารประกอบ][collections]

เราจะพูดถึงวิธีสร้างและอัปเดตเวกเตอร์ สตริง และแฮชแมป รวมถึงสิ่งที่ทำให้แต่ละชนิดพิเศษ

[collections]: ../std/collections/index.html
