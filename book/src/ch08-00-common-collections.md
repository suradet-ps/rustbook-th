# คอลเลกชันที่ใช้บ่อย

ไลบรารีมาตรฐานของ Rust มาพร้อมกับโครงสร้างข้อมูลที่มีประโยชน์อย่างยิ่งจำนวนมาก ซึ่งเรียกว่า **คอลเลกชัน (collections)** ในขณะที่ชนิดข้อมูลพื้นฐานส่วนใหญ่มักจะใช้แทนค่าเดี่ยวๆ เพียงค่าเดียว แต่คอลเลกชันสามารถบรรจุหลายๆ ค่าไว้ด้วยกันได้ และสิ่งที่ทำให้คอลเลกชันแตกต่างไปจากอาร์เรย์ (arrays) หรือทูเพิล (tuples) พื้นฐานที่มีมาให้ในตัวภาษาก็คือ ข้อมูลที่คอลเลกชันเหล่านี้ชี้ไปจะถูกจัดเก็บบนฮีป (heap) ซึ่งหมายความว่าเราไม่จำเป็นต้องทราบขนาดหรือปริมาณข้อมูลล่วงหน้าตั้งแต่ตอนคอมไพล์ และขนาดของข้อมูลสามารถขยายใหญ่ขึ้นหรือหดเล็กลงได้แบบไดนามิกระหว่างที่โปรแกรมกำลังทำงาน คอลเลกชันแต่ละชนิดต่างมีความสามารถและต้นทุนในการประมวลผล (performance costs) ที่แตกต่างกันไป ซึ่งการเลือกใช้ชนิดคอลเลกชันให้เหมาะสมกับสถานการณ์จึงเป็นทักษะที่คุณจะค่อยๆ สั่งสมและพัฒนาได้เมื่อมีประสบการณ์มากขึ้น ในบทนี้ เราจะมาเรียนรู้คอลเลกชัน 3 ชนิดยอดนิยมที่ถูกนำมาใช้งานบ่อยที่สุดในโปรแกรม Rust:

- **เวกเตอร์ (Vector)**: ช่วยให้คุณสามารถจัดเก็บข้อมูลหลายๆ ค่าเรียงต่อกันในหน่วยความจำ โดยมีจำนวนข้อมูลที่ปรับเปลี่ยนเพิ่มลดได้ตามต้องการ
- **สตริง (String)**: คือคอลเลกชันที่รวบรวมตัวอักขระ (characters) เอาไว้ แม้ว่าเราจะเคยกล่าวถึงชนิดข้อมูล `String` กันไปบ้างแล้วก่อนหน้านี้ แต่ในบทนี้เราจะมาเจาะลึกรายละเอียดการทำงานของมันอย่างแท้จริง
- **แฮชแมป (Hash Map)**: ช่วยให้คุณสามารถผูกจับคู่ระหว่างค่า (value) เข้ากับคีย์เฉพาะ (key) แต่ละตัว ซึ่งเป็นการนำโครงสร้างข้อมูลทั่วไปที่เรียกว่า _แมป (map)_ มาอิมพลีเมนต์ใช้งานจริง

หากคุณต้องการศึกษาเพิ่มเติมเกี่ยวกับคอลเลกชันชนิดอื่นๆ ที่มีให้ใช้งานในไลบรารีมาตรฐาน สามารถอ่านต่อได้ที่ [เอกสารประกอบฉบับทางการ][collections]

เราจะมาเรียนรู้วิธีการสร้างและอัปเดตข้อมูลของทั้งเวกเตอร์, สตริง และแฮชแมป พร้อมทั้งสำรวจจุดเด่นเฉพาะตัวที่ทำให้แต่ละชนิดมีความพิเศษ
