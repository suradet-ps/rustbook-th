## Hello, World!

ตอนนี้คุณติดตั้ง Rust เรียบร้อยแล้ว ถึงเวลาเขียนโปรแกรม Rust โปรแกรมแรกของคุณ เป็นธรรมเนียมปฏิบัติเมื่อเรียนภาษาใหม่ที่จะเขียนโปรแกรมเล็กๆ ที่พิมพ์ข้อความ `Hello, world!` ออกทางหน้าจอ เรามาทำแบบเดียวกันในที่นี้!

> หมายเหตุ: หนังสือเล่มนี้สมมติว่าคุณคุ้นเคยกับบรรทัดคำสั่งมาบ้างแล้ว Rust ไม่ได้กำหนดข้อบังคับเฉพาะเจาะจงเกี่ยวกับโปรแกรมแก้ไข เครื่องมือ หรือตำแหน่งที่เก็บโค้ดของคุณ ดังนั้นหากคุณสะดวกใช้ IDE แทนบรรทัดคำสั่ง ก็ใช้ IDE ที่คุณชอบได้เลย ทุกวันนี้ IDE หลายตัวรองรับ Rust ในระดับหนึ่ง ดูรายละเอียดได้จากเอกสารของ IDE นั้นๆ ทีมงาน Rust มุ่งเน้นการรองรับ IDE ที่ดีผ่าน `rust-analyzer` ดูรายละเอียดเพิ่มเติมได้ที่[ภาคผนวก D][devtools]<!-- ignore -->

### การตั้งค่าไดเรกทอรีโปรเจกต์

เริ่มต้นด้วยการสร้างไดเรกทอรีสำหรับเก็บโค้ด Rust ของคุณ Rust ไม่สนใจว่าคุณเก็บโค้ดไว้ที่ไหน แต่สำหรับแบบฝึกหัดและโปรเจกต์ในหนังสือเล่มนี้ เราแนะนำให้สร้างไดเรกทอรี _projects_ ในไดเรกทอรีโฮมของคุณและเก็บโปรเจกต์ทั้งหมดไว้ที่นั่น

เปิดเทอร์มินัลแล้วป้อนคำสั่งต่อไปนี้เพื่อสร้างไดเรกทอรี _projects_ และไดเรกทอรีสำหรับโปรเจกต์ "Hello, world!" ภายในไดเรกทอรี _projects_

สำหรับ Linux, macOS และ PowerShell บน Windows ให้ป้อนคำสั่งนี้:

```console
$ mkdir ~/projects
$ cd ~/projects
$ mkdir hello_world
$ cd hello_world
```

สำหรับ Windows CMD ให้ป้อนคำสั่งนี้:

```cmd
> mkdir "%USERPROFILE%\projects"
> cd /d "%USERPROFILE%\projects"
> mkdir hello_world
> cd hello_world
```

### พื้นฐานของโปรแกรม Rust

ต่อไป ให้สร้างไฟล์ซอร์สใหม่และตั้งชื่อว่า _main.rs_ ไฟล์ Rust ลงท้ายด้วยนามสกุล _.rs_ เสมอ หากชื่อไฟล์ของคุณมีมากกว่าหนึ่งคำ ธรรมเนียมปฏิบัติคือใช้ขีดล่างคั่นระหว่างคำ ตัวอย่างเช่น ใช้ _hello_world.rs_ แทน _helloworld.rs_

ตอนนี้ให้เปิดไฟล์ _main.rs_ ที่คุณเพิ่งสร้าง แล้วป้อนโค้ดในลิสติ้ง 1-1

<Listing number="1-1" file-name="main.rs" caption="โปรแกรมที่พิมพ์ `Hello, world!`">

```rust
fn main() {
    println!("Hello, world!");
}
```

</Listing>

บันทึกไฟล์แล้วกลับไปที่หน้าต่างเทอร์มินัลในไดเรกทอรี _~/projects/hello_world_ บน Linux หรือ macOS ให้ป้อนคำสั่งต่อไปนี้เพื่อคอมไพล์และรันไฟล์:

```console
$ rustc main.rs
$ ./main
Hello, world!
```

บน Windows ให้ป้อนคำสั่ง `.\main` แทน `./main`:

```powershell
> rustc main.rs
> .\main
Hello, world!
```

ไม่ว่าคุณจะใช้ระบบปฏิบัติการใด สตริง `Hello, world!` ควรพิมพ์ออกมาที่เทอร์มินัล หากคุณไม่เห็นเอาต์พุตนี้ ให้กลับไปดูส่วน["การแก้ปัญหา"][troubleshooting]<!-- ignore --> ของหัวข้อการติดตั้งเพื่อหาวิธีขอความช่วยเหลือ

หาก `Hello, world!` พิมพ์ออกมาจริง ขอแสดงความยินดีด้วย! คุณได้เขียนโปรแกรม Rust อย่างเป็นทางการแล้ว นั่นทำให้คุณเป็นโปรแกรมเมอร์ Rust—ยินดีต้อนรับ!

### โครงสร้างของโปรแกรม Rust

มาพิจารณาโปรแกรม "Hello, world!" นี้โดยละเอียดกัน นี่คือส่วนแรกของปริศนา:

```rust
fn main() {

}
```

บรรทัดเหล่านี้กำหนดฟังก์ชันชื่อ `main` ฟังก์ชัน `main` มีความพิเศษ เพราะเป็นโค้ดส่วนแรกที่ทำงานในทุกโปรแกรม Rust ที่รันได้เสมอ ในที่นี้ บรรทัดแรกประกาศฟังก์ชันชื่อ `main` ที่ไม่มีพารามิเตอร์และไม่คืนค่าใดๆ หากมีพารามิเตอร์ พารามิเตอร์จะอยู่ในวงเล็บ (`()`)

ตัวฟังก์ชันถูกล้อมด้วย `{}` Rust บังคับให้ต้องมีวงเล็บปีกกาล้อมตัวฟังก์ชันทุกฟังก์ชัน และเป็นสไตล์ที่ดีที่จะวางวงเล็บปีกกาเปิดไว้บนบรรทัดเดียวกับคำประกาศฟังก์ชัน โดยเว้นหนึ่งช่องว่างคั่น

> หมายเหตุ: หากคุณต้องการยึดสไตล์มาตรฐานเดียวกันในทุกโปรเจกต์ Rust คุณสามารถใช้เครื่องมือจัดรูปแบบอัตโนมัติชื่อ `rustfmt` เพื่อจัดรูปแบบโค้ดของคุณตามสไตล์ที่กำหนดได้ (รายละเอียดเพิ่มเติมเกี่ยวกับ `rustfmt` อยู่ใน[ภาคผนวก D][devtools]<!-- ignore -->) ทีมงาน Rust ได้รวมเครื่องมือนี้มาไว้ในชุดการแจกจ่าย Rust มาตรฐาน เช่นเดียวกับ `rustc` ดังนั้นมันจึงน่าจะติดตั้งอยู่ในเครื่องของคุณแล้ว!

เนื้อในของฟังก์ชัน `main` ประกอบด้วยโค้ดต่อไปนี้:

```rust
println!("Hello, world!");
```

บรรทัดนี้ทำงานทั้งหมดในโปรแกรมเล็กๆ นี้: มันพิมพ์ข้อความออกทางหน้าจอ มีรายละเอียดสำคัญสามประการที่ควรสังเกตตรงนี้

ประการแรก `println!` เรียกรมมาโครของ Rust หากมันเรียกฟังก์ชันแทน จะเขียนว่า `println` (ไม่มี `!`) มาโครของ Rust เป็นวิธีเขียนโค้ดที่สร้างโค้ดขึ้นมาเพื่อขยายวากยสัมพันธ์ของ Rust เราจะพูดถึงรายละเอียดเพิ่มเติมใน[บทที่ 20][ch20-macros]<!-- ignore --> สำหรับตอนนี้ คุณเพียงแค่ต้องรู้ว่าการใช้ `!` หมายความว่าคุณกำลังเรียกมาโครแทนฟังก์ชันปกติ และมาโครไม่ได้ปฏิบัติตามกฎเดียวกับฟังก์ชันเสมอไป

ประการที่สอง คุณจะเห็นสตริง `"Hello, world!"` เราส่งสตริงนี้เป็นอาร์กิวเมนต์ให้ `println!` และสตริงจะถูกพิมพ์ออกทางหน้าจอ

ประการที่สาม เราจบบรรทัดด้วยอัฒภาค (`;`) ซึ่งบ่งชี้ว่าเอ็กซ์เพรสชันนี้จบลงแล้ว และพร้อมที่จะเริ่มเอ็กซ์เพรสชันถัดไป โค้ด Rust ส่วนใหญ่จบบรรทัดด้วยอัฒภาค

### การคอมไพล์และการรัน

คุณเพิ่งรันโปรแกรมที่สร้างขึ้นใหม่ มาพิจารณาแต่ละขั้นตอนของกระบวนการกัน

ก่อนจะรันโปรแกรม Rust คุณต้องคอมไพล์มันด้วยคอมไพเลอร์ Rust โดยป้อนคำสั่ง `rustc` พร้อมชื่อไฟล์ซอร์สของคุณ เช่นนี้:

```console
$ rustc main.rs
```

หากคุณมีพื้นฐาน C หรือ C++ คุณจะสังเกตว่าคำสั่งนี้คล้ายกับ `gcc` หรือ `clang` หลังจากคอมไพล์สำเร็จ Rust จะสร้างไฟล์ไบนารีที่รันได้ออกมา

บน Linux, macOS และ PowerShell บน Windows คุณสามารถดูไฟล์ที่รันได้โดยป้อนคำสั่ง `ls` ในเชลล์ของคุณ:

```console
$ ls
main  main.rs
```

บน Linux และ macOS คุณจะเห็นสองไฟล์ ส่วน PowerShell บน Windows คุณจะเห็นสามไฟล์เหมือนกับที่เห็นเมื่อใช้ CMD สำหรับ CMD บน Windows คุณจะป้อนคำสั่งต่อไปนี้:

```cmd
> dir /B %= the /B option says to only show the file names =%
main.exe
main.pdb
main.rs
```

นี่แสดงไฟล์ซอร์สโค้ดที่มีนามสกุล _.rs_ ไฟล์ที่รันได้ (_main.exe_ บน Windows แต่เป็น _main_ บนแพลตฟอร์มอื่นทั้งหมด) และเมื่อใช้ Windows ยังมีไฟล์ที่มีข้อมูลดีบักนามสกุล _.pdb_ จากตรงนี้ คุณรันไฟล์ _main_ หรือ _main.exe_ ได้ดังนี้:

```console
$ ./main # or .\main on Windows
```

หาก _main.rs_ ของคุณเป็นโปรแกรม "Hello, world!" บรรทัดนี้จะพิมพ์ `Hello, world!` ออกทางเทอร์มินัลของคุณ

หากคุณคุ้นเคยกับภาษาไดนามิกอย่าง Ruby, Python หรือ JavaScript มากกว่า คุณอาจไม่ชินกับการคอมไพล์และรันโปรแกรมเป็นสองขั้นตอนแยกกัน Rust เป็นภาษาแบบ _คอมไพล์ล่วงหน้า_ (ahead-of-time compiled) หมายความว่าคุณคอมไพล์โปรแกรมแล้วมอบไฟล์ที่รันได้ให้ผู้อื่นได้ และพวกเขารันมันได้แม้ไม่ได้ติดตั้ง Rust หากคุณให้ไฟล์ _.rb_, _.py_ หรือ _.js_ แก่ใครสักคน พวกเขาจำเป็นต้องมีตัวรัน Ruby, Python หรือ JavaScript ติดตั้งอยู่ (ตามลำดับ) แต่ในภาษาเหล่านั้น คุณใช้เพียงคำสั่งเดียวในการคอมไพล์และรันโปรแกรม ทุกอย่างล้วนเป็นข้อแลกเปลี่ยนในการออกแบบภาษา

การคอมไพล์ด้วย `rustc` เพียงอย่างเดียวก็ใช้ได้สำหรับโปรแกรมง่ายๆ แต่เมื่อโปรเจกต์ของคุณเติบโตขึ้น คุณจะต้องจัดการตัวเลือกทั้งหมดและทำให้การแชร์โค้ดทำได้ง่าย ต่อไป เราจะแนะนำคุณรู้จักเครื่องมือ Cargo ซึ่งจะช่วยให้คุณเขียนโปรแกรม Rust ระดับใช้งานจริงได้
