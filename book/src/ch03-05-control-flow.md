## การควบคุมโฟลว์

ความสามารถในการสั่งให้โค้ดบางส่วนทำงานตามเงื่อนไข (condition) ว่าเป็นจริง (`true`) หรือไม่ รวมถึงความสามารถในการสั่งให้โค้ดทำงานซ้ำๆ ตราบใดที่เงื่อนไขยังเป็นจริง ถือเป็นโครงสร้างพื้นฐานที่มีอยู่ในภาษาโปรแกรมเกือบทุกภาษา สำหรับใน Rust โครงสร้างหลักๆ ที่ใช้ควบคุมลำดับการทำงาน (control flow) ของโปรแกรมก็คือนิพจน์ `if` และลูป (loop)

### นิพจน์ `if`

นิพจน์ `if` ช่วยให้คุณสามารถแยกสายการทำงาน (branch) ของโค้ดตามเงื่อนไขที่กำหนดได้ โดยมีหลักการคือ “หากเงื่อนไขนี้เป็นจริง ให้ทำงานในบล็อกโค้ดนี้ แต่ถ้าเงื่อนไขไม่เป็นจริง ก็ไม่ต้องทำงานในบล็อกนี้”

### การวนซ้ำด้วยลูป

การสั่งให้บล็อกโค้ดทำงานซ้ำมากกว่าหนึ่งครั้งถือเป็นงานที่พบบ่อยและมีประโยชน์อย่างยิ่ง สำหรับงานนี้ Rust มีโครงสร้าง_ลูป_ (loop) ให้เลือกใช้งานหลายรูปแบบ ซึ่งจะรันโค้ดภายในตัวลูปไปจนสุดแล้ววนกลับมาเริ่มต้นใหม่ทันที เพื่อทดลองใช้งานลูป มาสร้างโปรเจกต์ใหม่ชื่อ _loops_ กัน

Rust มีลูปให้ใช้งานสามรูปแบบ ได้แก่ `loop`, `while` และ `for` มาลองดูทีละแบบกัน

ก่อนลูป เราประกาศตัวแปรชื่อ `counter` และกำหนดค่าเริ่มต้นเป็น `0` จากนั้นเราประกาศตัวแปรชื่อ `result` เพื่อเก็บค่าที่คืนกลับมาจากลูป ในทุกๆ รอบของการวนซ้ำ เราเพิ่มค่า `1` ให้กับตัวแปร `counter` แล้วตรวจสอบว่า `counter` มีค่าเท่ากับ `10` หรือไม่ เมื่อเท่ากัน เราจะใช้คำสงวน `break` พร้อมกับค่า `counter * 2` หลังจบลูป เราใช้อัฒภาค (semicolon) เพื่อจบคำสั่งที่กำหนดค่าให้กับ `result` สุดท้าย เราพิมพ์ค่าใน `result` ออกมา ซึ่งในกรณีนี้คือ `20`

คุณยังสามารถใช้ `return` จากภายในลูปได้เช่นกัน โดยขณะที่ `break` จะออกจากลูปปัจจุบันเท่านั้น คำสั่ง `return` จะออกจากฟังก์ชันปัจจุบันเสมอ
