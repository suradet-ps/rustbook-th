## การควบคุมโฟลว์

ความสามารถในการรันโค้ดบางส่วนโดยขึ้นอยู่กับว่าเงื่อนไข (condition) เป็น `true` หรือไม่ และความสามารถในการรันโค้ดบางส่วนซ้ำๆ ในขณะที่เงื่อนไขเป็น `true` เป็นองค์ประกอบพื้นฐานในภาษาโปรแกรมส่วนใหญ่ โครงสร้างที่พบบ่อยที่สุดที่ช่วยให้คุณควบคุมโฟลว์การทำงานของโค้ด Rust คือเอ็กซ์เพรสชัน `if` และลูป (loop)

สร้างโปรเจกต์ใหม่ชื่อ _branches_ ในไดเรกทอรี _projects_ ของคุณเพื่อสำรวจเอ็กซ์เพรสชัน `if` ในไฟล์ _src/main.rs_ ให้ป้อนโค้ดต่อไปนี้:

### การวนซ้ำด้วยลูป

การรันบล็อกโค้ดมากกว่าหนึ่งครั้งมักมีประโยชน์ สำหรับงานนี้ Rust มี_ลูป_ (loop) หลายแบบ ซึ่งจะรันโค้ดภายในบอดี้ของลูปจนถึงจุดสิ้นสุดแล้วเริ่มกลับไปที่จุดเริ่มต้นทันที เพื่อทดลองกับลูป มาสร้างโปรเจกต์ใหม่ชื่อ _loops_ กัน

Rust มีลูปสามชนิด ได้แก่ `loop`, `while` และ `for` มาลองทีละชนิดกัน

#### การคืนค่าจากลูป

หนึ่งในการใช้งานของ `loop` คือการลองทำการดำเนินการที่คุณรู้ว่าอาจล้มเหลวซ้ำ เช่น การตรวจสอบว่าเธรด (thread) ทำงานเสร็จแล้วหรือยัง คุณอาจต้องส่งผลลัพธ์ของการดำเนินการนั้นออกจากลูปไปยังโค้ดส่วนที่เหลือของคุณด้วย เมื่อต้องการทำเช่นนี้ คุณสามารถเพิ่มค่าที่คุณต้องการให้คืนกลับไว้หลังเอ็กซ์เพรสชัน `break` ที่คุณใช้หยุดลูป ค่านั้นจะถูกคืนออกมาจากลูปเพื่อให้คุณใช้งานได้ ดังที่แสดงที่นี่:

```rust
{{#rustdoc_include ../listings/ch03-common-programming-concepts/no-listing-33-return-value-from-loop/src/main.rs}}
```

ก่อนลูป เราประกาศตัวแปรชื่อ `counter` และกำหนดค่าเริ่มต้นเป็น `0` จากนั้นเราประกาศตัวแปรชื่อ `result` เพื่อเก็บค่าที่คืนกลับจากลูป ในทุกการวนซ้ำของลูป เราเพิ่ม `1` ให้กับตัวแปร `counter` แล้วตรวจสอบว่า `counter` เท่ากับ `10` หรือไม่ เมื่อเท่ากัน เราใช้คำสงวน `break` พร้อมค่า `counter * 2` หลังลูป เราใช้อัฒภาคเพื่อจบสเตตเมนต์ที่กำหนดค่าให้ `result` สุดท้าย เราพิมพ์ค่าใน `result` ซึ่งในกรณีนี้คือ `20`
