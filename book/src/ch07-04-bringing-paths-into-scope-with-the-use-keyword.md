## นำพาธเข้าสู่สโคปด้วยคำสงวน `use`

การต้องคอยเขียนพาธเต็มยาวๆ เพื่อเรียกใช้งานฟังก์ชันอาจทำให้รู้สึกไม่สะดวกและดูซ้ำซ้อน ในลิสติ้ง 7-7 ไม่ว่าเราจะเลือกใช้พาธแบบสัมบูรณ์หรือแบบสัมพัทธ์ในการเรียกฟังก์ชัน `add_to_waitlist` เราก็ยังต้องระบุ `front_of_house` และ `hosting` ทุกครั้งที่ต้องการเรียกใช้งาน แต่โชคดีที่ Rust มีวิธีช่วยลดทอนขั้นตอนนี้ให้เรียบง่ายขึ้น: นั่นคือเราสามารถสร้างทางลัดไปยังพาธนั้นด้วยคีย์เวิร์ด `use` เพียงครั้งเดียว จากนั้นก็สามารถใช้ชื่อที่สั้นลงได้ในทุกๆ จุดภายในสโคป (scope) นั้น

### การส่งออกชื่ออีกครั้งด้วย `pub use`

จากนั้น เพื่อนำนิยามต่างๆ ของ `rand` เข้ามาไว้ในสโคปของแพ็กเกจ เราจึงเพิ่มบรรทัด `use` ที่ขึ้นต้นด้วยชื่อเครต `rand` พร้อมระบุไอเทมที่ต้องการนำเข้ามา ย้อนกลับไปในหัวข้อ [“การสร้างตัวเลขสุ่ม”][rand]<!-- ignore --> ในบทที่ 2 เราได้นำไอเทมในมอดูลพรีลูด `rand::prelude` เข้าสู่สโคป และเรียกใช้งานฟังก์ชัน `rand::rng`:

```rust,ignore
{{#rustdoc_include ../listings/ch02-guessing-game-tutorial/listing-02-03/src/main.rs:ch07-04}}
```

สมาชิกในชุมชน Rust ได้ร่วมกันแบ่งปันแพ็กเกจที่มีประโยชน์ไว้มากมายบน [crates.io](https://crates.io/) และขั้นตอนในการดึงแพ็กเกจเหล่านั้นมาใช้งานในโปรเจกต์ของคุณก็ใช้วิธีการเดียวกันทั้งหมด: นั่นคือระบุชื่อแพ็กเกจในไฟล์ _Cargo.toml_ ของคุณ แล้วใช้คำสั่ง `use` เพื่อนำไอเทมจากเครตเหล่านั้นเข้ามาในสโคป

โปรดทราบว่า ไลบรารีมาตรฐาน `std` ก็ถือเป็นเครตตัวหนึ่งที่อยู่ภายนอกแพ็กเกจของเราเช่นกัน เพียงแต่เนื่องจากไลบรารีมาตรฐานถูกติดตั้งมาพร้อมกับตัวภาษา Rust อยู่แล้ว เราจึงไม่จำเป็นต้องไปแก้ไขไฟล์ _Cargo.toml_ เพื่อรวม `std` เข้ามา แต่เรายังคงจำเป็นต้องใช้คำสั่ง `use` เพื่อดึงไอเทมจากในนั้นเข้ามาไว้ในสโคปของโปรเจกต์เรา เช่น การใช้งาน `HashMap` เราจะต้องเขียนคำสั่งดังนี้:

```rust
use std::collections::HashMap;
```

ซึ่งนี่คือพาธแบบสัมบูรณ์ (absolute path) ที่เริ่มต้นด้วย `std` อันเป็นชื่อของเครตไลบรารีมาตรฐานนั่นเอง

### การนำเข้ารายการด้วยตัวดำเนินการ glob

หากเราต้องการนำไอเทมสาธารณะ (public) _ทั้งหมด_ ที่นิยามอยู่ภายใต้พาธหนึ่งเข้ามาไว้ในสโคป เราสามารถระบุพาธนั้นแล้วตามด้วยตัวดำเนินการ glob (glob operator) คือเครื่องหมายดอกจัน `*`:

```rust
use std::collections::*;
```

สเตตเมนต์ `use` บรรทัดนี้จะนำทุกๆ ไอเทมสาธารณะที่นิยามอยู่ใน `std::collections` เข้ามาไว้ในสโคปปัจจุบันทั้งหมด แต่จงใช้ตัวดำเนินการ glob ด้วยความระมัดระวัง! เพราะ glob อาจทำให้ยากต่อการตรวจสอบว่ามีชื่ออะไรบ้างที่อยู่ในสโคป และชื่อแต่ละชื่อที่ถูกเรียกใช้ในโปรแกรมนั้นถูกนิยามมาจากที่ใดกันแน่ ยิ่งไปกว่านั้น หากดีเพนเดนซีภายนอกมีการปรับเปลี่ยนนิยามในเวอร์ชันใหม่ สิ่งที่คุณนำเข้ามาก็จะเปลี่ยนตามไปด้วย ซึ่งอาจก่อให้เกิดข้อผิดพลาดในการคอมไพล์เมื่อคุณอัปเกรดเวอร์ชันของดีเพนเดนซี ตัวอย่างเช่น หากดีเพนเดนซีนั้นเพิ่มนิยามใหม่ที่มีชื่อตรงกับชื่อที่คุณเคยนิยามไว้ในสโคปเดียวกัน

ตัวดำเนินการ glob มักถูกนำไปใช้ในกระบวนการเขียนเทสต์ เพื่อนำโค้ดทั้งหมดที่ต้องการทดสอบเข้ามาไว้ในมอดูล `tests` ซึ่งเราจะได้เรียนรู้กันในหัวข้อ [“วิธีเขียนเทสต์”][writing-tests]<!-- ignore --> ในบทที่ 11 นอกจากนี้ ตัวดำเนินการ glob ยังถูกนำมาใช้เป็นส่วนหนึ่งของรูปแบบพรีลูด (prelude pattern) อีกด้วย โดยคุณสามารถดูรายละเอียดเพิ่มเติมได้ที่ [เอกสารของไลบรารีมาตรฐาน](../std/prelude/index.html#other-preludes)<!-- ignore -->
