## นำพาธเข้าสู่สโคปด้วยคำสงวน `use`

### การนำเข้ารายการด้วยตัวดำเนินการ glob

หากเราต้องการนำรายการ_ทั้งหมด_ที่เป็นแบบสาธารณะ (public) ซึ่งนิยามในพาธหนึ่งเข้าสู่สโคป เราสามารถระบุพาธนั้นตามด้วยตัวดำเนินการ glob (glob operator) `*` ได้:

```rust
use std::collections::*;
```

สเตตเมนต์ `use` นี้นำรายการสาธารณะทั้งหมดที่นิยามใน `std::collections` เข้าสู่สโคปปัจจุบัน ระวังให้ดีเมื่อใช้ตัวดำเนินการ glob! Glob อาจทำให้บอกได้ยากว่าชื่อใดอยู่ในสโคปและชื่อที่ใช้ในโปรแกรมของคุณถูกนิยามไว้ที่ใด นอกจากนี้ หากดีเพนเดนซีเปลี่ยนนิยามของมัน สิ่งที่คุณนำเข้าก็เปลี่ยนไปด้วย ซึ่งอาจนำไปสู่ข้อผิดพลาดจากคอมไพเลอร์เมื่อคุณอัปเกรดดีเพนเดนซี หากดีเพนเดนซีเพิ่มนิยามที่ชื่อซ้ำกับนิยามของคุณในสโคปเดียวกัน เป็นต้น

ตัวดำเนินการ glob มักถูกใช้เมื่อเขียนเทสต์เพื่อนำทุกอย่างที่อยู่ภายใต้การทดสอบเข้าสู่มอดูล `tests` เราจะพูดถึงเรื่องนั้นใน[“วิธีเขียนเทสต์”][writing-tests]<!-- ignore --> ในบทที่ 11 ตัวดำเนินการ glob บางครั้งยังถูกใช้เป็นส่วนหนึ่งของแพตเทิร์นพรีลูด (prelude pattern): ดู[เอกสารไลบรารีมาตรฐาน](../std/prelude/index.html#other-preludes)<!-- ignore --> สำหรับข้อมูลเพิ่มเติมเกี่ยวกับแพตเทิร์นนั้น
