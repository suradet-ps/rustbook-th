# เพิ่มเติมเกี่ยวกับ Cargo และ Crates.io

จนถึงตอนนี้ เราได้ใช้เพียงฟีเจอร์พื้นฐานที่สุดของ Cargo ในการบิลด์ รัน และทดสอบโค้ดของเรา แต่ Cargo ทำได้มากกว่านั้นอีกมาก ในบทนี้ เราจะพูดถึงฟีเจอร์อื่นๆ ที่ขั้นสูงกว่าของมัน เพื่อแสดงให้คุณเห็นวิธีทำสิ่งต่อไปนี้:

- ปรับแต่งการบิลด์ของคุณผ่านโปรไฟล์การรีลีส (release profile)
- เผยแพร่ไลบรารีบน [crates.io](https://crates.io/)<!-- ignore -->
- จัดระเบียบโปรเจกต์ขนาดใหญ่ด้วยเวิร์กสเปซ (workspace)
- ติดตั้งไบนารี (binary) จาก [crates.io](https://crates.io/)<!-- ignore -->
- ขยายความสามารถของ Cargo ด้วยคำสั่งกำหนดเอง

Cargo ทำได้มากกว่าฟังก์ชันการทำงานที่เราครอบคลุมในบทนี้อีก ดังนั้นสำหรับคำอธิบายแบบเต็มของฟีเจอร์ทั้งหมดของมัน โปรดดู[เอกสารของมัน](https://doc.rust-lang.org/cargo/)
